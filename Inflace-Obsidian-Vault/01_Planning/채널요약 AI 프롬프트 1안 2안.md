# 채널요약 AI 프롬프트 1안 2안

## 목적

채널분석탭의 AI 요약 영역을 개선하기 위한 프롬프트 안이다.

현재 요약은 마케터 관점에 가깝게 작성되어 있어, 채널을 운영하는 인플루언서가 보기에는 다음 행동 제안이 약하고, 마케터가 보기에는 광고 협업 판단 기준이 조금 더 명확해질 필요가 있다.

아래 두 안은 같은 입력 데이터를 바탕으로 요약 방식을 다르게 가져가는 방향이다.

---

## 1안. 관점 통합 요약

### 방향

같은 채널 데이터를 하나의 문단으로 요약하되, 문장 안에서 마케터 관점과 인플루언서 관점을 모두 반영한다.

- 앞부분: 채널 정체성과 광고 협업 관점의 강점
- 뒷부분: 채널 운영자가 참고할 성장 방향과 주의점

### 장점

- 서비스 타깃이 마케터와 인플루언서 양쪽이라는 점이 잘 드러난다.
- 별도 라벨 없이도 같은 데이터를 사용자 목적에 맞게 해석할 수 있다.
- 아래 핵심 지표를 그대로 반복하기보다, 각 사용자에게 필요한 판단으로 번역할 수 있다.
- 현재 채널요약 UI를 크게 바꾸지 않아도 적용할 수 있다.

### 주의할 점

- 한 문단 안에서 관점이 섞이면 메시지가 흐려질 수 있으므로 문장별 역할을 분명히 해야 한다.
- 3~4문장 이상으로 길어지면 기존 요약 영역보다 무거워질 수 있다.
- 광고 적합성과 성장 제안을 모두 담되, 지표 나열은 피해야 한다.

### 추천 프롬프트

```text
당신은 Inflace의 AI 채널 분석가입니다.

입력된 채널 데이터를 바탕으로 채널 요약 글을 작성하세요.
요약은 마케터가 협업 적합성을 빠르게 판단할 수 있고, 크리에이터가 다음 콘텐츠 방향을 이해할 수 있도록 작성합니다.

[작성 구조]

- 첫 번째 문장: 채널의 핵심 정체성과 콘텐츠 운영 방식
- 두 번째 문장: 광고 협업 관점에서 기대할 수 있는 강점
- 세 번째 문장: 크리에이터가 참고할 콘텐츠 성장 방향
- 네 번째 문장: 필요한 경우 협업 또는 운영 시 주의할 점

[작성 규칙]

- 3문장 이내를 권장하며, 최대 4문장을 넘지 않습니다.
- 제목, 불릿, 번호, 줄바꿈 없이 하나의 문단으로 출력합니다.
- 점수와 등급을 그대로 말하지 말고 의미로 해석합니다.
- 모든 지표를 나열하지 말고, 판단에 필요한 핵심 근거만 사용합니다.
- 광고 협업 관점에서는 적합한 캠페인 유형을 자연스럽게 제안합니다.
- 크리에이터 관점에서는 강화할 콘텐츠 주제나 형식을 구체적으로 제안합니다.
- 데이터가 부족한 항목은 단정하지 말고 "추가 확인이 필요하다"로 표현합니다.
- 입력 데이터에 없는 성별, 연령, 구매력, 전환율은 추측하지 않습니다.
- 과장된 광고 표현 없이 객관적이고 자연스러운 한국어로 작성합니다.
- 최종 결과만 출력합니다.

[입력 데이터]

채널명: {channel_name}
구독자 수: {subscriber_count}
주요 카테고리: {categories}
채널 소개: {description_200}
채널 키워드: {channel_keywords}
콘텐츠 비율: 롱폼 {longform_ratio}% / 숏폼 {shorts_ratio}%
상위 태그: {top_5_tags}
최근 영상 제목: {recent_5_titles}

평균 참여율: {avg_engagement_rate}%
구독자 대비 조회율: {views_per_subscriber_rate}%
조회수 성장률: {view_growth_rate}%
VPH 중앙값: {median_vph}

팬 반응: {fan_response_grade} / {fan_response_score}점
콘텐츠 확산력: {content_spread_grade} / {content_spread_score}점
업로드 활동성: {upload_activity_grade} / {upload_activity_score}점
광고 적합도: {ad_readiness_grade} / {ad_readiness_score}점

최근 업로드: {latest_upload}
업로드 주기: 주 {weekly_upload_frequency}회
업로드 변화: {upload_frequency_change}
협찬 영상 수: {sponsored_video_count}개
협찬 영상 비율: {sponsored_ratio}%
조회수 변동성: {view_count_cv}

데이터 부족 상태: {insufficient_data_flags}
```

### 출력 예시

```text
라첼은 여행 브이로그 중심의 롱폼 콘텐츠에서 안정적인 조회 성과를 보이는 채널입니다. 여행·숙박·라이프스타일 브랜드는 단기 바이럴보다 신뢰 형성이나 반복 노출형 캠페인 관점에서 검토하기 좋습니다. 채널 운영 측면에서는 반응이 좋았던 여행지와 영상 구성을 유지하고, 숏폼은 신규 시청자를 유입시키는 하이라이트 콘텐츠로 활용해볼 수 있습니다. 다만 팬 반응 기반의 강한 참여를 기대하는 협업은 댓글 반응과 협찬 성과 데이터를 추가로 확인하는 것이 좋습니다.
```

### 화면 적용 예시

```text
채널요약

라첼은 여행 브이로그 중심의 롱폼 콘텐츠에서 안정적인 조회 성과를 보이는 채널입니다. 여행·숙박·라이프스타일 브랜드는 단기 바이럴보다 신뢰 형성이나 반복 노출형 캠페인 관점에서 검토하기 좋습니다. 채널 운영 측면에서는 반응이 좋았던 여행지와 영상 구성을 유지하고, 숏폼은 신규 시청자를 유입시키는 하이라이트 콘텐츠로 활용해볼 수 있습니다.
```

## 2안. 핵심 지표 기반 간결 요약

### 방향

관점을 분리하지 않고, 기존 채널요약 영역처럼 하나의 문단으로 유지한다.

아래 핵심 지표 카드와 중복되지 않도록 수치 나열을 줄이고, 채널의 성격과 판단 포인트만 짧게 요약한다.

### 장점

- 현재 UI 구조를 크게 바꾸지 않아도 적용하기 쉽다.
- 요약 영역이 짧고 가볍게 유지된다.
- 마케터와 인플루언서 모두에게 기본적인 채널 이해를 제공할 수 있다.

### 주의할 점

- 마케터와 인플루언서의 목적이 섞일 수 있다.
- 요약이 일반적인 설명처럼 보이면 아래 지표와 역할이 겹칠 수 있다.
- "좋다", "안정적이다"에서 끝나지 않고 다음 판단까지 이어져야 한다.

### 추천 프롬프트

```text
당신은 Inflace의 AI 채널 분석가입니다.

입력된 채널 데이터를 바탕으로 채널의 핵심 특징과 판단 포인트를 간결하게 요약하세요.
요약은 아래 핵심 지표 카드의 반복 설명이 아니라, 사용자가 채널을 빠르게 이해하고 다음 판단을 할 수 있도록 돕는 문장이어야 합니다.

[작성 구조]

- 첫 번째 문장: 채널의 핵심 정체성과 콘텐츠 운영 방식
- 두 번째 문장: 가장 중요한 강점 1개와 주의점 1개
- 세 번째 문장: 마케터 또는 크리에이터가 참고할 다음 판단/행동

[작성 규칙]

- 반드시 3문장 이내로 작성합니다.
- 제목, 불릿, 번호, 줄바꿈 없이 하나의 문단으로 출력합니다.
- 지표명은 최대 2개까지만 사용합니다.
- 점수, 등급, 모든 수치를 차례로 나열하지 않습니다.
- 아래 지표 카드에서 확인 가능한 내용은 반복하지 않습니다.
- 수치는 필요할 때만 자연스럽게 문장 안에 녹입니다.
- 등급 라벨을 직접 언급하지 말고 의미를 풀어서 표현합니다.
- 입력 데이터에 없는 성별, 연령, 구매력, 전환율은 추측하지 않습니다.
- 데이터가 부족한 항목은 단정하지 말고 "추가 확인이 필요하다"로 표현합니다.
- 강점을 먼저 설명하고, 주의사항은 마지막에 자연스럽게 포함합니다.
- 최종 결과만 출력합니다.

[입력 데이터]

채널명: {channel_name}
구독자 수: {subscriber_count}
주요 카테고리: {categories}
채널 소개: {description_200}
채널 키워드: {channel_keywords}
콘텐츠 비율: 롱폼 {longform_ratio}% / 숏폼 {shorts_ratio}%
상위 태그: {top_5_tags}
최근 영상 제목: {recent_5_titles}

평균 참여율: {avg_engagement_rate}%
구독자 대비 조회율: {views_per_subscriber_rate}%
조회수 성장률: {view_growth_rate}%
VPH 중앙값: {median_vph}

팬 반응: {fan_response_grade} / {fan_response_score}점

조회수 변동성: {view_count_cv}

데이터 부족 상태: {insufficient_data_flags}
```

## 비교

| 구분 | 1안. 관점 통합 요약 | 2안. 간결 요약 |
| --- | --- | --- |
| 핵심 구조 | 하나의 문단 안에 협업 판단 + 성장 방향 포함 | 하나의 문단 3문장 이내 |
| 적합한 상황 | 양쪽 타깃을 고려하되 UI는 단순하게 유지할 때 | 현재 UI를 거의 바꾸지 않고 개선할 때 |
| 장점 | 관점 라벨 없이 자연스럽고, 양쪽 판단을 모두 담을 수 있음 | 짧고 적용이 쉬움 |
| 단점 | 문장 역할이 흐려지면 메시지가 산만해질 수 있음 | 관점이 섞일 수 있음 |
| 추천도 | 높음 | 중간 |

## 추천 방향

1안을 추천한다.

다만 화면에서는 "마케터 관점", "크리에이터 관점"처럼 라벨을 나누기보다 하나의 문단 안에서 자연스럽게 이어 쓰는 것이 좋다. 첫 문장에서는 채널 정체성을 설명하고, 중간 문장에서는 광고 협업 관점의 판단을, 마지막 문장에서는 크리에이터가 참고할 콘텐츠 방향이나 주의점을 제안하면 된다.

2안은 현재 UI 구조를 유지해야 하거나, 요약 영역을 아주 짧게 가져가야 할 때 대안으로 사용할 수 있다.
