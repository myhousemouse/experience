# GA4 기반 베타 운영 및 전환 개선

태그: #marketing #ga4 #meta-ads #conversion #product-analytics #growth

## 역할

데모데이 이후 인플레이스 베타 버전을 실제 사용자에게 공개하고, Meta 광고 유입과 GA4 데이터를 확인하며 랜딩에서 핵심 기능으로 이어지는 전환 흐름을 개선한 운영 경험이다.

## 운영 상황

- 데모데이 이후에도 서비스를 계속 운영
- 현재 베타 버전으로 사용자를 받고 있음
- Meta 광고를 집행하고 GA4로 유입, 페이지 조회, 참여 시간, 기능 페이지 진입을 확인
- 확인 범위: GA4 홈, 보고서 개요, 웹/앱 트래픽, 페이지 및 화면
- 외부 설정 변경 없이 조회와 탐색 중심으로 데이터를 확인

## GA4 주요 지표

지난 28일 기준:

- 활성 사용자: 187명
- 새 사용자: 176명
- 조회수: 3,898
- 이벤트: 4,807
- 주요 이벤트: 0.00으로 표시

해석:

- 유입과 조회는 발생하고 있으나, 회원가입, 검색 실행, 채널 분석 실행, 문의하기 클릭 등 핵심 행동이 전환 이벤트로 설정되지 않은 상태로 보인다.
- 단순 방문 수보다 `랜딩 -> 핵심 기능 진입 -> 회원가입` 흐름을 별도로 측정할 필요가 있다.

## 발견한 문제

### 1. 랜딩 체류 시간 부족

- `/` 페이지 조회수: 796
- 활성 사용자: 183명
- 평균 참여 시간: 19초

랜딩에 많은 사용자가 들어왔지만 체류 시간이 짧았다. 첫 화면에서 서비스가 무엇을 할 수 있는지, 어떤 기능으로 바로 들어가야 하는지가 충분히 빠르게 전달되지 않았을 가능성이 있다.

### 2. 기능 페이지 진입자는 깊게 탐색

- `/influencer`: 조회수 869, 활성 사용자 16명, 사용자당 조회수 54.31, 평균 참여 시간 2분 53초
- `/videos`: 평균 참여 시간 1분 24초
- `/channel`: 평균 참여 시간 1분 22초

기능 페이지에 진입한 사용자는 적지만, 진입 이후에는 여러 화면을 눌러보고 오래 머무르는 경향이 있었다. 제품 가치가 랜딩보다 실제 기능 화면 안에서 더 강하게 전달되는 구조로 해석했다.

### 3. 랜딩에서 기능 진입 전환이 낮음

- 랜딩 활성 사용자: 183명
- `/influencer` 활성 사용자: 16명

랜딩 방문자 대비 핵심 검색/탐색 페이지 진입이 낮았다. 랜딩에서 바로 `인플루언서 검색하기`, `내 채널 분석하기`로 이동하는 CTA를 더 명확하게 보여줄 필요가 있었다.

### 4. Meta paid 유입 비중이 큼

첫 사용자 소스 기준:

- `meta / paid`: 81
- `direct`: 69
- `iboss/community`: 10
- `google organic`: 4

현재는 자연 검색보다 Meta 광고와 외부 공유 의존도가 큰 상태였다.

### 5. Direct 세션 비중으로 추적이 흐려질 수 있음

세션 기준:

- `(direct) / (none)`: 135
- `meta / paid`: 85

direct가 크게 잡히면 실제 유입 출처를 놓칠 수 있으므로, Meta 광고, 인스타그램, 커뮤니티, 테스트 링크의 UTM 규칙을 통일할 필요가 있다.

### 6. 지역 데이터 확인

서울 활성 사용자가 가장 많았고, Suwon, Busan, Jeju 등이 일부 확인되었다. 국내 초기 타깃 테스트는 맞게 잡힌 편으로 보이나, Prineville, India, United States 등 일부 값은 실제 사용자, 봇, 프록시, 테스트 유입 여부를 추가 확인할 필요가 있다.

## 개선 액션

### 핵심 기능을 로그인 없이 일부 공개

문제:

- 랜딩 방문자는 있었지만 핵심 기능 페이지로 진입하는 사용자가 적었다.
- 기능 페이지에 들어온 사용자는 오래 탐색했기 때문에, 회원가입 이전에 제품 가치를 먼저 보여줄 필요가 있었다.

개선:

- 인플루언서 검색을 회원가입/로그인 없이도 볼 수 있도록 수정
- 경쟁 채널 분석에서도 디폴트 뷰를 로그인 없이 노출
- 사용자가 가입 전에 핵심 기능의 가치를 확인한 뒤 회원가입 여부를 판단할 수 있도록 진입 장벽을 낮춤

## 개선 이후 측정

랜딩 활성 사용자 183명 수준에서 확인한 결과:

- 핵심 기능 진입 사용자: 약 30~35명
- 회원가입 전환 인원: 약 7명

해석:

- 로그인 장벽을 낮춘 뒤 핵심 기능 진입 사용자가 기존 `/influencer` 활성 사용자 16명 대비 약 2배 수준으로 늘어났다.
- 회원가입 전에 기능 가치를 먼저 보여주는 방식이 초기 베타 단계의 전환 개선에 더 적합하다고 판단했다.

- UTM 규칙 통일
  - Meta 광고, 인스타그램, 커뮤니티, 테스트 링크 구분
  - direct로 뭉치는 유입을 줄이고 채널별 성과를 비교할 수 있게 정리

## 이력서/포트폴리오용 bullet

- 데모데이 이후 베타 서비스를 운영하며 GA4 홈, 보고서 개요, 웹/앱 트래픽, 페이지 및 화면 데이터를 확인하고 랜딩-기능 진입-회원가입 전환 흐름 분석
- 지난 28일 기준 활성 사용자 187명, 조회수 3,898, 이벤트 4,807 데이터를 바탕으로 핵심 전환 이벤트 미설정과 랜딩 CTA 약점을 도출
- 기능 페이지 진입자는 평균 1분 22초~2분 53초 머무르는 반면 랜딩 평균 참여 시간은 19초에 그친 점을 근거로 로그인 전 핵심 기능 일부 공개를 제안
- 인플루언서 검색과 경쟁 채널 디폴트 뷰를 로그인 없이 노출하도록 개선해 랜딩 183명 기준 핵심 기능 진입 사용자를 약 30~35명으로 확대하고 회원가입 약 7명 전환 확인
- Meta paid, direct, 커뮤니티, organic 유입을 비교하고 UTM 규칙 통일 및 GA4 주요 이벤트 설정 필요성을 정리

## 면접용 설명

데모데이 이후 인플레이스를 베타로 운영하면서 GA4와 Meta 광고 유입 데이터를 확인했습니다. 단순히 유입이 늘었는지보다 사용자가 랜딩에서 핵심 기능으로 넘어가는지를 보려고 했습니다. 지난 28일 기준 활성 사용자 187명, 조회수 3,898, 이벤트 4,807이 있었지만 주요 이벤트가 0으로 잡혀 있어 전환 측정 체계가 비어 있다는 점을 먼저 확인했습니다. 또 랜딩은 183명이 봤지만 평균 참여 시간이 19초로 짧았고, 반대로 기능 페이지에 들어온 사용자는 1분 이상 머무르는 패턴이 보였습니다. 그래서 제품 가치를 회원가입 이후에만 보여주는 구조보다, 인플루언서 검색과 경쟁 채널 디폴트 뷰를 로그인 없이 일부 공개하는 방식이 맞다고 판단했습니다. 이후 핵심 기능 진입 사용자는 약 30~35명, 회원가입은 약 7명으로 확인되어 초기 베타 단계에서는 진입 장벽을 낮추고 GA4 이벤트를 명확히 잡는 것이 중요하다는 결론을 얻었습니다.
