# 인스타그램 운영

태그: #marketing #instagram #content

## 역할

인플레이스 프로젝트 후반에 진행한 공식 인스타그램 콘텐츠 운영 기록이다. 서비스 출시 이후 사용자에게 닿기 위한 마케팅 실험과 콘텐츠 기획 경험으로 연결된다.

데모데이 이후에는 인스타그램 콘텐츠 운영을 넘어 Meta 광고와 GA4 데이터를 함께 확인하며 베타 서비스의 실제 유입과 전환 흐름을 점검했다.

## 운영 방향

- 실무자가 저장하고 공유할 수 있는 카드뉴스
- 마케터, 크리에이터, 콘텐츠 기획자, PM에게 유용한 데이터/트렌드 인사이트
- AI, 유튜브 트렌드, 밈 마케팅 등 콘텐츠 실무 소재 활용
- 추후 인플레이스 내부 데이터와 채널 데이터를 활용한 특화 인사이트 발행

## Meta 광고 및 GA4 운영 인사이트

- 베타 버전으로 사용자를 받으며 Meta 광고 유입을 확인
- GA4 홈, 보고서 개요, 웹/앱 트래픽, 페이지 및 화면 데이터를 조회해 랜딩-기능 진입 흐름 분석
- 지난 28일 기준 활성 사용자 187명, 새 사용자 176명, 조회수 3,898, 이벤트 4,807 확인
- 주요 이벤트가 0으로 잡혀 있어 `sign_up`, `search_influencer`, `analyze_channel`, `view_influencer_detail` 등 전환 이벤트 설정 필요성 도출
- 랜딩 평균 참여 시간 19초 대비 기능 페이지 평균 참여 시간이 1분 이상으로 나타나, 회원가입 전 기능 가치 노출 필요성을 확인
- 인플루언서 검색과 경쟁 채널 디폴트 뷰를 로그인 없이 노출하도록 개선
- 랜딩 활성 사용자 183명 수준에서 핵심 기능 진입 사용자 약 30~35명, 회원가입 전환 약 7명 확인
