# UT 결과 시각화 요약

원본: https://app.notion.com/p/3823eee3a70481eeaf02fa5627c19dbb
태그: #research #ut #visualization

## 역할

UT 결과를 시각적으로 요약한 자료다. 루트 페이지와 UT 기록에서 연결된 후속 분석 문서로 사용한다.

## 한눈에 보는 결론

- 가장 큰 문제: 지표, 용어, 배지, 임팩트 지표에 대한 이해 장벽
- 두 번째 문제: 검색과 필터 사용 후 결과가 어디에 나오는지 불명확함
- 세 번째 문제: 데이터 부족, 빈 화면, 로그인 풀림 등 안정성 이슈
- 긍정 반응: AI 요약, 그래프/시각화, 평균 대비 증감량, 경쟁 채널 분석 플로우
- 핵심 개선 방향: 설명을 늘리는 것이 아니라, 화면 안에서 바로 이해되는 도움말, 상태 표시, 결과 안내를 강화해야 함

## 우선순위

### P0

- 용어/지표 설명 부족
- 검색 결과 위치와 상태 불명확
- 데이터 부족/빈 화면 처리

### P1

- 사이드바/내비게이션 인지 약함
- AI 요약 전략성 부족
- 로그인/토큰 안정성

### P2

- 요금제 접근성/가격 인식
- 브랜드 협업 이력 모아보기

## 개선 로드맵

1. 사용자가 기능을 오류로 오해하지 않게 하기: 빈 상태 메시지, 데이터 부족 안내, 검색 결과 위치 표시, 토큰 안정화
2. 지표를 이해하게 하기: 툴팁, 용어 정의, 산출 기준, 배지/임팩트 지표 명칭 통일
3. 기능 가치를 체감하게 하기: AI 요약 확장, 전략 제안 강화, 평균 대비 증감량 강조
4. 마케터 니즈 보강: 브랜드/PPL 이력 모아보기, 협업 이력 데이터셋
