# API 기능 구현

태그: #api #springboot #backend

## 구현 기능 범위

기능 명세서와 API 명세서의 `작성자` 필드에 `남은지`가 포함되어 있다. 따라서 단순 팀 백엔드 범위가 아니라, 기능/API 명세 작성 및 구현 논의에 직접 참여한 근거가 있는 항목으로 정리한다.

- 회원가입/로그인
- 경기대 이메일 인증
- 포인트 활동 목록 조회
- 포인트 활동 검색
- 포인트 활동 정렬
- 포인트 활동 상세 조회
- 맞춤형 포인트 추천
- 추천 채용 공고 목록 조회
- 추천 채용 공고 검색
- 추천 채용 공고 정렬
- 추천 채용 공고 상세 조회
- 포인트 활동/채용 공고 북마크
- 마이페이지 사용자 정보

## 주요 서비스 로직

### PointActivityService

- 포인트 활동 목록 조회
- 검색어 기반 활동 검색
- 마감일, 포인트, 소요 시간 기준 정렬
- 활동 상세 조회
- 잘못된 정렬 조건에 대한 예외 처리

### PointRecommendService

- 사용자의 관심 카테고리, 남은 포인트, 졸업까지 남은 기간을 입력으로 받는다.
- A코스는 진로 연계성과 관심 분야를 우선한다.
- B코스는 시간 대비 포인트 효율을 우선한다.

### RecruitService

- 교내 추천 채용 공고 목록 조회
- 검색
- 최신순/마감순 정렬
- 공고 상세 조회
