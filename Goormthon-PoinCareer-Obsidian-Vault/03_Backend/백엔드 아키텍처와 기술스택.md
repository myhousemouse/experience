# 백엔드 아키텍처와 기술스택

태그: #backend #architecture #springboot

## 기술스택

- Java 17
- Spring Boot
- MySQL
- Redis
- AWS EC2
- Docker, Docker Compose
- GitHub Actions
- Swagger
- GitHub Flow

코드 기준 서비스 DB는 MySQL이다. `application.yml`에서 MySQL URL, MySQL JDBC driver, MySQL8Dialect를 사용하고, `build.gradle`에도 MySQL connector 의존성이 있다. `docker-compose.yml`에는 Redis 컨테이너만 있으므로, 컨테이너 설정은 Redis용으로 정리한다.

## 구조

도메인 기반으로 controller, service, dao/repository, dto를 분리하는 구조를 사용했다.

- Controller: 요청 수신, 응답 반환
- Service: 비즈니스 로직
- Repository/DAO: 데이터 접근
- DTO: 요청/응답 데이터 전달
- Entity: DB 테이블과 매핑

## 공통 처리

- BaseResponse, BaseException 기반 공통 응답/예외 처리 구조를 계획했다.
- GlobalExceptionHandler를 통해 예외 응답을 일관화하는 방향이 논의되었다.
- Swagger로 API 명세를 공유해 프론트엔드와 연동 기준을 맞췄다.

## 의미

이 경험은 백엔드 입장에서 `학습용 CRUD`를 넘어, 실제 팀 프로젝트에서 기능 명세, API 계약, 데이터 모델링, 배포까지 연결한 경험으로 정리할 수 있다.
