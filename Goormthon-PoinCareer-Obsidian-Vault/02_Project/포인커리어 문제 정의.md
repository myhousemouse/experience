# 포인커리어 문제 정의

태그: #problem-definition #product

## 사용자 문제

경기대학교 재학생은 비교과 포인트를 졸업 요건에 맞춰 관리해야 하지만, 어떤 활동을 선택해야 하는지 판단하기 어렵다.

주요 문제는 다음과 같다.

- 졸업 직전에 포인트 부족을 인지하는 경우가 있다.
- 활동별 획득 포인트, 소요 시간, 마감일, 참여 방식이 흩어져 있다.
- 단순히 포인트를 채우는 것과 진로에 도움 되는 활동을 고르는 것 사이에서 판단 기준이 부족하다.
- 학교 추천 채용 공고 접근성이 낮아 취업 정보 탐색이 분리되어 있다.

## 제품 방향

포인커리어는 비교과 포인트 활동과 추천 채용 공고를 한 앱에서 관리하도록 설계되었다.

- 남은 포인트와 졸업까지 남은 기간을 기준으로 포인트 활동을 추천한다.
- 관심 분야와 진로 연관성을 반영해 A코스 추천을 제공한다.
- 시간 효율과 포인트 충족을 기준으로 B코스 추천을 제공한다.
- 교내 추천 채용 공고를 검색, 필터, 상세 조회, 북마크할 수 있게 한다.

## 기능 범위

- 회원가입/로그인
- 경기대 이메일 인증
- 포인트 활동 목록, 검색, 정렬, 상세 조회
- 맞춤형 포인트 추천 A/B 코스
- 추천 채용 공고 목록, 검색, 정렬, 상세 조회
- 포인트 활동/채용 공고 북마크
- 마이페이지와 사용자 정보 관리

## 백엔드 관점의 핵심

이 프로젝트는 단순 CRUD보다 `추천을 위한 데이터 구조`와 `프론트엔드가 바로 사용할 수 있는 API 계약`이 중요했다. 따라서 [[ERD와 데이터 모델링]], [[추천 로직과 태그 설계]], [[프론트 연동과 문서화]]가 핵심 축이다.
