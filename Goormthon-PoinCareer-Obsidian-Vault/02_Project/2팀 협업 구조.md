# 2팀 협업 구조

태그: #collaboration #team2

## 범위

포인커리어 협업 페이지에는 1팀과 2팀이 함께 존재하지만, 이 vault는 사용자가 참여한 `2팀`만 기준으로 정리한다.

## 2팀 구성

- PM: 엄윤아, 정민재
- Design: 홍명훈
- Frontend: 이윤지
- Backend: 김혜빈, 정수영, 남은지

## 협업 자료 구조

- 회의 및 일정
- 작업 현황
- 기획
- 백엔드
- 디자인
- 프론트

## 백엔드 협업 자료

백엔드 페이지에는 GitHub, ERDCloud, Figma UX/UI, Swagger, 기능 명세서, API 명세서, ERD, 개발 일정이 연결되어 있었다.

이 구조는 백엔드가 단독으로 구현하는 방식이 아니라, 기획/디자인/프론트와 기능 단위로 계약을 맞추며 진행한 협업 프로젝트였다는 근거가 된다.
