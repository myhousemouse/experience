# 프론트 연동과 문서화

태그: #collaboration #swagger #frontend

## 협업 방식

백엔드는 기능 명세서, API 명세서, Swagger, GitHub Issue를 기준으로 프론트엔드와 연동했다.

## 주요 조율 지점

- Figma 화면과 기획 기능 범위가 맞지 않는 부분을 확인했다.
- UI 담당자와 1:1로 기능 흐름을 맞췄다.
- Notion 기능 명세서와 GitHub Issue를 기준으로 구현 범위를 추적했다.
- Swagger를 통해 요청/응답 형식을 공유했다.
- Mock API와 PR 체크리스트를 통해 연동 누락을 줄였다.

## API 연동 이슈

프론트엔드와 API를 연결하는 과정에서 토큰 전달 방식에 대한 차이가 있었다.

- 문제: 토큰을 query parameter로 줄지, header로 줄지 기준이 달랐다.
- 해결: 인증 토큰은 header 기준으로 맞추고, 백엔드에서는 `@RequestHeader`를 사용하는 방향으로 조율했다.
- 함께 고려한 것: CORS, 인증 헤더, Swagger 명세

## 면접 포인트

이 경험은 백엔드가 단순히 서버 로직만 작성한 것이 아니라, 프론트엔드가 실제로 붙을 수 있는 API 계약을 만들고 조율했다는 근거가 된다.
