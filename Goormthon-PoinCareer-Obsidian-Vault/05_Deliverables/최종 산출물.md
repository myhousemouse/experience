## 화면 녹화 플로우 PDF

로컬 경로: `/Users/nam-eunji/Downloads/화면녹화_플로우_0623.pdf`

PDF는 3페이지이며, 시연 플로우가 정리되어 있다.

최종 시연 당시 기능은 전부 동작 가능한 상태였다. 실제 학교 데이터는 학교 측과 협의가 필요해 확보가 어려웠기 때문에, 시연에 필요한 전체 더미데이터를 직접 만들고 SQL로 입력했다.

### KGU 포인트 플로우

1. 앱 시작 화면
2. `나만의 맞춤 포인트 플랜` 클릭
3. 정보 입력: 남은 포인트, 기간, 관심 분야
4. 맞춤 경로 페이지 등장
5. A코스 확인
6. B코스 확인
7. 직무 클래스 상세 조회
8. 북마크
9. 신청하기

### 교내 추천 채용 플로우

1. `경기대 전용 추천채용 정보` 클릭
2. 맞춤형 정보 입력: IT, 신입
3. 토스 공고 클릭
4. 공고 스크랩
5. 지원하기
