## 정리 기준

- 원본 자료는 Notion, Figma, PDF, GitHub, Swagger에 유지한다.
- 로컬 vault에는 원본 파일을 복사하지 않고, 취업/면접에서 바로 쓸 수 있는 맥락과 관계를 정리한다.
- 포인커리어 협업 페이지는 `2팀` 기준으로만 정리한다.
- 역할은 `백엔드` 중심으로 정리하되, 아직 본인 직접 구현 API 범위가 확인되지 않은 항목은 팀 백엔드 범위로 표시한다.

## 확정된 경험 정보
