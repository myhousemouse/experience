# 백엔드 스터디 커리큘럼

태그: #study #backend #springboot

## 개요

구름톤유니브 활동 초반 약 3개월 동안 각 파트별 스터디가 진행되었고, 백엔드 파트는 Spring Boot 기반 웹 백엔드 개발 흐름을 주차별로 학습했다. 이 학습은 이후 포인커리어 백엔드 구현의 기반이 되었다.

## 주차별 학습 흐름

- 4/8: 프로젝트 구조와 아키텍처
  - MVC 패턴, Controller-Service-Repository 구조, DTO, DI, 패키지 구조
- 4/15: REST API
  - API 개념, REST 원칙, HTTP 메서드, 요청/응답 구조
- 4/29: 데이터베이스
  - JPA, Hibernate, Entity, Repository, MySQL/H2, CRUD
- 5/6: Service 계층과 비즈니스 로직
  - 서비스 책임, DTO-Entity 변환, 로직 분리
- 5/13: 인증/보안
  - 인증과 인가, JWT, 로그인 흐름 설계
- 5/20: 예외 처리와 검증
  - validation, 예외 응답, 공통 응답 구조
- 5/27: Swagger, API 문서화, 테스트
- 6/3: DB 관계 설계
  - JPA 1:1, 1:N, N:M, 연관관계 주인, 양방향/단방향
- 6/17: 배포와 프로젝트 적용
- 6/24: 개선과 Best Practice

## 프로젝트 적용

- MVC 계층 구조 학습은 [[백엔드 아키텍처와 기술스택]]으로 이어졌다.
- REST API와 Swagger 학습은 [[API 기능 구현]]과 [[프론트 연동과 문서화]]에 적용되었다.
- JPA 관계 학습은 [[ERD와 데이터 모델링]]과 [[추천 로직과 태그 설계]]에 직접 연결되었다.
- 배포 학습은 [[배포와 CI-CD]] 경험으로 이어졌다.
