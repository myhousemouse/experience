# 관계 타입 규칙

태그: #ontology #relationship-rule

## 관계 타입

- `source-of-truth`: 원본 Notion, Figma, PDF, GitHub, Swagger 등 기준 자료
- `prepared-for`: 스터디나 사전학습이 프로젝트 구현으로 이어짐
- `defines`: 문제 정의 또는 요구사항이 기능 구현을 규정함
- `implemented-by`: 기능이 특정 백엔드 구조/API/로직으로 구현됨
- `supports`: 데이터 모델, 태그, 아키텍처가 기능을 뒷받침함
- `collaborates-with`: FE, PM, Design 등 타 파트와의 협업 관계
- `resolved-by`: 문제 상황이 특정 의사결정이나 구현으로 해결됨
- `delivers`: 구현 결과가 최종 산출물/시연/배포로 이어짐
- `interview-evidence`: 면접에서 사용할 수 있는 근거
- `needs-context`: 본인 직접 기여 범위 확인이 필요한 지점
