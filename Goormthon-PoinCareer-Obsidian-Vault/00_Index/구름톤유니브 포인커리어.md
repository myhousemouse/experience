# 구름톤유니브 포인커리어

태그: #project #goormthon #backend #springboot #pointcareer

## 한 줄 요약

구름톤유니브 경기대 활동에서 약 3개월간 백엔드 스터디를 진행한 뒤, 2팀 백엔드로 `포인커리어`를 개발했다. 포인커리어는 경기대학교 재학생의 비교과 포인트 활동과 교내 추천 채용 정보를 통합 관리하는 모바일 앱이다.

## 프로젝트 맥락

- 활동: 구름톤유니브 경기대
- 프로젝트명: 포인커리어(PointCareer)
- 기간: 2025년 5월~6월
- 팀 구성: 기획 2명, 디자인 1명, FE 1명, BE 3명
- 본인 역할: 2팀 백엔드
- 최종 맥락: 연합 데모데이 `뭉실톤` 발표 및 시연

## 핵심 문제

경기대학교 재학생은 비교과 포인트를 졸업 요건과 연결해 관리해야 하지만, 활동 선택 기준과 남은 포인트, 시간 자원, 진로 연관성을 한 번에 판단하기 어렵다. 또한 학교 추천 채용 공고 접근성이 낮아, 포인트 활동과 취업 준비 정보를 별도로 탐색해야 하는 문제가 있었다.

## 핵심 해결 방향

- 개인의 남은 포인트, 관심 분야, 졸업까지 남은 기간을 기준으로 비교과 활동을 추천한다.
- A코스는 진로 연계 활동, B코스는 시간 효율 중심 활동으로 나누어 제안한다.
- 교내 추천 채용 공고를 탐색, 검색, 필터링하고 북마크할 수 있게 한다.
- 포인트 활동과 추천 채용 공고를 카테고리/태그 기반으로 구조화해 추천과 필터링에 활용한다.

## 주의할 점

현재 정리된 자료는 팀 백엔드 전체 범위가 섞여 있다. 이력서나 면접에서는 `본인이 직접 구현한 API`, `본인이 직접 해결한 배포/연동 이슈`, `본인이 작성한 명세 범위`를 추가로 분리하면 더 정확하다.

## 사용자 제공 지원서 상세

출처: [[지원서 경험 상세 업데이트]]; 최신 사용자 설명.
기간: 구름톤유니브 전체 활동: 2025.03.29 ~ 2025.09.06; 개별 프로젝트 기간과 구분

구름톤유니브 백엔드 파트로 활동하며 Java·Spring Boot 스터디와 팀 프로젝트, 해커톤을 통해 백엔드 개발 경험을 쌓음.

- 비교과 포인트·교내 추천 채용 정보 서비스 ‘포인커리어’ 개발
- 채용 공고 목록·정렬·검색·상세 조회 API, 마이페이지 프로필·북마크 조회 및 프로필 수정 API 구현
- 카테고리·엔티티 구조 정리 및 Dockerfile 작성
- 단풍톤에서 이동 도서관 서비스 ‘꿈마중 버스’ 백엔드 개발
- 버스 신청·신청 현황 집계·정류장 및 운행 정보 API와 산출 로직 구현

활용 기술·도구: Java, Spring Boot, MySQL, AWS EC2. 원문의 ‘Jave’는 ‘Java’로 표기 정정.
AWS EC2는 활동 전체 도구 목록이며 각 프로젝트의 배포를 입증하지 않는다. 꿈마중 버스의 기존 기록상 프론트 연동 시연 미완료·배포 링크 없음은 그대로 유지한다.

## 추가 자소서 활동 기록 — PC-01

출처: [[CJ 자소서 원문]] 2번 직무역량 두 번째 경험.

- 문제: 기획을 실제로 구현하는 시스템 구조를 이해하기 위해 구름톤 백엔드 파트에 도전했다.
- 수행: 한 학기 Java·Spring Boot를 학습하고 사용자·포인트 활동·채용공고·카테고리 ERD를 설계했다. 채용공고 조회·검색·마이페이지 관련 API를 구현하고 Swagger 기준 요청·응답을 프론트와 조율했다.
- 결과 기록: 원문은 API 6개 구현을 기록한다. 기존 사용자 제공 상세 API 목록과 연결해 백엔드 경험으로 활용한다.
- 범위·확인 사항: 6개는 초안의 묶음 기준으로, 목록·정렬·검색·상세 등을 모두 각각 세면 달라질 수 있다. 개인 구현 목록과 계수 정의 확인 전 개수를 추가로 늘리지 않는다. DB 전체와 배포를 단독 담당했다고 확대하지 않는다.
