## 에피소드 상세

### PC-01 · 백엔드 학습을 ERD·API와 프론트 협업으로 연결

**이 에피소드가 잘 맞는 질문:** 시스템 이해 / 백엔드 구현 / 기획·개발 연결 / 개발 협업

- 상황·문제: 기획을 실제로 구현하는 시스템 구조를 이해하기 위해 구름톤 백엔드 파트에 도전했다.
- 내가 한 행동: 한 학기 Java·Spring Boot를 학습하고 사용자·포인트 활동·채용공고·카테고리 ERD를 설계했다. 채용공고 조회·검색·마이페이지 관련 API를 구현하고 Swagger 기준 요청·응답을 프론트와 조율했다.
- 결과·배운 점: 원문은 API 6개 구현을 기록한다. 기존 사용자 제공 상세 API 목록과 연결해 백엔드 경험으로 활용한다.

**재사용할 때 강조할 관점:** 질문의 핵심에 맞춰 위 행동과 판단을 골라 쓴다.

**이미 활용한 문항:** CJ 자소서 2번 직무역량 두 번째 경험

**원문 위치:** [[CJ 자소서 원문]] 2번 직무역량 두 번째 경험

**표현·근거 메모:** 6개는 초안의 묶음 기준으로, 목록·정렬·검색·상세 등을 모두 각각 세면 달라질 수 있다. 개인 구현 목록과 계수 정의 확인 전 개수를 추가로 늘리지 않는다. DB 전체와 배포를 단독 담당했다고 확대하지 않는다.
