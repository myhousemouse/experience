# 면접용 포인트

태그: #interview #resume #backend

## 핵심 포지셔닝

포인커리어는 백엔드 개발 경험으로 강하게 사용할 수 있다. 단순히 기획 산출물을 만든 프로젝트가 아니라, Spring Boot 기반 API 구현, ERD 설계, Swagger 문서화, 프론트 연동, Docker/EC2 배포까지 이어진 프로젝트이기 때문이다.

## 30초 요약

구름톤유니브 경기대 2팀에서 백엔드로 참여해, 경기대학교 재학생의 비교과 포인트 활동과 교내 추천 채용 정보를 통합 관리하는 모바일 앱 `포인커리어`를 개발했습니다. Java 17, Spring Boot, MySQL 기반으로 기능 명세와 API 명세 작성에 참여했고, ERD는 팀원 1명과 함께 약 50% 기여했습니다. GitHub 코드 기준으로는 교내 추천 채용 목록/정렬/검색/상세 API와 마이페이지 프로필/북마크 조회, 프로필 수정 기능 구현 근거가 확인됩니다. 최종 시연은 전 기능이 동작 가능한 상태였고, 실제 학교 데이터 확보가 어려워 전체 더미데이터를 직접 구성해 SQL로 입력했습니다.

## 이력서 문장 초안

- Java 17, Spring Boot, MySQL 기반으로 경기대 비교과 포인트/추천 채용 통합 앱 `포인커리어` 백엔드 개발에 참여
- 기능 명세서와 API 명세서 작성에 참여해 기능 정의, 엔드포인트, 요청/응답 구조를 백엔드 관점에서 정리
- ERD 설계에 약 50% 기여하며 포인트 활동, 채용 공고, 사용자 관심사를 N:M 카테고리 구조로 설계해 추천과 필터링 기능의 확장성을 확보
- 교내 추천 채용 목록/정렬/검색/상세 조회 API와 마이페이지 프로필/북마크 조회, 프로필 수정 API 구현에 참여
- Swagger 기반 API 명세와 GitHub Issue를 활용해 Flutter 프론트엔드와 요청/응답, 인증 헤더, CORS 기준을 조율
- Dockerfile과 env를 작성하고 Docker 실행 환경을 세팅해 팀에 전달하며 배포 과정을 보조
- 학교 실제 데이터 확보가 어려운 상황에서 전체 더미데이터를 직접 구성하고 SQL로 입력해 전 기능 시연 가능 상태를 지원

## STAR 구조

### Situation

경기대학교 재학생은 졸업을 위해 비교과 포인트를 관리해야 하지만, 활동 선택 기준과 남은 포인트, 진로 연관성, 시간 효율을 함께 판단하기 어려웠다. 학교 추천 채용 공고도 별도로 흩어져 있어 정보 접근성이 낮았다.

### Task

백엔드 파트는 포인트 활동, 맞춤 추천, 추천 채용, 북마크, 마이페이지 기능을 API로 제공하고, 추천과 필터링이 가능한 데이터 구조를 설계해야 했다.

### Action

Spring Boot 기반 도메인 구조를 이해하고, 기능 명세서와 API 명세서 작성에 참여했다. ERD는 팀원 1명과 함께 약 50% 담당하며 User, Point, Recruit, Category, Bookmark 관련 Entity와 관계를 구성했다. 코드 기준으로는 Recruit/Mypage 도메인에서 Controller-Service-Repository-DTO 흐름을 구성하고, 채용 공고 목록/정렬/검색/상세 조회와 마이페이지 프로필/북마크 조회, 프로필 수정 API 구현에 참여했다. Swagger와 API 명세를 기준으로 프론트와 연동했고, Dockerfile과 env를 작성한 뒤 Docker 실행 환경을 세팅해 팀에 전달했다. 실제 학교 데이터 확보가 어려워 전체 더미데이터를 직접 구성하고 SQL로 입력해 최종 시연에서 전 기능이 동작 가능하도록 지원했다.

### Result

포인트 활동 추천, 교내 추천 채용, 북마크, 상세 조회, 마이페이지 기능을 포함한 백엔드가 데모데이에서 전부 동작 가능한 상태로 연결되었다. 이 과정에서 개발-문서화-연동-데이터 구성-배포 보조까지 이어지는 백엔드 협업 흐름을 경험했다.

## 직무별 어필 방향

### 백엔드

- Spring Boot API 구현
- JPA 관계 설계
- N:M 태그/카테고리 구조
- Recruit/Mypage 도메인 구현
- 기능 명세/API 명세 작성
- Swagger 문서화
- Docker 실행 세팅 및 배포 보조
- 전체 시연용 더미데이터 구성

### PM/서비스 기획

- 사용자 문제를 기능 요구사항과 데이터 구조로 연결한 경험
- 추천 로직의 기준을 A/B 코스로 나누어 정의한 경험
- 디자인/프론트/백엔드 간 기능 기준을 맞춘 경험

### AX/자동화

- 사용자의 상태 데이터를 바탕으로 개인화 추천을 제공한 경험
- 태그와 사용자 관심사를 구조화해 향후 추천/분석 확장이 가능하도록 만든 경험
