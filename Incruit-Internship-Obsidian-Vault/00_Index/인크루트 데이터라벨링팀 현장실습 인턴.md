## 한 줄 요약

인크루트 데이터라벨링팀에서 자율주행 TSR/TLR 이미지 데이터를 검수하고, 공고 재검수 업무를 수행하며 AI 학습 데이터 품질과 실무 커뮤니케이션 방식을 배운 현장실습 인턴 경험.

## 실습 개요

- 기업: 인크루트
- 부서: 데이터라벨링팀
- 직무: 데이터라벨러
- 기간: 2025.01.02 ~ 2025.02.28
- 주요 업무: TSR/TLR 데이터 라벨링 및 정교화, 공고 재검수
- 도구: 이미지 분류 툴, 인크루트 내부 ERP, Google 스프레드시트, Slack

## 핵심 업무

### TSR/TLR 데이터 라벨링

STRAD사의 외주 프로젝트에서 베트남 외주사가 1차 작업한 자율주행 이미지 데이터를 검수하고 정교화했다. 교통 표지판(TSR)과 신호등(TLR)을 중심으로 약 3,000장 이상의 이미지 데이터를 처리했다.

자세한 내용은 [[TSR TLR 데이터 라벨링]] 참고.

### 공고 재검수 프로젝트

인크루트 내부 ERP를 활용해 자동 게시된 기업 공고의 거절/수정 여부와 공고 정보의 정확성을 재점검했다. 해당 업무는 2월 이후 경영지원팀으로 이관되었다.

자세한 내용은 [[공고 재검수 프로젝트]] 참고.

## 핵심 문제 해결

- 국가별 신호등/표지판 심볼 차이로 인한 라벨링 기준 모호성 해결
- 애매한 케이스를 수집해 외주사/베트남팀과 주기적으로 기준 합의
- 많은 데이터 이동으로 인한 파일 혼선을 줄이기 위해 폴더 정리 체계 공유
- 실무 커뮤니케이션 방식, Slack 사용, 질문 방식, 회사 내 예절 학습

## 이 경험의 의미

이 경험은 단순 데이터 라벨링 작업이라기보다, AI 학습 데이터 품질을 높이기 위해 모호한 판단 기준을 정리하고, 클라이언트사와의 기준 싱크를 맞추며 반복 업무의 운영 기준을 정리한 실무 경험으로 보는 것이 좋다.

특히 PM/ERP 관점에서는 `요구사항/기준 불일치 발견 -> 대안 제시 -> 클라이언트와 기준 합의 -> 내부 ERP와 검수 프로세스 경험`으로 연결할 수 있다.
