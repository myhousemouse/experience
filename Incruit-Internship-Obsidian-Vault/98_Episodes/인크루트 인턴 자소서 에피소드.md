## 2026-10-14 최신 확인 — 새 자소서 작성 시 우선 적용

출처: SK브로드밴드 자소서 작성 대화의 사용자 설명·정정. 개인 진술이며 독립 인증 아님. 아래 내용과 기존 본문이 다르면 아래 최신 범위를 적용한다.

- 기존 사용자 기록 기준 데이터라벨링팀 현장실습 인턴, 2025.01.02~02.28. TSR/TLR 이미지 3,000장 이상 라벨링·검수, 외주 데이터 점검.
- 국가별 심볼·객체 가림 사례를 정리하고 매뉴얼·팀·외주사 기준을 조율했다. 폴더별 정리 방식을 만들어 동기와 공유했다.
- ERP 채용 공고 중복·신입/경력·수정/거절 여부 재검수, Google 스프레드시트 기록.
- 수량은 처리 범위이며 정확도 개선율·재작업 감소 실측값 없음. 기존 문서의 일반적인 개선 결과는 측정 성과로 확대하지 않는다.

재사용 업무 요약: AI 데이터 품질·기준 정리·운영 데이터 검수·기록 관리.

## 에피소드 상세

### IC-01 · 모호한 이미지 판정을 팀의 기준으로 만들다

**이 에피소드가 잘 맞는 질문:** 문제 구조화 / 꼼꼼함 / 데이터 품질 / 기준 합의 / 강점

- 상황·문제: 3,000장 이상 자율주행 이미지 검수 중 국가별 신호등·표지판 형태와 가림 때문에 판정이 모호했다.
- 내가 한 행동: 모호한 사례를 유형화하고 객체 가시 비율 등의 대안을 제시했다. 팀·외주사와 논의해 라벨링 분류 기준을 보완했다.
- 결과·배운 점: 개별 판단 문제를 공유 가능한 기준으로 정리했다. 정량 정확도 개선은 제시되지 않았다.

**재사용할 때 강조할 관점:** 국가별 형태 차이 또는 가림 중 대표 사례 한 가지를 골라 기준과 대안을 설명한다.

**이미 활용한 문항:** 두산 DDI 장점

**원문 위치:** [[자소서 정리 원문]] 125–127행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 3,000장은 처리·검수 규모. 오류율·모델 정확도 향상은 별도 근거 없이 사용하지 않는다.

### IC-02 · 잦은 질문을 사례 묶음과 정기 논의로 바꾸다

**이 에피소드가 잘 맞는 질문:** 단점 보완 / 자기 인식 / 업무 방식 개선 / 소통 효율

- 상황·문제: 정확성을 중시해 사례마다 질문하며 작업 흐름을 끊는 문제가 있었다.
- 내가 한 행동: 유사 사례·자신의 판단·쟁점을 묶어 격일 스크럼에서 논의하고 결정 사항을 지침으로 남겼다.
- 결과·배운 점: 질문 방식을 바꿔 정확성을 지키면서 협업 흐름을 고려하는 습관을 만들었다.

**재사용할 때 강조할 관점:** 단점을 그럴듯한 장점으로 돌리지 않고 실제 문제와 바꾼 행동을 연결한다. 긴급도에 따라 질문을 분리한다는 입사 후 계획은 향후 적용으로 구분한다.

**이미 활용한 문항:** 두산 DDI 단점·보완

**원문 위치:** [[자소서 정리 원문]] 125–127행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 질문 감소율·처리 속도 향상은 기록되지 않았다. IC-01과 같은 검수 업무의 별도 행동 관점이다.
