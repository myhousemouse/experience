## 보고서에서 확인된 역할

남은지는 총무 팀장으로 참여했다. 킥오프 미팅 전 고객사의 산업과 업무 특성을 사전 조사했고, 보고서 방향에 대한 의견을 제시하며 팀 의사결정에 기여했다.

또한 팀원별 강점을 고려해 역할을 나누는 방식을 제안했고, 팀 내에서 유연하게 협업할 수 있는 분위기를 만드는 역할을 했다.

## 개발/DB 관련 기여

- SQLite 기반으로 기본 CRUD SQL을 전반적으로 작성
- 고객사 요구사항을 물리적 설계에 반영
- SQL을 활용해 요구사항이 실제 데이터 구조로 이어지도록 기여
- 프로젝트 산출물의 물리적 설계 파트에 직접적으로 관여
- 업무 프로세스를 데이터베이스 테이블과 조회 흐름으로 연결하는 데 기여

## 테이블 설계 과정

테이블은 팀원 전체가 모여 수기로 그리며 관계를 설정했다. 각 테이블 사이의 1:N, N:M 관계와 필수/선택 관계를 검토했고, 제약조건을 손으로 표시하며 업무 규칙이 데이터 구조에 맞게 반영되는지 확인했다.

최종 결과물은 실제 DB 스키마, 데이터 열 구성, 그리고 이를 고려한 와이어프레임 형태였다.

## 현재까지 확인된 강점

- 요구사항을 기술 구조로 옮기는 이해도
- 팀원의 강점을 보고 역할을 나누는 협업 운영 능력
- 실제 회사 맥락을 보고 데이터 구조로 정리하는 사고
- SQLite와 CRUD SQL을 실제 업무 문제에 적용한 개발 관련 경험
