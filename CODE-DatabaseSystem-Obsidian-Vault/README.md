## 정리 기준

- 원본 자료는 Notion에 유지한다.
- 로컬 vault에는 원본 파일을 복사하지 않고, 취업/면접에서 바로 쓸 수 있는 맥락과 관계를 정리한다.
- 최종보고서는 이미지 기반 PDF라 텍스트 추출이 어려워, 주요 페이지를 확인해 핵심 내용만 요약했다.
