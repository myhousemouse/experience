## 팀 구조

최종보고서 기준 팀원은 4명이며, 각자 역할을 나누어 진행했다.

- 대표: 김혜민
- 기획 팀장: 나병수
- 총무 팀장: 남은지
- 인사 팀장: 최주은

## 협업 방식

보고서에는 킥오프 미팅, 회의록, DML 표, 수집 자료 등이 부록으로 정리되어 있다. 프로젝트는 고객사 문제를 파악하고, 요구사항을 정리한 뒤, DB 설계와 응용 시스템 설계로 이어지는 방식으로 진행된 것으로 보인다.

실제 회사 대표님과 2-3회 대면미팅을 진행했고, 자료 제공과 서면 의견을 받았다.

## 남은지의 협업 기여

- 고객사 산업/업무 특성 사전 조사
- 보고서 방향성에 대한 의견 제시
- 팀원별 강점을 고려한 역할 분배 제안
- 유연한 협업 분위기 형성
- SQLite 기반 CRUD SQL 작성
- 물리적 설계와 SQL 파트 기여

## 취업용으로 해석할 때

이 경험은 혼자 구현한 개발 프로젝트라기보다, 실제 요구사항이 있는 팀 프로젝트에서 문제를 구조화하고 DB 설계로 연결한 경험이다. 협업 역량과 기술 이해도를 함께 보여줄 수 있다.
