## 제안 시스템 개요

TS 종합건설의 건설 프로세스는 건축계획, 건축설계, 하청업체 선정, 착공 및 시공, 사용승인 흐름으로 이어진다. 이 과정에서 여러 협력업체와 자재업체가 반복적으로 연결되며, 프로젝트별 데이터와 주문 데이터가 계속 발생한다.

최종보고서에서는 이 중 협력업체 관리 시스템을 중심으로 제안했다.

## 주요 관리 대상

- 프로젝트
- 협력업체
- 자재업체
- 자재
- 주문
- 공사진행상황
- 담당자 또는 직원

## 화면 흐름

보고서에서 확인된 응용 화면은 다음과 같은 흐름을 가진다.

- 홈 또는 메인 화면
- 자재 목록 조회
- 자재 코드 검색
- 최신순 정렬
- 자재 수량 선택
- 주문 버튼
- 주문 상세 팝업
- 주문 확인 팝업
- 협력업체 관리 화면

## 사용자 가치

- 필요한 업체와 자재 정보를 빠르게 찾을 수 있다.
- 주문 정보를 시스템 안에서 관리할 수 있다.
- 협력업체 정보를 프로젝트와 연결해 관리할 수 있다.
- 종이 기반 자료를 구조화된 데이터로 전환할 수 있다.
