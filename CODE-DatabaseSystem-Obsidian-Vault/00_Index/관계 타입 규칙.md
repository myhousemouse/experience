# 관계 타입 규칙

이 vault에서는 단순 링크보다 관계 의미를 붙여서 프로젝트 맥락을 추적한다.

## 관계 타입

- `근거`: 특정 정리의 원본 자료 또는 확인 출처
- `문제정의`: 프로젝트가 해결하려 한 문제
- `설계결과`: 문제정의 이후 나온 구조/화면/DB 설계
- `구현근거`: SQL, 물리 설계, 화면 흐름처럼 실제 구현 또는 구현 수준 산출물
- `기여`: 개인 역할과 직접 연결되는 산출물
- `면접소재`: 자기소개서, 포트폴리오, 면접 답변으로 전환 가능한 경험
- `보완필요`: 기억 확인 또는 추가 정보가 필요한 지점
