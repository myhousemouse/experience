# UI UX 구현과 화면 구성

## UX 방향

[[리스크 매니저]]는 사용자가 자신의 사업 아이디어를 입력하고, 분석 질문을 거쳐 리스크 결과를 확인하는 앱이다. UX의 핵심은 “분석 도구처럼 보이되, 초보자도 따라갈 수 있는 흐름”을 만드는 것이었다.

## 화면 구성 방향

- 아이디어 입력 화면
- 유효성 확인 및 안내 화면
- 추가 질문 화면
- 리스크 분석 결과 화면
- RPN 수치 확인 화면
- 관점별 리포트 화면
- 실행 계획 화면
- 용어 설명 및 참고 링크 화면

## 디자인/구현 포인트

### 정보량 조절

비즈니스 리스크 분석은 텍스트 정보가 많아질 수밖에 없다. 그래서 한 화면에 모든 정보를 보여주기보다, 사용자가 단계별로 확인할 수 있도록 화면을 나누는 방식이 중요했다.

### 어려운 개념의 완충 장치

FMEA와 RPN은 일반 사용자에게 낯선 개념이다. 이를 보완하기 위해 용어 설명과 안내 화면을 포함하고, 결과 화면에서도 숫자만 강조하지 않도록 구성했다.

### 발표 자료와 앱 화면의 일관성

본인은 발표 PPT를 100% 담당했기 때문에, 발표에서 설명한 문제 정의와 앱 화면의 흐름이 서로 맞도록 정리했다. 이 부분은 단순 프론트 구현을 넘어서, 프로젝트 메시지와 화면 구성이 일관되게 보이도록 만든 경험으로 정리할 수 있다.
