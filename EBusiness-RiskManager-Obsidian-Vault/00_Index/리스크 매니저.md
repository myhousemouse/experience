# 리스크 매니저

## 한 줄 요약

[[리스크 매니저]]는 막연한 비즈니스 불안감을 FMEA 기반의 정량 지표와 AI 분석 흐름으로 구조화해, 사용자가 사업 아이디어의 위험도를 이해하고 다음 행동을 정리할 수 있도록 돕는 의사결정 지원 앱이다.

## 기본 정보

- 프로젝트명: 리스크 매니저 Risk Manager
- 과목: E비즈니스
- 기간: 2025년 11월
- 형태: 교내 수업 팀 프로젝트
- 개발 환경: Android Studio, Kotlin
- 프로젝트 맥락: 앱을 직접 만들어보는 수업 과제
- 본인 역할:
  - 보고서 작성 30%
  - 발표 PPT 100%
  - Android Studio 프론트 구현 80%
- 80% 산정 기준: 전체 프론트 화면과 흐름은 대부분 직접 구현했고, 나머지 약 20%는 내부 로직 수정 10%, QA 및 수정 10%에 해당한다.
- 시연 결과: 실제 기기를 연결해 시연했다.

## 프로젝트 성격

이 프로젝트는 완성도 높은 상용 앱 개발보다는 Android Studio로 앱 화면과 흐름을 직접 구현해본 경험에 가깝다. 따라서 취업 정리에서는 백엔드나 AI 시스템 구현 경험으로 과장하기보다, [[Android Studio 프론트 구현 경험]]과 [[UI UX 구현과 화면 구성]]을 중심으로 설명하는 것이 적절하다.

## 핵심 문제

초기 창업자나 기획자는 사업 아이디어를 검토할 때 리스크를 직관적으로만 판단하는 경우가 많다. 이 프로젝트는 그 판단을 정량화하고, 사용자가 자신의 아이디어를 더 객관적으로 점검하도록 돕는 방향에서 출발했다.

- 실행 계획 제안
- 외부 참고 링크와 용어 설명 제공

관련 문서: [[기능과 사용자 흐름]]

## 문제 해결과 고도화

- 앱과 프론트 구현이 처음이라 Android Studio 세팅부터 어려움이 있었다.
- 플러그인 AI를 설치해 세팅과 구현 적응 과정에 활용했다.
- 1차 위험도 측정 로직은 모든 엣지케이스를 반영하지 못해, 식당 창업/일반 창업 등 맥락별 질문을 더 세부화했다.
- RPN 공식 적용 전에 업종 카테고리와 가중치를 먼저 반영하는 방식으로 보완했다.
- AI 신뢰성을 높이기 위해 Cold Start, 낙관/비관 페르소나, 끊어서 생각하기 로직을 적용했다.
- 위험도 산출에서 끝나지 않도록 창업지원센터 등 후속 행동으로 연결되는 사용자 여정을 고려했다.

## 면접에서의 포지셔닝

- Android Studio를 활용해 앱 프론트 화면을 구현한 경험
- 기획 아이디어를 화면 흐름과 기능 구조로 바꿔본 경험
- 보고서와 발표자료까지 직접 정리해 프로젝트 메시지를 만든 경험
- 수업 과제지만, 기획-화면-시연 산출물까지 연결해본 경험
- 처음 접한 앱/프론트 분야에서 AI 도구를 활용해 개발 환경 적응과 구현을 진행한 경험
- 창업 수요 증가라는 시장 흐름을 읽고 서비스 기획으로 연결한 경험
- AI 분석 서비스에서 신뢰도 확보를 고민한 경험
