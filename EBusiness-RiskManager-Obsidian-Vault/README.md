교내 E비즈니스 수업에서 Android Studio를 활용해 앱 프론트를 구현한 경험을 정리한 볼트입니다.

## 프로젝트

- 프로젝트명: [[리스크 매니저]]
- 성격: 교내 수업 과제, 앱 프론트 구현 경험
- 기간: 2025년 11월
- 과목: E비즈니스
- 팀: E비즈니스시스템 6조
- 본인 역할: 보고서 작성 30%, PPT 100%, 프론트 구현 80%
