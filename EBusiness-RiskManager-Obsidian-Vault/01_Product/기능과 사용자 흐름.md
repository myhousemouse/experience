# 기능과 사용자 흐름

## 전체 흐름

1. 사용자가 사업 아이디어를 입력한다.
2. 앱이 아이디어가 분석 가능한 수준인지 확인한다.
3. 업종을 분류하고, 추가 질문을 제시한다.
4. 사용자의 답변을 바탕으로 리스크 분석 결과를 만든다.
5. RPN 점수와 리포트를 통해 위험도를 보여준다.
6. 사용자는 실행 계획과 참고 자료를 확인한다.

## 주요 기능

### 아이디어 유효성 검사

너무 짧거나 의미가 불분명한 입력, 사업 아이디어로 보기 어려운 입력을 걸러내는 흐름을 설계했다. 사용자가 분석 가능한 수준으로 아이디어를 입력하도록 돕는 진입 단계다.

### 업종별 맞춤 질문

아이디어를 업종별로 분류하고, 업종에 맞는 후속 질문을 제시하는 구조를 잡았다. 이를 통해 모든 아이디어에 같은 질문을 던지는 방식보다 더 구체적인 분석 경험을 만들고자 했다.

### RPN 기반 리스크 분석

FMEA의 RPN 개념을 활용해 리스크를 정량화했다.

- Severity: 심각도
- Occurrence: 발생 가능성
- Detection: 탐지 가능성
- RPN: Severity x Occurrence x Detection

이 기능은 [[문제 정의와 서비스 개요]]의 “막연한 불안감을 숫자로 바꾸기”와 직접 연결된다.

### 관점 기반 리포트

비관적 분석가와 낙관적 전략가 관점을 나누어 리스크를 해석하는 리포트 구조를 설계했다. 사용자가 단일한 답변보다 여러 관점에서 사업 아이디어를 검토할 수 있도록 하기 위한 장치다.

### 실행 계획

분석 결과가 단순 평가에서 끝나지 않도록, 사용자가 바로 참고할 수 있는 3단계 액션 플랜과 관련 분석 방법을 제공하는 흐름을 구성했다.

### 참고 링크와 용어 설명

사용자가 FMEA, RPN 같은 개념을 처음 접해도 이해할 수 있도록 용어 설명과 외부 참고 링크를 제공하는 화면을 포함했다.

## 프론트 구현 관점

이 기능들은 최종적으로 [[Android Studio 프론트 구현 경험]]과 [[UI UX 구현과 화면 구성]]에서 화면 흐름으로 구현됐다. 본인 기여는 특히 화면 구성, 사용자 입력 흐름, 결과 확인 흐름을 Android Studio에서 구현한 부분에 집중된다.
