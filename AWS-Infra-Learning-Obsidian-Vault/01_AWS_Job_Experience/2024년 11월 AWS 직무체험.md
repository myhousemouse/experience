# 2024년 11월 AWS 직무체험

## 개요

- 교육명: AWS 클라우드 실무 교육
- 기관: 한신대학교 AWS 직무체험 과정
- 기간: 2024년 11월
- 목표: AWS 클라우드 컴퓨팅 개념 이해 및 서버 운영/웹 애플리케이션 배포 실습

## 학습 내용

### AWS 기초

- 클라우드 컴퓨팅 개념
- AWS 주요 서비스 구조
- EC2, S3, RDS, IAM 개요
- AWS 글로벌 인프라: 리전, 가용 영역, 엣지 로케이션
- 클라우드 보안과 AWS 책임 분담 모델

### 서버 환경 구성

- AWS 계정 생성
- IAM 사용자 및 권한 설정
- EC2 인스턴스 생성
- Ubuntu 서버 접속
- PuTTY/SSH 기반 원격 접속
- `apt update` 등 기본 서버 패키지 관리

### 웹 서버 구축

- Nginx 설치
- 웹사이트 디렉토리 생성
- 사용자 권한 설정
- 기본 HTML 페이지 작성
- Nginx 서버블록 설정
- 심볼릭 링크 생성
- 설정 테스트 및 웹 서버 재시작

### 보안과 운영

- Security Group 설정
- HTTP 80, HTTPS 443, SSH 22 포트 개방/제한
- CloudWatch 기반 서버 모니터링 개념
- Auto Scaling과 Load Balancing 개념

## 배운 점

- 서버는 코드만으로 동작하지 않고, 인스턴스, 네트워크, 포트, 보안그룹, 웹서버 설정이 맞아야 외부 접근이 가능하다.
- 백엔드 API를 실제 서비스로 만들려면 배포 환경과 접근 제어를 함께 이해해야 한다.
- PM/기획 관점에서도 배포와 운영 리스크를 이해하면 개발자와 더 정확하게 소통할 수 있다.
