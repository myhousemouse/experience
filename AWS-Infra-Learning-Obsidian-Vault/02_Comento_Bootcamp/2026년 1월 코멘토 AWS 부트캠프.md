# 2026년 1월 코멘토 AWS 부트캠프

## 개요

- 형태: 미니 부트캠프/직무부트캠프
- 기간: 2026년 1월
- 구성: 4주차 실습
- 목표: 웹서버 구축, 배포, RDS 연계, 모니터링, 서버리스 API, 성능 테스트, 아키텍처 산출물 작성

## 1주차: 웹서버 구축과 IT 기획안 초안

주제: 클라우드 환경에서 웹서버를 구축하고 IT 기획안 초안을 작성.

학습/실습:

- AWS 계정 생성
- 비용 한도 설정
- VPC 생성
- 서브넷 생성
- 인터넷 게이트웨이 이해
- 라우팅 테이블 생성
- EC2 생성
- 보안그룹 설정
- Apache 웹 서버 설치
- 퍼블릭 IP로 테스트 페이지 접속
- 리소스 삭제와 비용 관리

## 2주차: 프론트엔드 개발과 배포

주제: HTML 웹페이지를 수정하고 웹서버에 배포.

학습/실습:

- HTML 코드 수정
- 웹서버에 정적 파일 배포
- IAM 사용자 생성
- AWS CLI 설치
- SFTP로 로컬 파일을 EC2에 전송
- `/var/www/html`로 파일 이동
- 브라우저에서 배포 결과 확인
- AWS Pricing Calculator로 운영 비용 산정

트러블슈팅:

- EC2 생성 시 네트워크 설정을 놓쳐 기본 VPC로 연결되면서 시간이 소요됨
- VPC, 서브넷, 보안그룹, 키페어, 인스턴스 네트워크 설정을 생성 시점부터 일관되게 맞춰야 함을 학습
- 생성/삭제 파이프라인과 비용 발생 지점을 이해해야 안전하게 실습 가능

## 3주차: 동적 서버 구축과 모니터링

주제: 서버 안정화를 위한 기술 적용과 모니터링 도구 구성.

학습/실습:

- 동적 처리를 위한 웹서버 재구성
- RDS 기반 관계형 데이터베이스 구축
- 웹서버와 데이터베이스 연계
- 서버 확장성과 가용성 개념
- 모니터링 지표 개발
- 실무형 모니터링 대시보드 산출물 작성

PM 관점의 배움:

- 개발 PM은 화면뿐 아니라 배포 환경과 운영 리스크를 설명할 수 있어야 한다.
- 일정 산정과 장애 리스크 판단을 위해 인프라 기본 구조를 이해하는 것이 중요하다.

## 4주차: 서버리스 백엔드 API와 성능 테스트

주제: 서버 내 처리를 위한 간단한 개발과 성능 테스트.

학습/실습:

- 서버 성능 테스트 도구 설치 및 테스트 수행
- 서버리스 서비스 기반 간단한 기능 개발
- API 개발과 목적지 연계
- 아키텍처링 도구로 요구사항 기반 아키텍처 작성
- 성능 테스트 결과 및 해석 보고자료 작성
- IT 아키텍처 산출물 작성
