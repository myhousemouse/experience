# 지혜샘어린이도서관 봉사 경험 Vault

지혜샘어린이도서관에서 수행한 서가정리, 독서문화프로그램 운영 지원, 어린이 대상 체험 부스 운영, 컴퓨터실 이용자 지원 경험을 취업·링크드인용으로 재구성한 Obsidian vault.

## 정리 기준

- 1365 자원봉사활동 확인서에 확인된 기간, 시간, 기관명, 공식 활동명을 기준으로 기록한다.
- 사용자가 제공한 세부 역할은 `본인 진술 기반 세부 활동`으로 기록한다.
- IT 직무 경험으로 과장하지 않고, 프로그램 운영·사용자 지원·현장 커뮤니케이션 경험으로 활용한다.
