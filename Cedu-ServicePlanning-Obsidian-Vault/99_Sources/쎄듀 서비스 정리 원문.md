# 쎄듀 서비스 정리

# 1. 쎄듀런

## 쎄듀런: [https://cedulearn.com/](https://cedulearn.com/)

> 쎄듀 교재 기반의 온라인 영어학습 플랫폼입니다. 선생님은 캠퍼스를 열어 수업을 운영하고, 학생은 배정된 과제로 학습·복습합니다.
> 

### 개요

㈜쎄듀가 운영하는 온라인 영어학습 플랫폼입니다. 천일문·어휘끝 등 쎄듀 베스트셀러 교재의 콘텐츠를 온라인 학습·관리 시스템으로 구현했습니다. 선생님이 '캠퍼스'를 개설해 학생을 초대하면, 학생은 과제를 학습하고 선생님은 채점·성적 관리까지 한 곳에서 처리할 수 있습니다.

유무료: 30일 단위 자동결제 구독 (프리미엄 올인원 / P보카), 일부 무료(Free Class)

### 핵심 특징

- 방대한 쎄듀 콘텐츠: 구문 문장 23,000개, 문법·서술형 문항 120,000개, 어휘 25,000개, 프리미엄 어휘 예문 170,000개를 골라 쓰거나 콘텐츠 마켓에서 복사해 활용합니다.
- 3단계 학습 구조: TR(시간 제한 없는 반복 훈련) → TEST(제한 시간 내 응시, 자동 채점) → AI 클리닉(오답 출제포인트를 분석해 맞춤 복습 문항 자동 생성, 구문·문법 한정)
- 다양한 학습 영역: 구문·문법·어휘 TR/TEST, 특별 TR, 선생님 자체 어휘, 선생님 자체 문항 TEST(OMR 채점), P보카
- 학사관리 자동화: 자동 채점, OX 리포트, 성적표 자동 제작 및 학부모 발송, 실시간 학습 현황, 열공/우등 배지, 1:1 메시지, TEST 인쇄·PDF

### 한 줄 요약

쎄듀 교재를 온라인 훈련·시험·복습 시스템으로 구현하고, 학원 운영에 필요한 학사관리까지 자동화한 선생님–학생용 구독형 플랫폼입니다.

# 2. 보카테스트

## 보카테스트: [http://vocatest.cedubook.com/](http://vocatest.cedubook.com/)

> 쎄듀 어휘 교재의 수록 단어로 어휘 시험지를 무료로 만들어 인쇄하는 프로그램입니다. 저작권 걱정 없이 쎄듀 교재의 어휘를 출제할 수 있습니다.
> 

### 개요

쎄듀 어휘 교재를 이용하는 사람이라면 누구나 쓸 수 있는 무료 어휘 출제 프로그램입니다. 표제어뿐 아니라 파생어·참고단어·관련단어까지 교재에 수록된 전 단어를 출제할 수 있습니다. 온라인 풀이가 아닌 **인쇄 전용(Print Only)** 서비스로, 만든 시험지를 인쇄하거나 문서·음원으로 다운로드해 오프라인 수업에 활용합니다.

이용 방법: 쎄듀북 홈페이지([https://www.cedubook.com/)에서](https://www.cedubook.com/)%EC%97%90%EC%84%9C) 로그인·회원가입 후 이용 / 학생용·선생님용 회원 구분

### 핵심 특징

- **무료·저작권 부담 없음**: 쎄듀 어휘 교재 수록 단어를 자유롭게 출제
- **넓은 출제 범위**: 표제어 + 파생어·참고단어·관련단어까지 포함
- **세밀한 출제 설정**: 교재의 유닛·유형·문항 수를 선택하고, 군등 분배·특정 문항 개수 조정·특정 단어의 출제 유형 변경까지 가능
- **인쇄 및 다운로드**: 시험지를 인쇄하거나 문서·음원 파일로 저장, 제작한 시험지 목록 관리
- **시험지 정보 입력**: 캠퍼스명·클래스명·선생님명·시험지명을 넣어 시험지에 표기

### 사용 흐름

1. 쎄듀북 홈페이지 접속 후 로그인
2. 출제할 교재 추가 (학생용: 교재 ISBN 입력 / 선생님용: 교재 목록에서 ★를 눌러 '나의 교재'에 추가)
3. '나의 교재'에서 교재 선택 후 [새 시험지 제작] 클릭
4. 출제할 유닛·유형·문항 수 선택
5. 출제 문항 수 선택 후 출제될 단어 확인
6. [변경사항 업데이트]로 인쇄 예시 확인 → [저장하기]/[다운로드]/[인쇄설정]
7. [인쇄설정]에서 캠퍼스명·클래스명·선생님명·시험지명 입력
8. 인쇄 설정 후 [인쇄]로 시험지 제작·인쇄 마무리

### 한 줄 요약

쎄듀 어휘 교재의 수록 단어로 어휘 시험지를 무료로 만들어 인쇄·다운로드하는 인쇄 전용 프로그램입니다. 학생용·선생님용 모두 쎄듀북 홈페이지에서 이용하며, 교재 추가 방식만 다릅니다.

# 3. 보카테스트  플레이

## 보카테스트 플레이 (Vocatest Play)

프로토타입: [https://vocatest-play.vercel.app](https://vocatest-play.vercel.app/)

> 더블보카 교재로 외운 단어를 유의어·반의어 관계로 확인하며 학습하는 학생용 어휘 학습 앱입니다. 게이미피케이션을 적용해 문제를 게임처럼 풀도록 설계했고, 시험지를 만들어 인쇄하는 보카테스트와 달리 학생이 화면에서 직접 학습하는 서비스입니다.
> 

### 개요

더블보카 교재와 연계된 어휘 학습 앱입니다. 단어의 뜻을 외웠는지 확인하는 데서 멈추지 않고, 표제어에서 유의어·반의어로 관계를 넓혀 가며 "진짜 내 것이 되었는지"를 점검하는 것이 핵심입니다. 학습과 테스트에 게이미피케이션 요소를 적용해, 문제 풀이가 공부라기보다 게임 한 판처럼 느껴지도록 설계했습니다. 교재의 Day 구성을 그대로 따라가므로 책으로 공부한 진도와 앱 학습이 어긋나지 않습니다.

진입 방법은 두 가지입니다. 앱을 설치해 회원으로 시작하거나, 책 속 QR 코드로 가입 없이 게스트 체험을 시작할 수 있습니다. 게스트 기록은 회원 전환 시 이어집니다.

유무료: Day 1~5 무료 체험 후 이용권 결제(앱 내 결제와 웹 결제 병행, 교재 보유 여부에 따라 결제 구성이 달라짐)

### 핵심 특징

- **유의어·반의어 관계 학습**: 표제어 → 유의어 → 반의어 순서로 한 단어의 관계망을 학습
- **게임처럼 푸는 문제**: 짝을 맞추는 매칭 게임, 직접 떠올려 답하는 리콜 등 게이미피케이션 기반 문제 유형으로 반복 학습의 지루함을 줄임
- **Day 단위 흐름**: 메인 캘린더에서 Day 선택 → 학습 → 테스트 → Day 결과 확인
- **오답 관리**: 오답은 표제어 기준으로 집계하고(출제는 관계 단위), 복습을 끝까지 마치면 오답이 회복됨. 오답노트와 약점 단어로 반복 학습
- **직접 테스트**: 원하는 범위를 골라 무작위로 출제해 스스로 점검
- **대시보드**: 학습 현황과 오답노트를 한눈에 확인

### 사용 흐름 (학생 기준)

1. 앱 설치 또는 더블보카 책 속 QR 접속(게스트 체험)
2. 교재를 선택하고 Day 캘린더에서 오늘 학습할 Day 선택
3. 표제어 → 유의어 → 반의어 순으로 학습
4. 게임형 테스트로 확인하고 Day 결과에서 오답 확인
5. 오답노트와 복습으로 약한 단어를 반복, 복습을 완주하면 오답이 회복됨
6. 무료 체험(Day 1~5) 이후 이용권 결제로 계속 이용

### 한 줄 요약

더블보카로 외운 단어를 유의어·반의어 관계로 확인하고, 게임처럼 풀리는 문제와 Day 단위 오답 복습으로 어휘를 완성하는 학생용 어휘 학습 앱입니다.

# 4. 중등 영문법 N제 온라인 추가 문제

## 중등 영문법 누적 N제 온라인 추가 문제(3권 QR_총괄평가용): [https://d2stvglg5s3cve.cloudfront.net/?book_id=347](https://d2stvglg5s3cve.cloudfront.net/?book_id=347)

> 2026년 10월 출간되는 「중등 영문법 누적 N제」(1~3권) 교재에 삽입되는 QR 서비스입니다. 학생이 QR로 접속해 회원가입·로그인 없이 추가 문항을 풀고 즉시 채점·결과를 확인합니다.
> 

### 개요

교재 지면에 다 담지 못하는 문항을 온라인으로 추가 제공해, '많은 문항 수'라는 교재 강점을 강화하는 것이 목적입니다. QR로 접속하는 모바일 웹 기반이며, 총괄 평가와 기초 훈련 두 가지 유형을 제공합니다.

### 두 가지 QR 서비스

- **총괄 평가** — 사용자가 선택한 챕터들을 누적해 랜덤으로 문항을 풀이하는 유형입니다. 화면을 새로 개발하며, 문제는 쎄듀런 DB에 이미 입력되어 있는 기존 문항을 재활용합니다.
- **기초 훈련** — 교재의 Speed Review Test 문항과 같은 유형의 쌍둥이 문제를 제작해, 해당 페이지의 QR로 바로 풀어볼 수 있는 유형입니다. 쎄듀런 기존 화면을 활용합니다.

### 진행 현황

- 기초 훈련용 쌍둥이 문항을 AI로 제작해 현재 DB에 입력 중입니다.
- 추후 두 가지 QR 확인(검수) 작업 예정입니다.

### 한 줄 요약

10월 출간 「중등 영문법 누적 N제」(1~3권)에 들어갈 QR 서비스로, 쎄듀런 DB 문항을 누적·랜덤 풀이하는 '총괄 평가'(화면 신규 개발)와 Speed Review Test의 쌍둥이 문제를 푸는 '기초 훈련'(쎄듀런 기존 화면 활용) 두 유형으로 구성됩니다.
