**[누적 영문법 N제] 누적 총괄평가 QA 디렉션**

**1. 서비스 한 줄 설명**

교재 앞면지·뒤표지의 QR을 찍으면 로그인 없이 모바일 웹으로 들어가, 배운 챕터를 누적 선택하고 그 범위에서 랜덤 30문항을 푼 뒤 점수·집중 복습 포인트를 확인하고 공유하는 서비스입니다.

- 교재: 누적 영문법 N제 1·2·3권, 권당 15챕터 (1권 1,683 / 2권 1,705 / 3권 1,349문항)
- 회원가입·로그인 없음, 결과는 저장되지 않음 (홈으로 가면 항상 새 세션)
- 채점 규칙: 미응답은 오답 처리, 정답률은 반올림 (복수정답인 문항 존재X, 객관식 문항)
- 같은 교재의 SRT(Speed Review Test) 추가문제 QR 45개는 별도 서비스입니다.

**2. 진입 방법**

- URL: 참고 링크 2번 참조 — book_id 345(1권) / 346(2권) / 347(3권)
- QR: 권별 QR 이미지 3장 (참고 링크 2번)
- 테스트 기기: iOS Safari, Android Chrome, 카카오톡 인앱 브라우저 (나와의 채팅에 URL을 보낸 뒤 눌러서 진입)

**3. 화면 흐름과 화면별 확인 포인트**

① 홈: 교재명·권 표기, 표지 이미지, 설명 문구, 시작하기

② 챕터 선택: 15개 챕터명이 교재 목차와 일치하는지, 복수 선택·전체 선택·해제, 미선택 시 다음 버튼 비활성, 긴 챕터명 줄바꿈

③ 출제 구성: 선택한 챕터만 집계되는지, 총 30문항, 다시 선택 시 선택값 초기화

④ 문제 풀이: 30문항·진행 카운터, 선택한 챕터 문항만 출제, 같은 회차 내 중복 문항 없음, 보기 번호·지문·밑줄 렌더링, 이전/다음 이동, X 누르면 이탈 확인

⑤ 제출: 미응답이 있으면 미응답 확인 모달, 모두 응답 시 바로 결과

⑥ 채점 결과: 점수·정답률·정답/오답 수, 집중 복습 포인트(최대 3개 + 전체 보기), 문항별 결과 탭(전체/정답/오답)과 펼침(내 답·정답·해석·해설), 홈으로·다시 풀기

⑦ 공유: 공유 시트의 본문 텍스트, 미리보기 카드, 공유하기·링크 복사, 카카오톡으로 보냈을 때 미리보기, 받은 링크로 들어가면 홈으로 진입

**4. QA 진행 순서** (아래 조건은 예시입니다. 참고하시되 자유롭게 진행해 주세요.)

1단계 사전 확인: 권별 QR 스캔 진입 → 도메인 확인 → 홈·챕터 선택 화면 확인. 챕터명·문항 수 확인

2단계 기본 플레이: (예) 전체 선택 1회, 챕터 1개 선택 1회 — 끝까지 풀고 결과·공유까지

3단계 챕터 단독 플레이: (예) 챕터를 하나씩 단독 선택해 30문항 구성·다른 챕터 섞임·중복만 빠르게 확인. 문항을 정독하지 말고 렌더링 깨짐만 훑으며 진행

4단계 조합 플레이: (예) 전체 선택 / 인접 2개 / 문항 수 최소+최대 챕터 / 첫+마지막 챕터 / 같은 조합 2회 연속(문항이 달라지는지)

5단계 예외: (예) 전부 미응답 제출, 풀이 중 X로 나가기, 풀이 중 새로고침, 브라우저 뒤로가기, 잘못된 book_id로 URL 직접 진입(예: 999), 비행기 모드에서 진입·제출

6단계 환경: (예) iOS / Android / 카카오톡 인앱 / 360px 소형 기기, 가로 모드·글자 크기 확대
