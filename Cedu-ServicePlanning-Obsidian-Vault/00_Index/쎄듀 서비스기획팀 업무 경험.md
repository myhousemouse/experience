# 쎄듀 서비스기획팀 업무 경험

최신 확인: 2026-10-14. 출처: 사용자 제공 1~10주 업무 및 후속 성과 설명. 이번 운영계획에서 프로그램 예정 기간·직무를 추가 확인했다. 실제 근무일자·수료·배치 부서는 아직 별도 확정하지 않았다.

- 자사 사이트·디지털 서비스 목적과 이용 흐름 분석, 유사 에듀테크 UX 장단점·참고 아이디어 정리.
- 영단어·영문법 학습 서비스 2개에서 문제 출제·풀이·답안 입력·정답/오답·채점·결과·문항/정답/해설 QA. 기기별 화면 표시 차이 점검.
- 약 30건의 QA 사항 발견, 그중 10건이 실제 개발에 반영됐다고 사용자 확인. 최종 배포·오류율 개선을 별도 인증한 것은 아니다. 약 30건을 분모로 정밀 반영률을 만들지 않는다.
- 학습 사용자 시나리오를 작성해 UI/UX 개선점을 검토하고 수정본 재확인·추가 QA, 콘텐츠·데이터 정리 지원.
- 마지막 주 PPT 제작·발표는 **예정 업무**다. 완료 산출물·실제 발표 성과로 쓰지 않는다.

## CE-01 — 사용자 흐름을 기준으로 서비스 QA와 개선점 검토

상황: 학습 서비스 기능·콘텐츠·모바일 사용성 점검.
본인 행동: 시나리오 작성, 기기별 차이·문항·채점/결과 점검, 오류·개선사항 정리, 수정본 검수.
결과: 두 서비스 약 30건 발견, 10건 개발 반영.
재사용 관점: 기능 테스트 나열보다 사용자 과정·본인 점검 방법·반영 결과를 설명. 본인 개발 구현으로 포장하지 않는다.

## 운영계획 및 현재 업무 기록 범위

- 공식 프로그램: **[쎄듀](IT) 인턴형일경험프로그램_15차**
- 계획 기간: **2026.08.31 ~ 2026.11.06 (10주)**; 직무 **디지털 서비스 운영 & QA**, 운영계획상 부서 **콘텐츠마케팅사업본부**.
- 사용자 설명상 현재 노션에 **7주차까지** 기록돼 있다. [[쎄듀 1~7주차 업무 기록]]을 실제 수행의 주차별 근거로 사용한다. 현재 링크 본문은 환경 네트워크 403으로 미조회.
- 위의 기존 업무·30건 발견·10건 반영은 이전 사용자 확인 기록을 보존한 것이며, 이번 노션의 1~7주차 실적이라고 재확정하지 않았다.
- 8~10주차 계획과 PPT 제작·발표를 완료 성과에 포함하지 않는다.

## 확인된 1주차 실제 산출물

- [[쎄듀 1주차 보카테스트 UI UX 분석 및 개선안]]: 보카테스트 강점·학습 구조 분석, 경쟁 서비스 6개 비교, 학습 홈·햅틱/스와이프·롱프레스 예문/발음의 적용안 3개와 위젯 아이디어.
- 10쪽 가이드 완성은 확인됐지만 서비스 구현·반영·학습 지표 개선은 확인하지 않았다.
- 경쟁 서비스 조사도 사용자가 지정한 **실제 1주차 결과물**에 포함한다. 운영계획의 2주차 일정으로 재배정하지 않는다.
- 재사용 에피소드: CE-02 경쟁사 비교를 서비스 적용 방향으로 연결, CE-03 학습 단계별 피드백·복습 인터랙션 구체화.

## QA 내보내기 자료 기반 최신 확인

- [[쎄듀 QA 업무 기준 및 서비스 구분]]: Notion·Figma 기록 및 Re-QA 안내, 인쇄용 보카테스트와 앱 보카테스트 플레이 구분.
- [[쎄듀 QA 발견사항 및 개인 담당 기록]]: 팀 전체 65건; 남은지 담당자 포함 27건(단독 24·공동 3); 반영 완료 9건. 확인 완료는 별도 상태.
- 기존 약 30건·10건 반영은 이전 사용자 설명으로 보존하고, 새 자소서에는 CSV 기준·범위와 개인/공동 역할을 먼저 적용한다.
- [[쎄듀 1~7주차 업무 기록]]의 최신 상태를 우선한다. 기존 노션 조회 대기 문구는 이번 내보내기로 확인된 자료까지 미확인이라는 뜻이 아니다.

## 최신 개인 회고 — 출시·운영을 고려한 QA 판단

[[쎄듀 출시 운영과 QA 우선순위 멘토링 회고]]에 사용자 직접 회고를 추가했다. 중요도 상·중·하를 부여하던 초기 기준에서 주요 사용자·발생 빈도·재현·영향·출시/인쇄 일정을 함께 보는 판단을 배웠다. 이후 QR·결제·운영 반영 재검수와 기기·네트워크 변수 점검에 더 집중했다고 확인했다. 구매자·학습자 차이와 책/디지털 역할은 멘토링을 통해 배운 관점으로 구분한다. 기존 개별 이슈 상태는 이 회고로 수정완료로 바꾸지 않는다.
