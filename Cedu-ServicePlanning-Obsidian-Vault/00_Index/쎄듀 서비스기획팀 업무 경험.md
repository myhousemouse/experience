# 쎄듀 서비스기획팀 업무 경험

최신 확인: 2026-10-14. 출처: 사용자 제공 1~10주 업무 및 후속 성과 설명. 정확한 근무일자·직급/고용형태는 미제공.

- 자사 사이트·디지털 서비스 목적과 이용 흐름 분석, 유사 에듀테크 UX 장단점·참고 아이디어 정리.
- 영단어·영문법 학습 서비스 2개에서 문제 출제·풀이·답안 입력·정답/오답·채점·결과·문항/정답/해설 QA. 기기별 화면 표시 차이 점검.
- 약 30건의 QA 사항 발견, 그중 10건이 실제 개발에 반영됐다고 사용자 확인. 최종 배포·오류율 개선을 별도 인증한 것은 아니다. 약 30건을 분모로 정밀 반영률을 만들지 않는다.
- 학습 사용자 시나리오를 작성해 UI/UX 개선점을 검토하고 수정본 재확인·추가 QA, 콘텐츠·데이터 정리 지원.
- 마지막 주 PPT 제작·발표는 **예정 업무**다. 완료 산출물·실제 발표 성과로 쓰지 않는다.

## CE-01 — 사용자 흐름을 기준으로 서비스 QA와 개선점 검토

상황: 학습 서비스 기능·콘텐츠·모바일 사용성 점검.
본인 행동: 시나리오 작성, 기기별 차이·문항·채점/결과 점검, 오류·개선사항 정리, 수정본 검수.
결과: 두 서비스 약 30건 발견, 10건 개발 반영.
재사용 관점: 기능 테스트 나열보다 사용자 과정·본인 점검 방법·반영 결과를 설명. 본인 개발 구현으로 포장하지 않는다.
