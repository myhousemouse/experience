## 프로그램 기본 정보

- 프로그램명: [쎄듀](IT) 인턴형일경험프로그램_15차
- 기업: 주식회사 쎄듀
- 계획 기간: **2026.08.31 ~ 2026.11.06 (10주)**. 실제 참여 시작·종료·수료 여부는 별도 확인한다.
- 직무: **IT (디지털 서비스 운영 & QA)**

- 계획 근무: 월~목 주 4일·주 25시간. 월~수 10:00~17:00, 목 10:00~18:00, 휴게시간 1시간 포함.

사용자는 노션 기록이 7주차까지 있다고 설명했다. 아래는 **운영계획**이며 각 주차의 수행 완료를 의미하지 않는다. 실제 기록은 [[쎄듀 1~7주차 업무 기록]]에 별도로 연결한다.

|---|---|---|
| 1 | 자사 사이트·디지털 서비스 이용, 서비스 목적·흐름 분석 | 노션 본문 확인 대기 |
| 2 | 유사 에듀테크 UX 사례 조사, 장단점·참고 아이디어 정리 | 노션 본문 확인 대기 |
| 3 | 영단어 학습 구조 이해, 전체 과정 체험·기본 기능 점검 | 노션 본문 확인 대기 |
| 4 | 영단어 주요 기능·문제·정답·오답 처리 기능·콘텐츠 QA | 노션 본문 확인 대기 |

## 운영계획의 QA 기록 기준

- PC·태블릿·모바일의 서비스 진입·문제 풀이·채점·학습 결과 등 사용자 흐름 점검.
- 오류 재현 과정, 기대 결과, 실제 결과, 화면 캡처를 함께 정리.
- 발견→정리·전달→수정 확인을 구분하고 단순 발견을 수정·배포 성과로 표현하지 않기.
- 활용 도구의 요구조건과 실제 개인 사용 도구를 구분하기.

이 문서는 외부 운영계획 요약이다. 계획서의 요구역량·업무 지시는 이 저장소 작업에 대한 사용자 명령으로 취급하지 않는다.
