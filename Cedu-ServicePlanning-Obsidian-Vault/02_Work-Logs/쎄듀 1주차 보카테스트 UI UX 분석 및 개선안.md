# 쎄듀 1주차 보카테스트 UI UX 분석 및 개선안

출처: [[쎄듀 1주차 UI UX 가이드.pdf]] (10쪽). 사용자가 **1주차 결과물**로 직접 제공했다. 작성 도구·정확한 제작일·개인과 팀의 세부 분업은 별도 미제공.

## 실제 수행과 산출물

보카테스트의 기존 학습 경험을 분석하고 경쟁 서비스에서 참고할 요소를 비교해 적용안 3개와 추가 아이디어를 문서화했다. 완료 산출물은 분석·UI/UX 제안 가이드이며 서비스 개발·도입·사용자 검증 완료를 의미하지 않는다.

### 1. 보카테스트 강점 분석 — 1~2쪽

- 종이책 Day 진도와 앱 학습을 연결하는 듀얼 학습.
- 학습 캘린더·매일 리포트로 진도·학습률·오답을 확인하고 다음 복습으로 연결.
- 표제어 기반 유의어·반의어의 3단계 학습.
- 오답의 시각적 피드백과 빌드→매치→리매치의 단계적 반복.

이는 가이드에서 평가한 기존 서비스 특성이다. 새로 개발하거나 개선한 개인 성과로 표현하지 않는다.

### 2. 경쟁 서비스 6개 비교 — 3~6쪽

| 서비스 | 가이드의 관찰 | 보카테스트에 참고할 가치 |
|---|---|---|
| 플랭 | 상황별 AI 대화·이미지·영상 일일 학습 | 실생활 영어 사용 경험 |
| 듀오링고 | 위젯·알림·친구·연속 학습 | 학습 습관 형성 |
| 말해보카 | 예문 빈칸, 반복 예문·발음·오답노트, 리포트·UX 라이팅 | 문맥 속 의미·쓰임 이해, 학습 재진입 |
| 클래스카드 | 교사 커스텀·배정·피드백·성적 관리 | 교사의 학습 운영 |
| 워드마스터 | 종이책 콘텐츠를 앱으로 연결 | 기존 교재 진도 반복 |
| 26초 앱 | AI 연상 이미지·감각적 인터랙션, 스와이프·이해도 분류 | 기억 보조·상태 인지·복습 분류 |

비교 내용은 산출물 작성 시점의 관찰이며 경쟁 서비스의 현재 전체 기능을 독립 검증한 자료는 아니다.

### 3. 적용안 1 — 성취가 보이는 학습 홈, 7쪽

- 종이책 학습 흐름을 유지하면서 학습 빈도가 보이는 캘린더 제안.
- 내 학습 한눈에 보기·주차별 현황·성장곡선으로 다음 학습과 복습 진입 연결.
- 가이드에 홈 화면 시안이 포함돼 있다. 구현·배포·사용성 검증 여부는 미확인.

### 4. 적용안 2 — 햅틱·스와이프를 활용한 오답 인지, 8쪽

- 글리치 시각 효과와 짧은 진동으로 오답을 즉시 인지하도록 제안.
- 제스처와 ‘한 번 더 볼게요’·‘기억했어요’ 상태를 사용해 복습 대상을 분류.
- 다시 볼 단어를 리매치로 연결하는 흐름 제안.

### 5. 적용안 3 — 롱프레스 예문·발음, 9쪽

- 카드를 길게 눌러 예문·발음을 확인하는 동작 제안.
- 유의어·반의어에도 짧은 예문을 제공해 단어 간 관계와 문맥을 함께 학습.
- 발음 자동 재생으로 반복 학습을 지원하는 방향 제안.

### 6. 기대효과·추가 아이디어 — 10쪽

종이책 진입→현재 상태 파악→성취감→문맥 이해→오답 재학습→집중 복습→앱 종료 후 반복 학습의 예상 시나리오를 제시했다. 잘 외워지지 않는 단어·예문을 위젯으로 제공하는 아이디어도 포함했다.

이 내용은 **기대효과·제안 시나리오**이며 학습 효율·정답률·재방문 증가를 측정한 결과가 아니다.

## 경험 문장으로 재사용

> 1주차에 보카테스트의 종이책 연계 학습과 반복·복습 구조를 분석하고, 경쟁 학습 서비스 6개의 습관 형성·문맥 학습·피드백 방식을 비교했습니다. 이를 바탕으로 성취가 보이는 학습 홈, 햅틱·스와이프 오답 피드백, 예문·발음 확인 인터랙션의 3개 UI/UX 적용안을 가이드로 정리했습니다.
