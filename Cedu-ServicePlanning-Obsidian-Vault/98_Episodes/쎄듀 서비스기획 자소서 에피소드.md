## 1주차 실제 산출물 기반 에피소드

### CE-02 — 자사 강점과 경쟁사 비교를 개선 방향으로 연결

- 상황·과제: 보카테스트의 목적과 학습 경험을 이해하고 참고할 UX 방향을 정리.
- 본인 활동 기록: 종이책→Day 진도→앱 반복·복습의 장점을 정리하고 6개 경쟁 서비스의 습관 형성·문맥 학습·사용 피드백을 비교. 학습 캘린더·리포트 중심 홈 개선안으로 연결.
- 결과: [[쎄듀 1주차 UI UX 가이드.pdf]] 분석·비교표·적용안 완성. 서비스 적용·재방문 개선 실적은 미확인.
- 적합한 질문: 사용자 관점 분석, 벤치마킹, 서비스 기획, 새로운 환경 적응, 현업 개선 제안.
- 쓸 때 강조: 경쟁 기능을 그대로 옮기기보다 자사 종이책 연계 강점을 유지하면서 학습 습관을 보완한 판단.
- 근거: [[쎄듀 1주차 보카테스트 UI UX 분석 및 개선안]], PDF 1~7쪽. 작성 도구·세부 분업은 미제공.

### CE-03 — 오답 인지부터 재학습까지 인터랙션을 구체화

- 상황·과제: 단어를 빠르게 확인하는 흐름에서 의미·쓰임 이해와 오답 복습을 이어줄 방향 검토.
- 본인 활동 기록: 햅틱·글리치·스와이프로 상태를 인지하고 복습 단어를 리매치로 연결하는 흐름, 롱프레스 예문·발음·관계어 예문을 제안. 외워지지 않는 단어의 위젯 재노출 아이디어 정리.
- 결과: UI/UX 적용안과 예상 사용자 시나리오를 가이드로 문서화. 인터랙션 개발·학습 효율 검증 결과는 아님.
- 적합한 질문: 사용자 흐름 설계, UX 개선 제안, 문제를 화면·행동으로 구체화, 고객 중심 사고.
- 쓸 때 강조: 오답 알아차리기→복습 분류→문맥·발음 확인의 학습 과정을 연결한 이유.
- 근거: PDF 8~10쪽. CE-02와 같은 가이드의 다른 관점이므로 독립 프로젝트로 중복 계산하지 않는다.

이번 가이드는 1주차 산출물이며 10주차 PPT 발표와 별개다. 시안의 정답률·학습량은 예시 값이다.

## CSV 기반 QA 에피소드 — 최신 집계 적용

CE-01의 이전 약 30건·10건은 사용자 설명이다. 이번 CSV 기준 개인 담당자 포함 27건(단독 24·공동 3), 반영 완료 9건을 우선 근거로 사용한다. 본인이 개발하거나 모든 수정 완료를 직접 Re-QA했다고 단정하지 않는다.

### CE-04 — 비회원 체험에서 가입 후 학습 기록까지 흐름 점검

- 상황: QR로 비회원 학습 후 가입·로그인했을 때 학습 결과가 보존되지 않는 흐름.
- 행동: QR 진입→DAY40 학습→가입하고 저장/로그인→학습 기록 확인의 재현 시나리오를 작성·등록.
- 결과: CSV 행 63, 10/13, 개인 담당, **QA 등록 완료**. 수정·배포 성과가 아니다.
- 적합한 문항: 고객 여정, 시나리오 기반 검증, 서비스 전환·정보 연속성, 꼼꼼함.

### CE-05 — 기기·브라우저별 QR·인증·결제 차이 확인

- 상황: iPhone 앱 QR 카메라 사용 불가, 기기·브라우저별 학부모 인증 오류, Safari 결제 진행 불가.
- 행동: 환경·발생 조건·화면 근거를 기록하고 QA 항목으로 관리.
- 결과: CSV 행 27·6·8은 개인 담당·반영 완료 상태. 이와 별개로 계좌이체 관련 행 53·57은 대기 상태다.
- 적합한 문항: 예외 상황, 다환경 QA, 사용자 불편 분석, 운영 품질. 결제 성공률 개선이나 모든 결제 오류 해결을 주장하지 않는다.

### CE-06 — 학습 결과·진도 표시와 실제 수행의 일치 점검

- 상황: 5의 배수 Day 오답 0개 표기, 전체 Day 완료 후 진도율 불일치, 연속 클릭 시 문항 스킵.
- 행동: 실제 풀이·완료·반복 클릭 조건과 결과 화면을 비교해 불일치를 기록.
- 결과: 행 17은 개인 담당·반영 완료; 행 58은 공동 담당·확인 필요, 행 60은 개인 담당·확인 필요. 완료/미완료를 구분.
- 적합한 문항: 데이터 정합성, QA 기준, 정확성, 경계·예외 상황. 전체 오류를 수정했다는 성공 서사로 쓰지 않는다.
