## 1주차 실제 산출물 기반 에피소드

### CE-02 — 자사 강점과 경쟁사 비교를 개선 방향으로 연결

- 상황·과제: 보카테스트의 목적과 학습 경험을 이해하고 참고할 UX 방향을 정리.
- 본인 활동 기록: 종이책→Day 진도→앱 반복·복습의 장점을 정리하고 6개 경쟁 서비스의 습관 형성·문맥 학습·사용 피드백을 비교. 학습 캘린더·리포트 중심 홈 개선안으로 연결.
- 결과: [[쎄듀 1주차 UI UX 가이드.pdf]] 분석·비교표·적용안 완성. 서비스 적용·재방문 개선 실적은 미확인.
- 적합한 질문: 사용자 관점 분석, 벤치마킹, 서비스 기획, 새로운 환경 적응, 현업 개선 제안.
- 쓸 때 강조: 경쟁 기능을 그대로 옮기기보다 자사 종이책 연계 강점을 유지하면서 학습 습관을 보완한 판단.
- 근거: [[쎄듀 1주차 보카테스트 UI UX 분석 및 개선안]], PDF 1~7쪽. 작성 도구·세부 분업은 미제공.

### CE-03 — 오답 인지부터 재학습까지 인터랙션을 구체화

- 상황·과제: 단어를 빠르게 확인하는 흐름에서 의미·쓰임 이해와 오답 복습을 이어줄 방향 검토.
- 본인 활동 기록: 햅틱·글리치·스와이프로 상태를 인지하고 복습 단어를 리매치로 연결하는 흐름, 롱프레스 예문·발음·관계어 예문을 제안. 외워지지 않는 단어의 위젯 재노출 아이디어 정리.
- 결과: UI/UX 적용안과 예상 사용자 시나리오를 가이드로 문서화. 인터랙션 개발·학습 효율 검증 결과는 아님.
- 적합한 질문: 사용자 흐름 설계, UX 개선 제안, 문제를 화면·행동으로 구체화, 고객 중심 사고.
- 쓸 때 강조: 오답 알아차리기→복습 분류→문맥·발음 확인의 학습 과정을 연결한 이유.
- 근거: PDF 8~10쪽. CE-02와 같은 가이드의 다른 관점이므로 독립 프로젝트로 중복 계산하지 않는다.

이번 가이드는 1주차 산출물이며 10주차 PPT 발표와 별개다. 시안의 정답률·학습량은 예시 값이다.
