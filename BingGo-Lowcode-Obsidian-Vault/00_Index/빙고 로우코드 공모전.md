# 빙고 로우코드 공모전

원본: https://app.notion.com/p/2a13eee3a70480669a21d4f437747412
협업 페이지: https://app.notion.com/p/9703eee3a70482a9aec38104347bd043
태그: #project #lowcode #flextudio #contest #binggo

## 개요

- 프로젝트명: 빙고(氷GO)
- 팀명: ComFlex
- 기간: 2025년 10월-11월
- 형태: 플렉스튜디오 로우코드 개발 공모전
- 한 줄 소개: 시민 제보와 공공 데이터를 AI로 통합 분석해 빙판 위험 구간을 예측하고 실시간 제설/위험 정보를 제공하는 안전 지도 서비스

## 문제 정의

겨울철 결빙·빙판 사고는 치명도가 높고, 산간·지방도로·교량·터널처럼 제설 사각지대가 생기기 쉽다. 기존 서비스는 날씨앱, 뉴스, 내비게이션 안내처럼 정보가 분산되어 있고 시민 제보와 제설 상태를 통합해서 볼 수 있는 흐름이 부족했다.

## 핵심 기능

- 도로 위험도 TOP 10 리스트
- 시민 제보 게시판 및 등록
- 위치 기반 위험 구간 확인
- 빙판길 AI 챗봇 `Snow` 또는 `빙봇`
- 공공데이터와 시민 제보를 결합한 위험도 판단

## 기술 구성

- Lowcode/Frontend: Flextudio
- Backend: Spring Boot
- Database: PostgreSQL, Google Sheets
- AI: OpenAI API, RAG 실험 구조
- External API: 기상청 API, 네이버 지도 API, Google Sheets API

## 이 프로젝트의 핵심 포인트

기획과 개발이 명확히 분리된 프로젝트라기보다, 로우코드 환경에서 문제 정의, 화면 구성, API 연동, 데이터 저장, 우회 설계를 빠르게 반복한 프로젝트다. 따라서 기여를 `기획`, `개발`로 나누기보다 `문제정의`, `기술 제약 판단`, `대안 설계`, `구현 안정화`, `팀 학습 리딩`으로 보는 것이 적합하다.
