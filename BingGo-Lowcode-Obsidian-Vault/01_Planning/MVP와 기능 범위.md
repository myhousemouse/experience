## MVP 4축

1. 현재 위치 기반 빙판 위험 지도
2. 시민 제보 기능
3. 제설/위험 구간 리스트 및 필터
4. RAG형 질의응답

## 최종 기능 정리

### 도로 위험도 TOP 10

- 기상청·도로 정보 기반 데이터를 주기적으로 반영한다.
- 결빙 가능성이 높은 도로를 위험도 순으로 제공한다.
- 사용자는 현재 위험 구간을 빠르게 파악한다.

### 시민 제보

- 사용자가 현재 위치 기반으로 제설 상태나 미끄러운 구간을 제보한다.
- 사진, 위험 등급, 설명, 주소 정보를 결합해 저장한다.
- 제보 데이터는 리스트 형태로 공유된다.

### 빙판 AI 챗봇

- 빙판길/눈길 운전 및 보행 안전 요령을 대화형으로 안내한다.
- 초기에는 RAG 서버 연동을 고려했지만, 최종 구현에서는 로우코드에서 OpenAI API 직접 호출과 프롬프트 엔지니어링을 활용한 경량 구조로 정리했다.

## 기능 우선순위 변화

초기에는 지도 중심 UX를 강하게 고려했지만, 로우코드와 지도 API 연동 제약 때문에 최종적으로는 `위험도 TOP 10 리스트`, `시민 제보`, `AI 챗봇` 중심으로 가치를 전달하는 방향이 강화됐다.
