## 확인된 화면

- 스플래시/인트로 화면
- 로그인 화면
- 홈 화면
- 검색 결과 화면
- 책 상세 카드/상세 정보
- 책소개/작가소개/목차/리뷰/출판사 서평 탭
- 리딩 화면
- 프로토타입 시연 화면

## 프로토타입 흐름

1. 앱 진입
2. 로그인
3. 홈에서 자료 탐색
4. 검색어 입력
5. 검색 결과에서 책 선택
6. 상세 정보 확인
7. 대출 또는 읽기 진입
8. 리딩 화면에서 독서 도구 사용

## 산출물 해석

Figma는 최종 개선 UI의 기준 자료다. PPT는 발표용 설명 자료이고, Figma는 화면 구조와 프로토타입 흐름을 확인하는 원본으로 둔다.
