## 개선 목표

교보문고 전자도서관 앱의 핵심 이용 흐름을 모바일 앱에 맞게 다시 정리했다. 목표는 사용자가 로그인 후 책을 탐색하고, 대출하고, 읽기 화면으로 진입하는 과정을 더 자연스럽게 만드는 것이다.

## 화면별 개선

### 로그인

- 교보 eBook 로고 중심의 명확한 진입 화면
- 아이디/비밀번호 입력 필드 정리
- 아이디 저장, 아이디/비밀번호 찾기 제공
- 네이버, 카카오, 구글 등 간편 로그인 아이콘 배치
- 회원가입, 도서검색 진입 버튼 제공

### 홈

- 상단에 도서관명과 검색창 배치
- 베스트셀러, 신착 자료, 오디오북 베스트셀러 영역 구성
- 하단 탭으로 홈, 검색, 책장, 알림, 마이 이동 가능
- 기존 목록형 화면보다 모바일 앱 탐색 경험에 가깝게 구성

### 검색 결과

- 검색어 입력 후 결과 리스트 제공
- 책 표지, 제목, 저자/역자, 출판사, 출간일, 평점, 태그 노출
- 대출 버튼을 우측에 명확하게 배치
- 사용자가 책을 비교하고 대출 가능 여부를 빠르게 판단할 수 있도록 구성

### 상세 화면

- 책소개, 작가소개, 목차, 리뷰, 출판사 서평을 탭으로 구분
- 책 설명을 한 화면에서 탐색할 수 있도록 정보 구조 정리
- 검색 결과와 리딩 화면 사이의 판단 단계로 기능

### 리딩 화면

- 책 표지와 본문 리더 화면 제공
- 재생, 북마크, 목차, 메모, 잠금, 설정 등 독서 도구 배치
- 독서 중 필요한 기능을 하단 도구 영역에서 접근하도록 구성

## 개선의 의미

단순히 화면을 예쁘게 바꾸는 것이 아니라, 기존 전자도서관 서비스의 복잡한 진입 과정과 낡은 화면 구조를 모바일 사용자 여정에 맞게 재배치한 프로젝트다.
