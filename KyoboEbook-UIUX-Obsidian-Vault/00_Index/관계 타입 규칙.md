# 관계 타입 규칙

태그: #ontology #relationship-rule

## 관계 타입

- `source-of-truth`: 원본 산출물 또는 기준 자료
- `defines`: 문제 정의와 개선 방향을 정한다
- `supports`: 사용자 불편, 기존 화면, 이용 정책이 판단을 뒷받침한다
- `improves`: 기존 UI 문제를 개선 UI로 연결한다
- `prototype`: Figma 화면과 시연 흐름으로 구현된다
- `interview-evidence`: 면접에서 경험 설명 근거로 쓸 수 있다
- `needs-context`: 추가 기억 확인이 필요한 지점
