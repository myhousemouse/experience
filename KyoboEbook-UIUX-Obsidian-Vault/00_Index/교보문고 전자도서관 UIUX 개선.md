## 한 줄 요약

교보문고 전자도서관 앱의 복잡한 이용 과정과 낡은 UI를 개선하기 위해 로그인, 홈, 검색, 상세, 리딩 화면을 중심으로 모바일 앱 UX를 재설계한 수업 프로젝트.

## 프로젝트 성격

- 수업명/맥락: 정보기술론 프로젝트
- 대상 서비스: 교보문고 전자도서관
- 산출물: PPT, Figma 개선 UI, 프로토타입
- 핵심 관점: 모바일 전자책 이용 흐름 개선

## 문제 배경

대학 전자도서관 이용자는 전자책을 빌려 읽기 위해 기관 선택, 도서관 계정 로그인, 출판사별 앱 사용, PC 최초 로그인 등 여러 단계를 거쳐야 한다. PPT에서는 이 과정이 답답하고 어플 사용성이 떨어진다는 문제의식이 확인된다.

자세한 내용은 [[기존 UI 문제 정의]] 참고.

## 개선 방향

- 로그인 화면을 모바일 앱에 맞게 정리
- 홈에서 베스트셀러, 신착 자료, 오디오북 등을 빠르게 탐색
- 검색 결과에서 책 표지, 제목, 저자, 평점, 태그, 대출 버튼을 명확하게 제공
- 상세 화면에서 책소개, 작가소개, 목차, 리뷰, 출판사 서평을 탭으로 구분
- 리딩 화면에서 재생, 북마크, 목차, 메모, 잠금, 설정 등 독서 도구를 접근 가능하게 정리

상세 개선안은 [[개선 UI 설계]], [[Figma 프로토타입]] 참고.

## 이 프로젝트의 핵심 포인트

이 프로젝트는 개발 구현보다 UI/UX 개선 기획과 프로토타입 제작 경험으로 보는 것이 맞다. 기존 서비스의 사용 흐름을 분석하고, 모바일 사용자가 더 쉽게 로그인, 탐색, 대출, 읽기를 이어갈 수 있도록 화면 구조를 재설계한 경험으로 정리할 수 있다.
