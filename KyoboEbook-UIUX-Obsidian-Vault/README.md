## 정리 기준

- 원본 PPT와 Figma는 링크/경로로만 연결한다.
- vault에는 문제 정의, 개선 방향, 화면별 개선 의도, 취업용 해석을 정리한다.
- PPT 내부 텍스트가 이미지 중심이라 주요 이미지를 확인해 요약했다.
