전체 안내: [[일경험 우수사례 공모전 준비]]
소재: [[쎄듀 우수사례 수기 에피소드 선정]]. 아직 제출용 완성 수기가 아니며 공고의 분량·항목을 확인한 뒤 조정한다.

## 중심 주제 후보

**좋은 화면을 찾던 기획에서, 사용자가 끝까지 학습할 수 있는 경험을 살피는 QA로.**

제목 후보:
- 화면 너머, 학습자가 멈추는 순간을 찾다
- 틀린 답보다 먼저 살펴야 할 것
- 작은 불편을 설명하는 힘, 일경험에서 배운 서비스 기획

이는 제목·방향 제안이다. 본인 마음의 변화는 실제 회고와 맞는 경우에만 사용한다.

| 구간 | 넣을 내용 | 필요한 실제 근거·회고 |

| 참여 전 | 일경험을 선택한 이유와 기획·QA에 대한 초기 기대 | 본인의 실제 진로 고민·경험 |
| 첫 시도 | 1주차 강점·경쟁사 조사와 3개 적용안 | UI/UX 가이드, 어떤 기준으로 제안했는지 |
| 난관과 행동 | 대표 오류 재현·기록·피드백 과정 | CSV/이슈 기록, 멘토의 실제 피드백, 본인이 바꾼 방법 |

## 공고 확인 후 조정

공식 평가항목·분량·개인정보/기업자료 공개 조건·산출물 첨부 여부를 확인하고 구성한다. 수상 사례를 읽은 후 전개 방식만 참고해 본인 경험의 진정성과 구체성을 유지한다.

## 예시 수기에서 참고할 전개 방식

- 방송 사례: 부서 사람별 소제목이 인상적이지만 쎄듀에서는 아직 멘토별 회고가 없으므로 사건 중심으로 유지한다.
- 광고 사례: 낯선 용어·절차→질문→스스로 판단하는 사건. 쎄듀는 재현 조건·상태 구분을 배운 실제 장면을 넣는다.
- 전략컨설팅 사례: 보고서의 정보량이 아니라 방향성이라는 기준을 배운 변화. 쎄듀는 UI 기능의 많음보다 학습자의 다음 행동을 보는 기준으로 연결할 수 있다.
- 개발협력 사례: 동료·멘토의 지원이 어떻게 개인 행동을 바꿨는지. 본인 발견과 다른 사람의 보충·수정 기여를 명확히 쓰면 협업 이야기가 살아난다.
- 호텔 사례: 하루의 감각적인 장면에서 직업관으로 확장. 쎄듀의 실제 문제풀이·오조작 순간을 짧게 보여주는 도입을 검토한다.

여기 적은 전개는 제안이다. 본인의 실제 시간 순서·감정·대화가 확인된 뒤 초안으로 쓴다.
