# 대시보드와 모니터링

원본: https://app.notion.com/p/23f3eee3a704807397cbc4d396fd0fd6
태그: #dashboard #monitoring #prometheus #grafana

## 학습 내용

대시보드 페이지에서는 Prometheus, Grafana, Actuator 기반 모니터링 구조를 참고했다.

## 개념

- Prometheus: 모니터링 오픈소스 도구
- Grafana: 데이터를 쿼리하고 그래프, 차트, 테이블 등으로 시각화하는 대시보드 도구
- Actuator: 애플리케이션 상태, 메트릭, 환경 정보를 노출하는 기능

## 프로젝트와의 관계

텃밭닥터에서 대시보드는 서비스 상태, API 상태, 모델/서버 운영 현황을 시각화하기 위한 보조 학습 영역이다. 최종 서비스 핵심 기능은 챗봇과 병해충 진단이지만, 운영 가능한 서비스로 확장하려면 모니터링 대시보드가 필요하다.
