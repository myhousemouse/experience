## 요약

`꿈마중 버스`는 청소년 수요 기반 이동 도서관 모바일 플랫폼이다. 사용자가 지역과 희망 도서/프로그램을 신청하면 지역별 신청 현황을 확인하고, 운영 확정 이후 버스 정류장/노선/실시간 위치 정보를 확인하는 흐름을 MVP로 삼았다.

남은지는 백엔드 파트로 참여했고, GitHub 계정 `myhousemouse` 커밋 기준으로 버스 신청 현황, 가장 가까운 정류장/정류장 상세 조회, 지역 검색/노선 검색, 코스별 실시간 버스 정보 API 구현 근거가 확인된다.

해커톤 결과는 완주다. 백엔드 API와 산출 로직은 구현되어 백엔드 측에서는 동작했지만, 제한된 시간 안에 프론트엔드와 연동하지 못해 최종 시연 화면으로는 확인하지 못했다. 별도 배포 링크나 Swagger 배포는 없고, GitHub 저장소와 Notion API 문서가 근거 자료다.
