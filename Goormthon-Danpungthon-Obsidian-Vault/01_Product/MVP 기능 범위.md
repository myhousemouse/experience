# MVP 기능 범위

## MVP 필수 기능

- 도서관 신청
  - 거주 지역, 나이, 희망 도서/프로그램 입력
  - 신청 데이터 DB 저장
  - 신청 내역과 상태 관리
- 신청 현황 확인
  - 지역별 신청 인원 확인
  - 정원 50명 기준 잔여 인원과 충족률 표시
- 버스 일정/노선 안내
  - 지역과 날짜 기준 코스 및 정류장 목록 조회
  - 평일 코스 기반 운행 정보 제공
- 카카오맵 기반 버스 위치 확인
  - 가장 가까운 정류장 조회
  - 특정 정류장 상세 모달
  - 코스별 실시간 버스 상태, 현재/다음 정류장, 도착 ETA, 남은 정차 시간 제공

## MVP 이후 확장 아이디어

- 신청자 거주지 기반 클러스터링 및 최적 운행 경로
- AI 기반 일정 최적화
- AI 기반 맞춤 도서/프로그램 추천
- 프로그램 신청과 참여 기록
- 내 서재 및 대출/반납 관리

## 회의에서 조정된 내용

2025-08-31 회의록 기준:

- 일반 로그인/카카오 로그인에서 JWT 로그인 구현으로 정리
- 버스 신청 공유 기능은 제외
- 희망 도서 분야/프로그램은 드롭다운 선택으로 정리
- 사용자/관리자 유저를 분류하되, 해커톤 범위에서는 사용자 페이지를 우선 설계
- 버스 코스 설계 정책과 버스 시뮬레이션을 핵심 로직으로 정리
