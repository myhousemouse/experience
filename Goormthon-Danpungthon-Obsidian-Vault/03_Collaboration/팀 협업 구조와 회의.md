## 주요 의사결정

2025-08-31 회의록 기준:

- 스플래시 화면 추가
- 일반 로그인/카카오 로그인에서 JWT 로그인 구현으로 정리
- 버스 신청 현황은 실시간 시각화 디자인까지는 필요하지 않다고 판단
- 버스 신청 공유 기능은 제외
- 희망 도서 분야/프로그램은 드롭다운 선택
- 사용자/관리자 유저를 분류하되 해커톤에서는 사용자 페이지 우선
- 버스 코스 설계 정책과 버스 시뮬레이션을 핵심 로직으로 정리
- 9월 2~3일까지 디자인 완성, 9월 5일부터 프론트-백 연동 시작

## 협업 방식

- API가 필요한 화면을 먼저 식별
- 기능을 화면 단위로 분리
- 핵심 기능과 부가 기능을 분리
- Swagger와 Notion API 문서를 병행해 프론트 연동
- ERD, API, Docker 환경 문서를 협업 문서로 관리
