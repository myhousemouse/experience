## 메인 페이지 중심 작업 범위

기능명세서의 메인 페이지는 크게 세 흐름으로 구성된다.

### 1. 버스 운행 현황

- 카카오 맵 API 기반 화면
- 지역 검색과 요일 선택
- 현재 위치 기반 맵, 검색 지역 맵, 당일 경로 맵
- 정류장 마커 표시
- 버스 경로 Polyline 표시
- 정류장 정보/버스 정보/버스 시간표 모달
- 모달 드래그 전: 버스 운행 정보
  - 버스 상태
  - 현재/다음 정차 위치
  - 도착 시간
  - 남은 정차 시간
- 모달 드래그 후: 버스 시간표
  - 각 정류장별 도착 시간~마감 시간
  - 현 버스 위치

백엔드 연결:

- `/stops/nearest`
- `/stops/{stopId}`
- `/regions/{regionId}/service`
- `/courses/{courseId}/live`

### 2. 버스 신청 현황

- 지역 검색
- 버스 신청/남은 인원 현황 시각화
- 신청 인원과 남은 인원 집계

백엔드 연결:

- `/applications/summary`

주의:

- 기능명세서에는 신청 1명당 1%로 적혀 있으나, 코드와 API 문서에서는 정원 50명 기준으로 신청 1명당 2% 충족률을 계산한다. 최신 구현 기준은 코드/API 문서다.

### 3. 버스 신청하기

- 이름, 나이, 전화번호 입력
- 도로명 주소 검색 API를 통한 상세 거주지 입력
- 희망 도서 입력
- 희망 프로그램 선택

백엔드 연결:

- `/applications`
