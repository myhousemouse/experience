# 관계 타입 규칙

옵시디언 그래프에서 링크만 연결하면 의미가 약하기 때문에, 핵심 관계는 본문에 `관계타입`을 함께 적는다.

## 관계 타입

- `defines`: 상위 문제/목표가 기능 범위를 정의한다.
- `implemented_by`: 기획 또는 요구사항이 구현 산출물로 연결된다.
- `evidenced_by`: 기여 주장이 커밋, 코드, 문서 등 증거로 뒷받침된다.
- `decides`: 회의록이나 피드백이 제품/기술 방향을 결정한다.
- `depends_on`: 기능 구현이 다른 모델, API, 데이터 구조에 의존한다.
- `refines`: 초기 아이디어나 초안이 후속 문서에서 구체화된다.
- `conflicts_with`: 문서 간 내용이 충돌한다.
- `source_of_truth`: 충돌 시 더 우선하는 기준이다.

## 이 프로젝트의 우선순위

1. GitHub 실제 코드/커밋
2. 협업 Notion의 API/ERD/회의록
3. 최종 GUI 및 발표 산출물
4. 초기 기획 문서
