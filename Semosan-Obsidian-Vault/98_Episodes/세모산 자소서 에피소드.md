# 세모산 자소서 에피소드

## 2026-10-14 최신 확인 — 새 자소서 작성 시 우선 적용

출처: SK브로드밴드 자소서 작성 대화의 사용자 설명·정정. 개인 진술이며 독립 인증 아님. 아래 내용과 기존 본문이 다르면 아래 최신 범위를 적용한다.

- 등산 앱 10인 팀 PM. 팀원 대부분 등산 문화를 낯설어했다. 개발자는 기존 이용자가 많은 4050으로 주타깃 변경을 제안했고 본인은 2030 수요에 주목했다.
- 자료만으로 실제 수요를 충분히 알기 어렵고 직접 경험으로 가정을 검증하고자 팀원 9명과 관악산에 올랐다. 약 200명의 현장 인터뷰로 2030 수요·산행 기록·완등 성취·하산 후 맛집/막걸리까지의 코스를 확인했다. 최신 자소서는 200명을 2030으로 쓰지만 과거 기록은 전체 등산객으로도 표기한다. 전원 연령을 독립 확인한 것은 아니다.
- 본인도 운동·체력·다이어트 중심 가정에서 기록·성취·하산 후 활동의 중요성을 받아들였다. 현장 확인을 바탕으로 2030 타깃에 팀이 합의했다. 내 의견으로 상대를 이긴 이야기보다 본인 변화·의견 수용을 중심으로 쓴다.
- 개발자의 가벼운 추천 제안을 받아 온보딩 6문항→3문항으로 줄이고 30초 이내 산 추천을 목표로 구성했다. 코스까지 정확히 추천하는 방식에서 산 정도를 가볍게 추천하도록 바꿨다. 30초는 구성 목표이며 실측값 미확인.
- 하산 후 맛집 자동 추천 제안에는 BM 확장 가능성을 검토하고 산행 난이도 평가 화면에 추천을 추가할 수 있는 구조의 디자인을 요청했다. 자동 추천 구현 완료·매출로 확대하지 않는다.
- 산별 시설 정보가 통일되지 않아 백엔드 수집·디자인 표시가 어려웠다. 본인은 데이터를 확인해 화장실/편의점까지 필수였던 정책을 필요한 항목 중심으로 수정하고 누락 시설 정보는 AI로 공식 산 자료를 수집·추출하는 구조를 제안했다. 정보 누락과 시설 부재를 구분한다. 제안의 구현·합의 결과는 미확인.
- 최신 사용자는 방향이 불분명한 20개 기능→핵심 4개를 확인했다. 과거 10개 기록과 단계 차이는 미확정이므로 옛 10개를 새 자소서에 자동 재사용하지 않는다.
- 팀은 밋업 프로젝트 최우수상, 앱 출시, 현재 약 70명 회원 사용을 설명했다. 기준일은 이번 준비 시점으로 활성/누적 가입 정의는 미확인. 사용자 추정 개인 기획·조율 기여도 약 70%, 팀 전체 코드 개발의 70%로 확대하지 않는다.

재사용 에피소드: **SM-Q3 공동 산행으로 서로 다른 관점을 받아들이고 공동 방향을 정한 경험**. 타깃 차이→현장 검증→본인 인식 변화·팀 합의→추천 축소·맛집 제안 반영→20개를 4개로 집중·팀 수상. **SM-DATA 시설 데이터와 디자인 표시 기준을 조정한 사례**는 별도 보조 에피소드.

## 에피소드 상세

### SM-01 · 타깃 의견 충돌을 공동 산행과 사용자 조사로 풀다

**이 에피소드가 잘 맞는 질문:** 다른 의견과 협업 / 갈등 조율 / 현장 중심 문제해결 / 고객 리서치 / 도전적 실행

- 상황·문제: 개발자는 4050을, PM은 2030을 주타깃으로 제안했다. 팀원들의 등산 경험이 부족해 자료만으로 공통 기준을 만들기 어려웠다.
- 내가 한 행동: 온라인 언급량·자료로 가설을 설명하고 팀원과 관악산에 올랐다. 원문 기준 팀원 9명과 약 200명의 등산객에게 기록·산 주변 맛집 니즈를 조사해 공통 판단 자료를 만들었다.
- 결과·배운 점: 사용자가 되는 경험을 통해 타깃과 핵심 기능 방향에 공감하고 산행 기록·맛집 탐색 등 네 가지 기능을 선정했다.

**재사용할 때 강조할 관점:** 협업 문항에서는 상대 주장의 이유와 공동 검증 방식을, 실행 문항에서는 조사 준비와 발견한 니즈를 강조한다. 내 의견으로 상대를 이겼다는 서사보다 공동 기준을 만든 과정을 쓴다.

**이미 활용한 문항:** 농협 협업; 현대글로비스 도전적 실행; LG CNS 다른 의견 협업

**원문 위치:** [[자소서 정리 원문]] 36–38, 94–102, 155–158행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 약 200명은 첨부 초안의 현장 조사 규모. 기존 24명 UT와는 다른 조사다. 전원이 2030이라는 표현과 조사 방식·시점은 원기록 확인 전 범위를 확대하지 않는다.

### SM-02 · UT와 실제 산행으로 기능을 덜어내 핵심 경험에 집중

**이 에피소드가 잘 맞는 질문:** 우선순위 결정 / 선택과 집중 / 사용자 중심 개선 / 실패·피드백 수용 / PM 의사결정

- 상황·문제: 24명 UT에서 서비스 이용 흐름 이해가 낮았다. 등산 전·중·후 경험을 확신하지 못한 채 기능 후보가 늘어나 있었다.
- 내가 한 행동: 팀원과 앱을 직접 사용하며 산행 준비·길 확인·알림을 경험하고 핵심 기능을 네 개로 좁혔다. 사진·기록을 남기는 경험에 집중했다.
- 결과·배운 점: 기능 우선순위를 조정하고 핵심 산행 경험을 구체화했다. 첨부 초안은 최우수상·앱 출시·실제 사용자 약 70명을 후속 성과로 기록한다.

**재사용할 때 강조할 관점:** 기능을 추가하기보다 줄인 이유와 남길 기능의 판단 기준을 보여준다. SM-01과 산행 사건이 겹치므로 같은 지원서에서 다른 사건처럼 나누지 않는다.

**이미 활용한 문항:** 스타벅스 도전·몰입; 현대글로비스 실행; LG CNS 협업의 보조 소재

**원문 위치:** [[자소서 정리 원문]] 173–175, 98–100, 158행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 기능 후보는 글로비스·LG CNS 초안 10개, 스타벅스 초안 20개로 다르다. 재사용 시 후보 단계 확인 전 “여러 후보→4개”로 표현. 기존 UT 33.3%+37.5%=70.8%는 흐름 비이해 응답이며 남성 70%와 구분. 출시·수상·70명은 새 초안 기록으로 출시 시점·배포 상태·집계 기준 확인 전 독립 검증 성과로 단정하지 않는다.

### SM-03 · 칭찬과 인정으로 낯선 개발·디자인 도전을 지원

**이 에피소드가 잘 맞는 질문:** 리더십 / 동기부여 / 조직문화 / 존중과 협업 / 팀 분위기 개선

- 상황·문제: 파트마다 목표와 우선순위가 달랐고 디자인팀은 피드 UX, 개발팀은 익숙하지 않은 React Native 기반 iOS 구현에 어려움을 겪었다.
- 내가 한 행동: 어벤져스 팀 문화를 만들고 작은 성과를 인정했다. 디자인팀과 레퍼런스를 찾아 피드 설계를 지지하고 개발팀의 학습·시도를 격려했다.
- 결과·배운 점: 디자인 피드에 대한 긍정적 피드백과 팀의 도전 지속을 원문에서 보고한다.

**재사용할 때 강조할 관점:** 칭찬이라는 가치 선언보다 막힌 과제에서 함께 한 행동과 팀원의 반응을 구체화한다. 기술 산출물의 직접 구현은 담당 팀원의 기여로 남긴다.

**이미 활용한 문항:** 현대글로비스 조직문화·가치관

**원문 위치:** [[자소서 정리 원문]] 72–77행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** “능력 8→10”, “120% 혁신”은 비유이며 정량 성과가 아니다. 최우수상과 출시를 칭찬만의 인과적 결과로 단정하지 않는다.

### SM-04 · 고객 여정으로 10개 기능의 우선순위를 정하다

**이 에피소드가 잘 맞는 질문:** 고객 여정 / 기능 우선순위 / 서비스 기획

- 상황·문제: 10개 기능이 모두 핵심으로 논의돼 사용 흐름이 불분명했다.
- 내가 한 행동: 2030 수도권 취미 등산객의 탐색→준비→등산→하산 후 여정을 구체화했다. 현장 관찰과 조사를 바탕으로 산 탐색·실시간 정보 확인·트래킹·등산 인증 및 공유의 4개 기능에 집중했다.
- 결과·배운 점: 삼성 초안은 전시 체험자 93.2%가 다음 등산에서 기록·공유 기능을 사용할 의향을 보였다고 기록한다.

**재사용할 때 강조할 관점:** 질문의 핵심에 맞춰 위 행동과 판단을 골라 쓴다.

**이미 활용한 문항:** 삼성 자소서 1번 지원동기

**원문 위치:** [[삼성 자소서 원문]] 1번 지원동기

**표현·근거 메모:** SM-02와 같은 기능 축소 사건의 고객 여정 관점이다. 93.2%는 이용 의향이며 실제 재사용·전환·유지율이 아니다. 전시 응답의 분모·문항 확인 전 24명 UT 결과로 합치지 않는다.

## 삼성·CJ 추가 활용 기록

CJ 4번 자발적 개선의 두 번째 경험은 SM-01·SM-02에 연결한다. 새로운 산행 사건으로 중복 생성하지 않는다. 삼성 1번은 고객 여정과 전시 이용 의향을 SM-04로 보강한다.
