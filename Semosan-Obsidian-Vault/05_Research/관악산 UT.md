# 관악산 UT

원본: https://app.notion.com/p/ac13eee3a70483b0b176817152cb8c05
태그: #research #ut #field-test #qa

## 역할

5월 31일 관악산 현장 UT와 트래킹 QA를 준비한 문서다. 트래킹 기능 최종 QA, 트래킹 시나리오 UT, 등산객 대상 유저 리서치, 베타테스터 모집이 목적이다.

문서와 수치만으로는 팀원들이 사진 기록 기능을 핵심 MVP로 선택한 이유에 충분히 공감하기 어렵다고 판단해, 전 팀원이 실제 등산 흐름에서 프로토타입을 사용하도록 제안했다. 산행 중 사진을 남기고 기록이 쌓이는 과정을 함께 확인하면서 기능의 사용자 가치와 구현 우선순위를 같은 경험을 기준으로 논의했다.

- 트래킹 코스 선택
- 현위치 실시간 반영
- 클라이브 촬영/알림/저장
- 프로그래스 바
- 진행 상황별 알림
- 정상도착/하산완료 버튼
- 최종 리포트 산출
- 포토리포트 선택 및 저장
- 클라이브 저장

## 현장 검증 이후 결정

- 24명 UT에서 사진 기록과 산행 아카이빙에 긍정적인 반응이 집중된 결과를 현장에서 다시 확인했다.
- 전 팀원이 트래킹, 사진 촬영·저장, 알림, 최종 리포트 흐름을 직접 사용했다.
- 실시간 사진 기록 기능인 `클라이브`를 핵심 MVP로 확정했다.
- 기능명세서, 최종 화면, API 명세와 ERD의 기능 범위를 다시 맞췄다.
- 변경된 우선순위를 기준으로 새로운 개발 마일스톤을 시작했다.

이 현장 UT는 완성된 화면을 평가하는 데 그치지 않고, 기획·디자인·개발 구성원이 동일한 사용 맥락을 경험한 뒤 MVP 범위와 산출물 정합성을 다시 맞춘 협업 사례다.
