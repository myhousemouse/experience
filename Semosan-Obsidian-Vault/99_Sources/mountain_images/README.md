### 앱 내 출처 표기 권장 문구

```text
이미지 출처
도봉산: Jinhwae Kim, CC0, Wikimedia Commons
한라산: 제주영상문화산업진흥원, 공공누리 제1유형
수락산: 서울연구데이터서비스, 공공누리 제1유형
```

Pixabay 이미지는 출처 표기가 의무는 아니지만, 내부 추적용으로 아래처럼 별도 문서나 관리자 DB에 남겨두는 것을 권장한다.

```text
관악산: jg991004, Pixabay Content License
북한산: KIMDAEJEUNG, Pixabay Content License
설악산: KIMDAEJEUNG, Pixabay Content License
지리산: JJChoi, Pixabay Content License
수락산: Mike Throm, Unsplash License
```

## 사용 전 주의

- `CC0`: 출처 표기 의무는 없지만, 내부 추적을 위해 출처를 남기는 것을 권장.
- `CC BY`: 저작자, 원본 링크, 라이선스 링크 표기 필요.
- `CC BY-SA`: 저작자, 원본 링크, 라이선스 링크 표기 필요. 이미지를 수정/가공해 배포하는 경우 동일 또는 호환 라이선스 조건이 붙을 수 있음.
- `KOGL Type 1`: 공공누리 제1유형. 출처 표시 필요.
- `Unsplash License`: 앱 대표이미지 사용 가능. 출처 표기는 의무가 아니지만 내부 추적용 표기를 권장.
