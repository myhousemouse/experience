## 역할

세모산 Notion 메인 페이지는 포털이고, 원본 문서는 각 팀 페이지와 공통 자료에 유지된다. 이 Obsidian Vault는 원본을 대체하지 않고, 프로젝트 지식의 관계를 탐색하기 위한 로컬 그래프 레이어로 사용한다.

사용자는 등산 중 찍은 사진을 기록하고 정복 지도로 성취를 쌓는 등산 가이드 앱 `세모산`의 PM을 맡아 기획·디자인·개발을 포함한 9명의 팀원과 협업했다. 관악산에서 등산객 216명을 대상으로 스티커 보드 조사와 인터뷰를 진행하고, 24명 UT와 전 팀원 현장 QA를 거쳐 사진 기록 기능을 핵심 MVP로 좁혔다. 두 달간의 스프린트 끝에 앱스토어 출시와 베타 사용자 모집까지 연결했으며, 큐시즘 밋업 프로젝트 최우수상을 받았다.

## PM 의사결정과 파트 조율

초기에는 산 추천, 지도, 커뮤니티, 기록 중 어느 기능을 먼저 개발할지 파트마다 의견이 달라 MVP 범위를 확정하기 어려웠다. 사용자 근거 없이 파트별 선호로 결정하지 않기 위해 24명을 대상으로 UT를 진행했다.

등산 사진을 피드처럼 확인하는 `세모피드`에 `힙하다`, `신선하다`, `구경하고 싶다`는 반응이 모였다. 이를 근거로 사진 기록과 산행 아카이빙을 핵심 MVP로 선별하고, 서비스를 단순 등산 정보 앱이 아니라 `등산 경험을 기록해 성취를 쌓는 앱`으로 좁혔다.

수치와 문서만으로는 팀 전체가 핵심 기능에 공감하기 어렵다고 판단해 전 팀원이 관악산에 올라 실제 등산 흐름에서 프로토타입을 사용하도록 제안했다. 산행 중 사진을 남기고 기록이 쌓이는 과정을 함께 확인한 뒤 PM·디자인·프론트엔드·백엔드가 핵심 기능에 합의했다. 합의된 방향에 맞춰 기능명세서, 최종 화면, API 명세, ERD를 다시 정리하고 새 개발 마일스톤을 시작했다.

최종적으로 디자인·개발 분야 외부 전문가 2명에게 핵심이 명확하고 등산 중 사진을 실시간으로 남기는 기능이 매력적이며 설득된다는 평가를 받았다. 앱 출시를 완료해 현재 베타 사용자를 받고 있다.

## 외부 피드백 기반 방향성 검증

세모산은 등산 중 사진을 찍고 남기고 싶어 하는 사용자 니즈를 핵심 니치 포인트로 보고, 사진 기록과 아카이빙 경험을 메인 기능 방향으로 잡았다. 실제 우디디자인랩 대표 우디님께서 서비스를 보고 등산객들이 사진을 찍고 남기고 싶어 하는 지점을 잘 포착했으며, 이를 메인 기능으로 잡은 점이 사업성 측면에서도 가능성이 있다고 피드백했다.

이 피드백은 세모산의 방향성이 단순 등산 정보 제공이 아니라, 등산객의 기록 욕구와 성취감을 중심으로 차별화될 수 있다는 외부 검증 근거로 활용한다.

UT가 서비스 방향을 정하는 근거였다면, 관악산 현장 테스트는 파트별 의견을 하나의 MVP로 합의하는 과정이었다. 정의서 재정리는 현장에서 만든 합의를 실제 개발 범위와 일정으로 옮기는 역할을 했다.
