# 세모산 워크트리 운영 가이드

태그: #operations #index

## 요약

세모산 페이지는 메인 포털로 두고, 문서 원본은 팀별 페이지와 공통 자료에 유지한다. 팀별 공간은 worktree처럼 분리하고, 메인에서는 빠른 진입과 공통 자료 탐색을 담당한다.

## 루트 구조

- [[세모산]]: 메인 포털
- 업무 공간: [[PM 기획]], [[Backend]], [[Frontend]], [[전체 회의]]
- 디자인: [[디자인 시스템]], 와이어프레임, 완성 디자인
- 운영: 데일리 스크럼, 일정, 자산 DB
- 공통 자료: 피그마 초대 링크, 일정, 팀 공통 참고 자료
