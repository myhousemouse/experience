## 역할

세모산 백엔드 API 명세의 상위 문서다. Notion 안에는 배포 Swagger 링크와 API 명세 DB가 연결되어 있다.

백엔드 개발자가 화면 요구사항과 데이터 구조를 API로 명세하고 구현하기 위한 기준이다. 상세 엔드포인트 확인은 배포 Swagger를 우선 참고한다.
