# 개인 기여 정리

## 2026-10-14 최신 확인 — 새 자소서 작성 시 우선 적용

출처: SK브로드밴드 자소서 작성 대화의 사용자 설명·정정. 개인 진술이며 독립 인증 아님. 아래 내용과 기존 본문이 다르면 아래 최신 범위를 적용한다.

- 코드와 유사도 추천 로직은 팀원이 작성·설계했다. 본인은 파이프라인·유사도 기반 추천을 학습하고 Jupyter Notebook에서 팀원 코드로 독립서적 크롤링을 보조했다.
- 필수 데이터인 도서관 정보나루 API의 월별 인기도서 키워드와 인디도서 설명을 활용한 추천 방향을 이해했다. 기획 배경 조사·콘텐츠·와이어프레임 제작이 본인 핵심 역할이다.
- 2,085건→1,454건 정제와 추천 로직은 팀 산출물이다. 본인이 전부 정제하거나 모델을 단독 설계했다고 쓰지 않는다. 기존 개인 기술 주도 표현과 상충할 때 이 최신 역할 구분을 우선한다.
- 팀은 국립중앙도서관 빅데이터 공모전 1차 합격·최종 발표, 최종 수상은 아님. 팀 인원 4/5명 기존 기록 충돌로 인원은 확인 전 제외.

재사용 에피소드: **LB-LEARN 데이터 수집·추천 방법을 이해해 기획·콘텐츠·와이어프레임으로 구체화**. 분석 모델 단독 개발 성과로 사용하지 않는다.

## 역할 요약

개인 페이지 기록 기준으로, 이 프로젝트에서 일정/업무 분배, 회의 진행, 발표·프로토타입·문서 산출물 제출 흐름 관리에 기여했다. 또한 개인적으로 AI 자연어처리 기반 추천 프로젝트를 정리하고 코드/데이터를 다뤘다.

## PM/협업 기여

- 공모전 일정과 제출 흐름 정리
- 회의 자료와 업무 분배 관리
- 발표, 프로토타입, 문서 산출물 제출 흐름 관리
- 1차 발표 및 최종 발표 산출물 완성까지 관리

## 기획 기여

- 공모전 평가 기준과 필수 데이터 조건 확인
- 아이디어 발산 및 점수화 프로세스 정리
- 독립서적 추천 아이디어의 문제 배경과 필요성 정리
- 도서관 데이터와 독립출판/독립서점 맥락을 연결

## 데이터/NLP 기여

- 인디펍 독립서적 데이터 수집/크롤링 실험
- 도서관 정보나루 키워드/도서 데이터 활용 방향 검토
- TF-IDF, Word2Vec, 코사인 유사도 기반 추천 구조 참고
- `indi_crawling`, `full_code` 등 노트북 산출물 정리
