# 면접용 포인트

태그: #interview #storytelling #career

## 한 줄 요약

국립중앙도서관 도서관 데이터 활용 공모전에서 독립서적 추천 서비스를 기획하고, 도서관 공공데이터와 인디펍 독립출판물 데이터를 자연어처리 기반 추천 구조로 연결해 1차 합격까지 이끈 경험.

## 문제 상황

- 공모전은 도서관 데이터 활용이 필수였고, 단순 아이디어가 아니라 데이터와의 연관성이 중요했다.
- 독립서적은 베스트셀러/판매량 중심 추천에서 잘 발견되지 않는 문제가 있었다.
- 독립서점과 독립출판물은 취향, 주제, 컨셉 기반 큐레이션이 중요했다.

## 판단

- 단순히 도서관 인기대출도서를 추천하는 방식은 차별성이 약하다고 판단했다.
- 도서관 정보나루 키워드와 인디펍 독립서적 설명을 연결하면, 공공데이터 활용성과 독립서적 발견 문제를 동시에 다룰 수 있다고 봤다.
- 자연어처리 기반 유사도 추천이 서비스 아이디어를 설명하기에 적합하다고 판단했다.

## 행동

- 공모전 요건과 평가 기준을 분석했다.
- 아이디어 발산, Affinity Diagram, 점수화 프로세스를 통해 아이디어를 좁혔다.
- 독립서적 추천 알고리즘 관련 논문과 사례를 조사했다.
- 인디펍 데이터 크롤링과 키워드 기반 추천 실험을 진행했다.
- 발표/프로토타입/보고서 산출물을 관리했다.

## 결과

- 1차 합격을 했다.
- 최종 발표까지 진행했지만 최종 수상은 하지 못했다.
- 공모전형 데이터 프로젝트에서 문제정의, 데이터 적합성, 모델 적용, 발표 산출물 관리까지 경험했다.

## 직무별 어필

- PM/서비스기획: 공모전 요건 분석, 아이디어 검증, 문제정의, 산출물 관리
- 데이터/AI 기획: 도서관 데이터와 외부 독립서적 데이터를 연결한 추천 구조 설계
- AX/AI 직무: 자연어처리 기반 추천, 사용자 입력 키워드-도서 설명 유사도 매칭
- 마케팅/콘텐츠: 독립서적 발견성, 취향 기반 큐레이션, 콘텐츠 추천 경험
