## 에피소드 상세

### LB-01 · 공공데이터와 취향 키워드를 추천 기획으로 연결

**이 에피소드가 잘 맞는 질문:** 데이터 기반 서비스 기획 / 개인화 추천 / 공공데이터 활용 / 입사 후 과제의 경험 근거

- 상황·문제: 독립서적의 발견 가능성이 낮고 대중 서적 중심 추천과 다른 취향 기반 탐색이 필요했다.
- 내가 한 행동: 도서관 정보나루 키워드·도서 데이터와 독립서적 정보를 활용한 유사도 기반 추천 구조를 기획했다. 기존 경험 기록의 TF-IDF·Word2Vec·코사인 유사도 검토와 연결한다.
- 결과·배운 점: 독립서적 추천 서비스 빅데이터인디깅을 기획하고 최종 발표에 참여했다. 최종 수상은 아님.

**재사용할 때 강조할 관점:** 지역 도서·문화 혜택 추천 같은 제안을 할 때 과거 추천 기획의 데이터 분류·품질·근거 추적 관점을 연결한다.

**이미 활용한 문항:** 농협 입행 후 목표·실무 과제

**원문 위치:** [[자소서 정리 원문]] 55–59행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 농협 지역 생활혜택 AI, 프로그램 신청률·혜택 이용률은 미래 제안이다. 실제 구축·운영한 서비스나 측정 성과로 아카이빙하지 않는다. 추천 모델 직접 구현 범위는 기존 역할 기준을 유지한다.

### LB-02 · 인기 편향을 베스트셀러와 독립서적 데이터 결합으로 풀다

**이 에피소드가 잘 맞는 질문:** 추천 기획 / 데이터 전처리 / 편향 문제정의 / 분석을 사용자 경험으로 연결

- 상황·문제: 독립서적 인지도 문제를 단순 홍보가 아니라 판매량·대중성에 의존한 추천 구조의 문제로 해석했다.
- 내가 한 행동: 익숙한 베스트셀러를 독립서적 탐색의 진입점으로 삼고 책 정보·인디펍·정보나루 키워드·대출 데이터를 결합했다. TF-IDF·Word2Vec·코사인 유사도 추천 흐름을 구체화했다. 삼성 초안 기준 기획·전처리와 프로토타입·시연 영상 제작을 담당했다.
- 결과·배운 점: 1차 심사를 통과해 최종 발표에 진출했다. 최종 수상은 아니다.

**재사용할 때 강조할 관점:** 질문의 핵심에 맞춰 위 행동과 판단을 골라 쓴다.

**이미 활용한 문항:** 삼성 자소서 4번 직무 성공경험 첫 소제목

**원문 위치:** [[삼성 자소서 원문]] 4번 직무 성공경험 첫 소제목

**표현·근거 메모:** 삼성 초안 팀 인원 4명은 기존 사용자 제공 5명과 다르다. 추천 파이프라인은 팀 구현·검토와 개인 작성 범위를 구분하고, 신규 초안으로 개인 전체 모델 구현을 확정하지 않는다. LB-01과 같은 추천 프로젝트의 구체적 문제해결 관점이다.
