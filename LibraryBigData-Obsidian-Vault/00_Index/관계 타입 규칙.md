# 관계 타입 규칙

태그: #ontology #relationship-rule

## 관계 타입

- `requirement`: 공모전 요건이나 평가 기준이다.
- `defines`: 문제 정의와 서비스 방향을 정한다.
- `supports`: 데이터, 논문, 사례가 기획 판단을 뒷받침한다.
- `implements`: 기획을 분석/모델/프로토타입으로 구현한다.
- `documents`: 회의, 협업 페이지, 산출물이 과정을 기록한다.
- `source-of-truth`: 충돌 시 우선 기준이 되는 문서다.
- `result`: 제출/1차 합격/최종 결과를 설명한다.
- `interview-evidence`: 면접에서 경험 설명 근거로 쓸 수 있다.

## 충돌 기준

1. 개인 정리 페이지의 산출물/결과 기록
2. 협업 페이지의 공모전 진행 기록
3. 산출물 파일명과 제출 자료
4. 초기 아이디어 탐색 기록
