# 최종보고서

원본: https://app.notion.com/p/2563eee3a70482ff8bb3813282c48107
태그: #planning #final-report #submission

## 역할

5주간 진행한 1차 기업 과제의 최종 제출 문서다. 팀 소개, 담당 과제, R&R, 주차별 타임라인, 문제 인식, 문제 정의, 해결 방안, 최종 산출물이 정리되어 있다.

## 과제

- 과제 이름: 리트머스 파트너 플랫폼
- 진행한 선택과제: 기획 / 디자인 / 개발 프로세스 로직 정립 및 자동화 가능성 탐구

## 기획 R&R

- 정지율: 기획리드, 서비스 기획, 서비스 정책 확립, 와이어프레임 작성
- 남은지: 서비스 기획, 유저 리서치, 와이어프레임 작성, UX writing, 기능명세서 작성

## 문제 정의

IT 지식이 없는 고객이 복잡한 기능 구조와 용어 때문에 프로젝트 현황을 직관적으로 이해하지 못하고, 문서 및 피드백 관리가 분산되어 사용이 어렵다.

## 해결 방향

- 기술 용어를 제거하고 문장형 안내로 대체한다.
- 기능 수를 줄이고 핵심 기능 완성도를 높인다.
- 문서와 피드백을 한 화면에서 처리할 수 있도록 3패널 구조를 설계한다.
- 홈 화면에는 미확인 문서, 미완료 투두, 최근 알림을 우선 노출한다.
- 문의/요청 기능을 통해 외부 채널로 흩어진 소통을 플랫폼 안으로 흡수한다.
