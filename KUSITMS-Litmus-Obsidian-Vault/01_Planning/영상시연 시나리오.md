# 영상시연 시나리오

원본: https://app.notion.com/p/7cc3eee3a70482928130015669b75032
태그: #planning #demo #scenario

## 역할

최종 시연에서 PM 시점과 고객사 시점의 사용 흐름을 정리한 문서다.

## PM 시점

- 로그인
- 회의록 업로드
- 바로가기 링크 추가
- 문의/요청 답변
- 문의/요청 파일 분류
- 문서 댓글 확인 및 대댓글
- 최종 기획안, 와이어프레임 업로드
- 해야 할 일 추가
- 진행현황 업데이트
- 중도금 납부 신청

## 고객사 시점

- 로그인 후 홈에서 진행상황 확인
- 진행현황 클릭
- 해야 할 일 상세 확인
- 와이어프레임 문서에서 댓글 작성
- 플로팅으로 문의/요청 접수
- 답변 완료 건 확인
- 문서함 확인
- 회의기록 댓글 작성
