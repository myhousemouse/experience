## 핵심 요구사항

- 고객사가 홈페이지에서 문의하기 버튼을 누르면 즉시 프로젝트가 생성된다.
- 로그인 후 프로젝트 관리 화면에서 해당 프로젝트를 클릭해 진입한다.
- 홈에는 중요 진행상황 3개를 노출한다.
- 제안서와 질의서는 문서 기반으로 관리한다.
- 제안서는 주요 문서 4개와 추가 확장 구조를 가진다.
- 질의서는 질문 1개당 답변 1개 형태로 누적된다.
- 답변 수정은 md 파일 수정 방식보다 DB 기반 저장 후 API 응답 방식이 더 적합하다고 판단했다.
- 수정 요청 사항은 댓글 내용, 생성일, 바로가기 버튼을 포함한다.
- 회의는 기존 양식을 유지하고 AI 요약 기능은 제외한다.
