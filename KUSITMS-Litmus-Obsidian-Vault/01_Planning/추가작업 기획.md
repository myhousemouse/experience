# 추가작업 기획

원본: https://app.notion.com/p/6403eee3a70482dc811601ae163118e5
태그: #planning #extension #phase2

## 역할

1차 기업 과제 이후 약 한 달간 추가로 진행하기로 한 연장 작업의 기획 방향이다.

## 핵심 방향

개발 범위는 한 달 안에 메이저 기능 1-2개에 집중하고, UX 고도화를 병행하는 것으로 정리됐다.

핵심 구조:

```text
세일즈
-> 문서
-> 피드백
-> 티켓
-> 즉시 반영
```

## 주요 기능 방향

- 세일즈와 문서 흐름: 제안서, 회사소개, 초대, 플랫폼 진입
- QA와 피드백 시스템: QA 화면 통합, 화면에서 직접 피드백, 티켓 자동 생성
- 협업과 프리뷰: Vercel Preview 기반 첫 화면, 팝업형 피드백
- 유저 진입: 문의 접수, 이메일 OTP 인증, 회원가입, 플랫폼 진입
- 개발 포인트: 문의 생성 API, 제안서 기반 진입 화면, WorkOS 조직 초대

## 후순위

- 읽음 처리
- 알림 기능과 트리거
