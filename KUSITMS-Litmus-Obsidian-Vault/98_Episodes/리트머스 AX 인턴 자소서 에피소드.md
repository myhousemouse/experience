# 리트머스 AX 인턴 자소서 에피소드

연결 경험: [[리트머스 AX 교육형 인턴]]
기간·역할: 2026.04.20 ~ 2026.05.15
출처: [[자소서 정리 원문]]. 활용 안내: [[자소서 정리]].

같은 경험의 여러 관점을 에피소드로 나눴다. 동일 사건을 독립 프로젝트 성과로 중복 계산하지 않는다. 회사별 지원동기·입사 후 계획은 사용처로만 연결한다.

## 에피소드 상세

### AX-01 · 124개 확인 항목을 PM 업무 흐름으로 구조화

**이 에피소드가 잘 맞는 질문:** 업무 자동화 / 현업 요구분석 / 암묵지 구조화 / 꼼꼼함 / 부서 간 정보 연결

- 상황·문제: 세일즈에서 PM으로 고객 정보가 넘어갈 때 누락이 생기고 Notion·Teams·대시보드를 번갈아 확인해야 했다.
- 내가 한 행동: PM·세일즈 미팅에 참여해 약 110개 고객 정보·10개 착수 정보·4개 유의사항을 정리했다. 고객 답변/확인 항목/누락·재확인으로 재구성하고 Notion MCP로 PM 대시보드에 연결하는 체크리스트를 기획·프로토타입 제작했다.
- 결과·배운 점: 124개 확인 포인트를 화면에서 확인하는 기능을 만들고 구현 과정에 참여했다. 누락률·시간 절감량은 아직 제시되지 않았다.

**재사용할 때 강조할 관점:** 직무역량 문항은 요구사항 구조화와 MCP 연결, 꼼꼼함 문항은 누락을 막는 화면 배치, AX 문항은 현업 지식을 재사용 가능한 기준으로 바꾼 판단을 강조한다.

**이미 활용한 문항:** 카카오뱅크 인증기획 역량; 농협 지원동기; 포스코 직무역량; 두산 도전

**원문 위치:** [[자소서 정리 원문]] 15–16, 50–52, 107–109, 136–138행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 미팅 8회는 원문에 기록된 수치. 124는 정리한 항목 수이며 절감 시간이나 자동화 성공률이 아니다. 전체 상용 기능을 단독 개발했다고 쓰지 않는다.

### AX-02 · 법무팀 요구를 작동형 프로토타입으로 확인

**이 에피소드가 잘 맞는 질문:** AI 도구 실무 적용 / 빠른 가설 검증 / 비전문가와 협업 / 요구사항 구체화 / 실행력

- 상황·문제: 신설 법무팀이 계약서와 프로젝트별 위험 요소를 추적할 기능이 필요했다. 와이어프레임만으로는 실제 동작과 요구를 확인하기 어려웠다.
- 내가 한 행동: 동료 인턴과 법무팀 미팅에서 계약 추적·리스크 관리 정보를 파악했다. 사내 에이전트와 AI 도구로 작동형 프로토타입을 만들고 대표·법무팀 피드백을 반영하며 대시보드 구현을 보조했다.
- 결과·배운 점: 기획 아이디어를 작동하는 형태로 확인하고 기능 반영 과정에 참여했다.

**재사용할 때 강조할 관점:** 정적 화면에서 작동형 프로토타입으로 바꾼 이유와 피드백에 따라 수정한 과정을 보여준다. AX-01과 다른 부서·과제여서 같은 지원서에서 함께 쓰기 좋다.

**이미 활용한 문항:** 현대글로비스 지원동기·직무역량; LG CNS 직무경험

**원문 위치:** [[자소서 정리 원문]] 69, 151–153행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 한 차례 미팅은 LG CNS 초안 기준이다. 개인 담당은 기획·프로토타입·구현 보조로 유지한다.

### AX-03 · 산학협력의 인연을 현업 학습과 결과물로 연결

**이 에피소드가 잘 맞는 질문:** 기회를 잡은 경험 / 성장 과정 / 도전 / 학습을 업무에 적용

- 상황·문제: 산학협력 과정에서 AI 도구를 배우려 했지만 팀원 노트북 환경으로 원활한 활용이 어려웠다.
- 내가 한 행동: 기업이 제안한 교육형 인턴에 참여해 도구 습득에 머물지 않고 PM 미팅에서 실제 정보 누락 문제를 찾아 체크리스트 기능으로 연결했다.
- 결과·배운 점: 산학협력에서 인턴으로 경험을 확장하고 현업 요구를 기능으로 구체화했다.

**재사용할 때 강조할 관점:** 환경 제약→학습 기회 선택→현업 문제 발견→결과물의 흐름으로 쓴다. AX-01은 기능 상세, AX-03은 성장 경로에 초점을 둔다.

**이미 활용한 문항:** 두산 DDI 도전·인상 깊은 경험

**원문 위치:** [[자소서 정리 원문]] 132–138행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 두산 초안은 환경 제약과 인턴 제안을, LG CNS 초안은 성과 인정을 강조한다. 제안 이유를 하나로 단정하지 않고 산학협력 이후 제안받았다는 공통 사실을 사용한다.

## 삼성·CJ 추가 활용 기록

삼성카드 2번 성장 과정: AX-01의 124개 항목과 사내 대시보드 반영, AX-02의 리스크 등급·NDA 만료 알림·개인정보 관리 및 작동형 프로토타입 제작 지원을 보강한다. CJ 1번은 AX-02의 현업 요구분석을 지원동기에 사용한다. 삼성의 “두 달간”은 확정 근무 기간 2026.04.20~05.15와 달라 아카이브에서는 확정 기간을 유지한다. 삼성의 5개 직무 회의 참여·CJ의 법무팀 주 2회 미팅·이전 초안의 1회 미팅은 전체/특정 과제 범위와 시점을 구분해 보관한다.
