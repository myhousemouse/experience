# KUSITMS Litmus Obsidian Vault

큐시즘 IT경영학회에서 리트머스와 진행한 산학협력 기업 프로젝트 정리 vault다.

원본 협업 공간은 Notion이고, 최종 산출물은 Figma와 배포 플랫폼에 흩어져 있다. 이 vault는 기획파트 참여 경험을 중심으로 문제 정의, 리서치, 기업 피드백, 화면 설계, 최종 GUI, 발표 자료의 관계를 추적하기 위해 만든다.

시작 문서: [[큐시즘 리트머스]]
