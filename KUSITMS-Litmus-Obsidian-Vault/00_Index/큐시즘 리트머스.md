# 큐시즘 리트머스

활동 기간: 2026.02.08 ~ 2026.04.16 (1차 종료 2026.03.16, 이후 한 달 연장)

원본: https://app.notion.com/p/32e3eee3a7048359aab1814f812a9ae2
태그: #project #kusitms #litmus #planning #b2b #outsourcing

## 역할

큐시즘 IT경영학회에서 리트머스라는 IT 외주개발사와 진행한 산학협력 기업 프로젝트다. 리트머스가 과제를 제시하고, 팀이 이를 바탕으로 고객사 전용 프로젝트 관리 플랫폼을 기획, 디자인, 개발했다.

초기 1차는 2026.02.08 ~ 2026.03.16에 진행했고, 이후 한 달 연장하여 2026.04.16까지 수행했다. 1차와 2차를 엄격히 나누기보다는, 기업 과제 수행 이후 핵심 기능을 더 고도화한 연장 프로젝트로 본다.

사용자는 기획파트로 참여했다.

## 제품 정의

리트머스 고객사가 외주 개발을 맡긴 뒤 프로젝트 진행 상황, 문서, 미팅, 해야 할 일, 문의/요청을 한 곳에서 확인하고 처리할 수 있게 돕는 B2B 파트너 플랫폼이다.

핵심 문제는 IT 비전공 고객사가 외주 개발 과정에서 현재 단계, 다음 액션, 문서/피드백 흐름을 이해하기 어렵다는 점이다.

## 기획 우선순위

1. 기업 대표님과의 미팅에서 확인된 요구사항
2. 최신 회의록
3. 최종 GUI와 실제 개발된 플랫폼 화면
4. 최종보고서와 최종발표에 정리된 방향성
5. 유저 리서치, PM 인터뷰, MAZE UT 결과
6. 오래된 내부 회의록의 논의/결정사항

기업 과제 프로젝트이므로, 내부 아이디어보다 기업 미팅에서 확인된 요구사항과 최신 회의록, 최종 GUI/개발 화면을 더 우선한다. 최종 GUI는 전체 화면이 개발 완료된 상태다.

Figma 최종 GUI의 기능 우선순위는 빨간불, 초록불, 파란불 순서다. 각 페이지에서 빈값이거나 없는 화면은 미팅 중 필요하지 않다고 결론이 나 작업하지 않은 범위로 본다.

## 면접 포인트

이 프로젝트의 핵심 면접 포인트는 실제 기업 과제에서 문제 정의를 하고, 기업 피드백을 받아 MVP 범위를 조정한 뒤, 개발 완료와 실제 기업 사용까지 이어낸 경험이다. 특히 기획자가 개발 협업 과정에서 로그인/인증/회원가입의 복잡한 진입 로직, 회의기록, 문서함, QA 기능의 필요성과 우선순위를 조율한 점이 중요하다.

기업 과제 이후에는 대표님 제안으로 2026.04.20 ~ 2026.05.15 주 5일 출근하는 [[리트머스 AX 교육형 인턴]]으로 이어졌다. 이 경험은 기획-디자인-개발 분업이 느린 상황에서 문제 정의, UX 개선, 기능 구현까지 빠르게 연결한 실무 경험으로 정리한다.

## 핵심 흐름

```text
리트머스 과제
-> 내부 기획 회의
-> 유저 리서치 / PM 인터뷰
-> 와이어프레임 / 화면 설계
-> UT 시나리오 / MAZE UT
-> 최종보고서 / 최종 GUI
-> 2차 연장: 추가작업 기획 / 대표님 요구사항
-> 세일즈-문서-피드백-티켓 흐름 고도화
-> 실제 기업 사용
-> AX 교육형 인턴 / 내부 대시보드 개선
```
