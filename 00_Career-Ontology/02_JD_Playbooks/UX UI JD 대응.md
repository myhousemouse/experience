# UX UI JD 대응

## UX/UI JD에서 자주 나오는 요구

- 사용자 문제 정의
- 리서치/UT 기반 개선
- 화면 흐름 설계
- 정보구조 개선
- 디자인 시스템 이해
- 프로토타입/GUI
- 사용성 문제 해결

## 우선 조합

1. [[세모산]]
   - UT 가이드, UT 인사이트, 최종 GUI, 디자인 시스템

2. [[인플레이스]]
   - 기능별 GUI, UT 가이드, 디자인 시스템, 파트별 협업

3. [[교보문고 전자도서관 UIUX 개선]]
   - 기존 앱의 검색/대출/사용성 개선안

4. [[리스크 매니저]]
   - 어려운 AI/FMEA 개념을 단계별 앱 화면으로 풀어낸 경험

## 대표 문장

> 저는 화면을 예쁘게 만드는 것보다 사용자가 어떤 판단을 해야 하는지에 맞춰 흐름을 나누는 데 집중했습니다. 세모산과 인플레이스에서는 UT와 GUI를 연결했고, 리스크 매니저에서는 RPN과 AI 분석처럼 어려운 개념을 입력-질문-결과-설명 흐름으로 풀었습니다.
