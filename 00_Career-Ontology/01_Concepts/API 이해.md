# API 이해

## 정의

API 이해는 화면과 데이터가 서버와 어떻게 연결되는지 파악하고, Swagger/API 문서/기능명세를 기준으로 개발자와 소통하는 역량이다.

## JD에서 쓰는 표현

- 화면 요구사항을 API 단위로 이해
- Swagger/API 문서를 읽고 개발자와 커뮤니케이션
- 데이터 흐름과 기능 흐름을 함께 고려
