# 데이터 모델링

## 정의

데이터 모델링은 업무나 기능을 엔티티, 관계, 스키마, SQL, 더미데이터로 구조화하는 역량이다.

## 대표 경험

- [[CODE 데이터베이스 시스템 프로젝트]]: SQLite, CRUD SQL, ERD, 실제 회사 업무 구조화
- [[구름톤유니브 포인커리어]]: ERD, 전체 더미데이터 SQL 입력
- [[도서관 빅데이터 공모전]]: 도서/키워드/대출 데이터 기반 추천 구조
- [[단풍톤 꿈마중 버스]]: 신청자/정류장/노선 기반 산출 로직

## JD에서 쓰는 표현

- 데이터 구조를 고려한 기능 설계
- DB 스키마와 화면 흐름 연결
- 업무 데이터를 시스템 구조로 전환
