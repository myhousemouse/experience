# 직무별 해석

## AX 기획/AX PM

핵심 메시지:

> 기술을 단순히 붙이는 사람이 아니라, 업무 흐름과 사용자 문제를 이해한 뒤 AI/자동화/데이터를 적용해 실제 사용 가능한 형태로 바꾼 사람.

우선 경험:

- [[큐시즘 리트머스]]
- [[텃밭닥터 캡스톤]]
- [[리스크 매니저]]
- [[인크루트 데이터라벨링팀 현장실습 인턴]]

강조:

- 내부 대시보드 UX 개선
- 실제 기업 과제와 인턴 경험
- 챗봇 시스템 구현
- AI 신뢰성 설계
- 데이터 기준 정립

주의:

- AI 모델 자체 연구자로 말하지 않는다.
- “AI를 제품/업무 흐름에 맞게 설계하고 적용했다”로 말한다.

## 서비스 기획/PM

핵심 메시지:

> 문제를 정의하고, 사용자 검증과 협업 산출물을 통해 기능 범위와 우선순위를 조정할 수 있는 사람.

우선 경험:

- [[세모산]]
- [[인플레이스]]
- [[큐시즘 리트머스]]
- [[CODE 데이터베이스 시스템 프로젝트]]

강조:

- UT/유저리서치 기반 의사결정
- PRD/기능명세/회의록/GUI 연결
- 개발팀 전달을 위한 API/ERD 이해
- 실제 기업 피드백 반영

주의:

- “기획만 했다”가 아니라 “기획을 구현 가능한 산출물로 바꿨다”를 강조한다.

핵심 메시지:

> 기획 이해도가 있는 백엔드 경험자로, API/DB/배포 보조/더미데이터까지 프로젝트 완주에 필요한 작업을 해본 사람.

우선 경험:

- [[구름톤유니브 포인커리어]]
- [[단풍톤 꿈마중 버스]]
- [[텃밭닥터 캡스톤]]
- [[AWS 인프라 학습]]

강조:

- Spring 백엔드 구현
- FastAPI 챗봇 서버
- ERD/DB/SQL
