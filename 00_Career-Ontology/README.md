# Career Ontology

이 폴더는 여러 프로젝트 경험을 JD에 맞춰 다시 조합하기 위한 상위 온톨로지다.

목표는 특정 직무 하나에 경험을 고정하지 않는 것이다. 같은 프로젝트라도 JD에 따라 [[AX]], [[PM]], [[UX UI]], [[개발 협업]], [[백엔드 구현]], [[AI 활용]], [[데이터 모델링]] 관점으로 다르게 꺼내 쓸 수 있게 만든다.

## 사용 순서

1. JD에서 요구 역량을 뽑는다.
2. [[역량 태그 사전]]에서 대응되는 태그를 찾는다.
3. [[경험 매핑 테이블]]에서 대표 프로젝트와 근거를 고른다.
4. [[직무별 해석]]에서 해당 직무에 맞는 표현 방식으로 바꾼다.
5. [[이력서 포트폴리오 작성 원칙]]으로 첫 화면, 경험 순서, 목적-실행-결과 구조를 점검한다.
6. [[포트폴리오 구성 템플릿]]에 맞춰 사례를 3-5개로 조립한다.
7. 부족한 정보는 [[추가로 필요한 정보]]에서 확인한다.

## 핵심 관점

- 직무명보다 문제 해결 방식이 중요하다.
- 프로젝트별 기록은 원본 근거이고, 이 폴더는 JD 대응용 조립 레이어다.
- 경험은 `문제 -> 판단 -> 실행 -> 산출물 -> 근거 -> JD 표현`으로 변환한다.
- 과장하지 않고, 본인 직접 기여와 팀 산출물을 구분한다.
