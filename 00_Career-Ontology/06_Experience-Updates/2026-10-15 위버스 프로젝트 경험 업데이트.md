# 위버스 프로젝트 경험 업데이트

확인일: 2026-10-15. 출처는 이번 대화의 사용자 자료·설명. 교수 피드백·개인 기여는 사용자 진술, 설문 수치는 XLSX 재집계다. 실제 서비스 반영이나 개선 성과와 구분한다.

새 경험: [[위버스 앱 개선 프로젝트]], [[위버스 자소서 에피소드]]. 전체 자료는 `Weverse-ServiceImprovement-Obsidian-Vault/README.md`.

- 직접 리뷰 코드 작성, 설문 설계/진행, 버블 비교, 팬레터·번역 개선 Figma 작성. 약 70%는 태스크 기여 자기 추정.
- 클릭 가능한 프로토타입을 제작. 전달받은 PNG 33장의 정적 화면은 확인했으나 분석자가 클릭 실행한 것은 아니다.
- 리뷰는 국가·날짜·정렬 조건을 지정해 수집하고 1~2점 불만·4~5점 만족을 나눠 분석. 원본 CSV·분류 코드·중복 제거는 미확인이다.
- 설문 총 138행, 상세 63(경험 있음 60·없음 3), 사용자 경험 있음 66 중 6은 상세 공란. 팬레터 불편 36/63, 번역 불편 38/63. 전체 이용자 불편률이 아니다.
- 개선안은 크롤링·유저리서치의 불편에서 선정. 교수의 ‘1등’ 평가는 공식 수상으로 취급하지 않는다.
- 기대효과는 작성 수정 부담·번역 이해 장벽·공지/영상 탐색 번거로움 감소와 참여/공유 유도. 측정된 개선 효과는 아니다.
- 라이브 재생바 댓글 위치 표시는 MD에 미구현으로 명시. TTS·팬 매칭은 추가 검토·미구현.

다음 지원서에는 개인 행동·분모가 맞는 조사 결과·프로토타입을 중심으로 사용하고 실제 글로벌 운영·레이블 협업·번역 모델 개발로 확장하지 않는다. 지원 회사의 포부는 과거 경험으로 저장하지 않는다.
