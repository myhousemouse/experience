# 추가 학습 경험 자소서 에피소드

출처: [[자소서 정리 원문]]. 전체 안내: [[자소서 정리]].
기존 프로젝트에 억지로 연결하지 않고 원문에 나온 독립 학습 경험을 보관한다.

### SP-01 · 코딩 경험 없이 C언어 스터디와 테스트를 완주

**이 에피소드가 잘 맞는 질문:** 꾸준함 / 학습 몰입 / 비전공자의 기술 적응 / 성장 과정

- 상황·문제: 대학 1학년 때 코딩 경험 없이 정보보호 동아리에 가입해 C언어와 매주 테스트에 어려움을 겪었다.
- 내가 한 행동: 책의 코드를 직접 입력하고 이해되지 않는 알고리즘은 영상과 필기로 반복 학습했다.
- 결과·배운 점: 한 학기 모든 스터디와 테스트를 완주했다고 원문에 기록한다.

**재사용할 때 강조할 관점:** 처음 막힌 내용과 반복 학습 방식, 완주를 중심으로 짧게 쓰면 AX 인턴의 현업 실행 사례를 보완한다.

**이미 활용한 문항:** 카카오뱅크 인증기획 역량

**원문 위치:** [[자소서 정리 원문]] 18–19행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 원문의 “프로듀스 101”은 공식 동아리명인지 별칭인지 미확인. 경험 기간과 테스트 성적은 미제공. 구름톤이나 KSEB에 임의로 합치지 않는다.

### SP-02 · MDD 호기심을 DevOn NCD 설치·가이드 탐색으로 옮기다

**이 에피소드가 잘 맞는 질문:** 기술 호기심 / 회사 지원동기의 구체적 계기 / 자기주도 탐색

- 상황·문제: 시스템 설계 수업에서 MDD에 관심을 갖고 실제 개발 방식을 알아보고자 했다.
- 내가 한 행동: DevOn NCD를 직접 설치하고 가이드를 살펴 SQL·시각화된 로직 기반 개발 방식을 탐색했다.
- 결과·배운 점: 새 개발 방식에 대한 탐색 경험을 확보했다. 작동 프로그램 제작은 원문에 기록되지 않았다.

**재사용할 때 강조할 관점:** 왜 회사 기술에 관심을 가졌는지 설명하는 짧은 도입으로 쓰고, 실행 역량은 텃밭닥터·AX 인턴 사례로 이어간다.

**이미 활용한 문항:** LG CNS 지원동기

**원문 위치:** [[자소서 정리 원문]] 142–145행. 반복된 후반부 대신 첫 출현 위치를 기준으로 연결.

**표현·근거 메모:** 시스템 설계 수업을 [[택시 승차 서비스 설계]]와 연결할 가능성은 있지만 동일 과제 여부는 미확인. 별도 탐색 경험으로 보관한다.
