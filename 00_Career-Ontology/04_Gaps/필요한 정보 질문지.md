# 필요한 정보 질문지

이 문서는 JD별 포트폴리오를 더 정확하게 만들기 위해 추가로 확인하면 좋은 정보만 따로 모은 질문지다. 전부 한 번에 답할 필요는 없고, 기억나는 프로젝트부터 채우면 된다.

## 1순위: 중심 경험

### 세모산

- 본인 역할을 한 문장으로 말하면?
  - 예: PM 중심, UX 리서치 중심, 개발협업형 기획 중심 등
    => PM역할 + 기획자역할
- 본인이 직접 만든 산출물은 무엇인가?
  - 기획서, 기능명세서, 발표자료, UT 가이드, 회의록, 화면정리 등
	=> 기획서, 기능명세서, 와프 등 모든 문서를 PM에이전트로 1차적으로 만들고 다른 팀원과 회의로 소통하며 디벨롭하는 과정을 거쳤음
- UT에서 가장 중요한 인사이트 2-3개는 무엇이었나?
	=> 이거 너가 노션에서 UT결과 찾아서 정리해줘 그러고나서 추가질문이 있으면 넣어줘
- 최종적으로 개발 완료/시연/출시 중 어디까지 갔나?
	=> 모든 MVP 개발까지 완료됨. 그리고 애플 앱스토어에 출시 준비중임 현재는 테스트앱형태로 준비중
- 세모산에서 가장 어려웠던 판단은 무엇이었나?
	=> 이거는 JD에 맞춰서 에피소드를 엮으면 되지않나?
- 면접에서 꼭 강조하고 싶은 한 가지는 무엇인가?
	=> 저는 강점이 두개 있는데, 하나는 구조를 설계하는 능력이고 둘째는 짠 구조를 사용자 측면에서 항상 생각한다는 점이다. 처음 데스크리서치나 유저리서치를 통해서 페인포인트와 니즈를 구체화하여 MVP를 설계했었다 (막막해요 -> 산 추천, 중간 재미요소를 넣기 -> 트래킹하며 고도별 사진 찍기, 정보가 흩어져있음 -> 산목록 데이터화, 나와같은 등산객들과 소통 -> 커뮤니티, 등산한 산을 아카이빙 하고싶다 -> 지도형태로 완등 마커 + 아카이빙 기능)근데, 실제 등산을 해보며 내가 그 페르소나가 되어 실제 페인포인트를 느껴보고 이 기능이 맞는지 체크하는 과정을 겪음 -> 그 중 메인기능을 고도별 사진 찍기 + 아카이빙으로 정하게 됨. 실제 사용자가 되어 중요한 기능 즉, 내가 이 앱을 필요로 느끼는 지점을 고르는 경험을 함
