# 추가로 필요한 정보

지금도 JD 대응용 조합은 가능하다. 다만 아래 정보가 있으면 포트폴리오와 면접 답변이 더 정확해진다.

## 우선순위 높음

### 세모산

- 확인됨: 세모산 10인 팀 PM; 기획·일정·요구사항·개발 협업 담당
- 실제 출시/개발 완료 여부
- UT에서 나온 가장 중요한 인사이트 2-3개
- 본인이 직접 만든 산출물: 기획서, 기능명세, 발표, 화면정리 등

### 인플레이스

- 본인 역할 비율: PM/PD/FE/BE/marketing 중 직접 기여 범위
- 최종 결과: 개발 완료, 데모데이, 수상/평가 여부
- PRD와 최종 GUI 사이에서 본인이 조정한 판단 사례

### 큐시즘 리트머스/인턴

- 인턴 중 실제 개발까지 한 기능의 범위
- 확인됨: 법무 계약서 추적·프로젝트 리스크 관리, Notion MCP 세일즈 체크리스트 기반 PM 대시보드 기능 기획·프로토타입
- 회사 업무라 공개 불가한 내용과 공개 가능한 요약 범위

## 우선순위 중간

### 빙고 로우코드 공모전
- 공모전 결과
- 본인 구현 범위
- 로우코드에서 가장 어려웠던 제약과 우회 방법

### 도서관 빅데이터 공모전

- NLP/분석 코드 직접 작성 범위

### 교보문고 전자도서관 UIUX 개선

- 교수님/팀 피드백
