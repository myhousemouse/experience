## 한 줄 요약

취준생과 사회초년생이 금융앱에서 내려받은 거래내역 CSV를 업로드하면, 현재 현금성 자산과 월 지출 기준으로 몇 개월 버틸 수 있는지 계산하고 조정 가능한 지출과 예산 계획을 제안하는 PlayMCP용 자산관리 도구.

## 문제 정의

기존 자산관리 앱은 계좌, 카드, 소비 내역, 자산 현황을 잘 보여준다. 하지만 무소득 또는 불규칙 소득 상태의 취준생이 `얼마나 더 버틸 수 있는지`, `어떤 지출을 유지하고 줄여야 하는지`, `면접/교육/포트폴리오 비용을 어떻게 배분해야 하는지`를 판단하기에는 개인 맥락이 부족하다.

취준생에게 중요한 질문은 단순한 월별 소비 리포트가 아니라 다음에 가깝다.

- 현재 현금성 자산으로 몇 개월을 버틸 수 있는가?
- 목표 구직 기간까지 버티려면 월 지출을 얼마나 줄여야 하는가?
- 줄이면 안 되는 취준 필수비와 줄일 수 있는 변동비는 무엇인가?
- 수입이 불규칙할 때 투자 확대보다 현금 확보가 우선인지 어떻게 판단할 수 있는가?
- 금융앱에서 내려받은 거래내역을 어떻게 의사결정 가능한 형태로 바꿀 수 있는가?

## 해결 방향

이 MCP는 금융앱을 대체하지 않는다. 토스, 카카오뱅크, 카드사 앱 등에서 내려받은 CSV/엑셀 거래내역을 입력으로 받아, 사용자의 현재 상황과 목표 구직 기간을 기준으로 생활비 런웨이와 지출 리스크를 계산한다.

핵심은 `거래내역 표시`가 아니라 `구직 기간을 버티기 위한 판단 보조`다.

## 차별점

### 기존 금융앱

- 계좌/카드/자산 통합 조회
- 소비 카테고리 자동 분류
- 월별 소비 리포트
- 예산 초과 알림
- 금융상품 추천

### 취준생 생활비 런웨이 MCP

- 취준/인턴/무소득/불규칙 소득 상태를 입력값으로 반영
- 현금성 자산 기준 생존 가능 개월 수 계산
- 취준 필수비와 조정 가능 지출을 분리
- 목표 구직 기간별 예산안 생성
- AI가 계산 도구를 호출해 사용자의 질문에 맥락 있는 답변을 제공
- 투자 추천이 아니라 현금흐름과 위험 신호 점검에 집중

## 입력 데이터

초기 버전은 실제 계좌 연동 없이 CSV 업로드와 수동 입력으로 설계한다. 실제 금융 API 연동은 오픈뱅킹/마이데이터 승인과 보안 요건이 필요하므로 포트폴리오 MVP 범위에서는 제외한다.

### 사용자 프로필

```json
{
  "monthly_income": 1800000,
  "employment_status": "취준생/인턴",
  "goal": "6개월 생활비 확보",
  "target_months": 6,
  "cash_assets": 4200000
}
```

### 거래내역 CSV 최소 컬럼

```csv
date,description,amount,type,category,memo
2026-07-01,월세,-500000,expense,housing,고정비
2026-07-03,통신비,-69000,expense,telecom,고정비
2026-07-05,스타벅스,-6500,expense,food,카페
2026-07-25,인턴급여,1800000,income,income,수입
```

앱마다 컬럼명이 달라도 MCP 내부에서 표준 포맷으로 정규화한다. 예를 들어 `거래일시`, `적요`, `출금액`, `입금액`, `거래금액`, `가맹점명`을 `date`, `description`, `amount`, `type`으로 변환한다.

## MCP Tool 초안

### parse_finance_csv

CSV 원본을 읽고 날짜, 금액, 설명, 수입/지출을 표준 포맷으로 변환한다.

입력:
- CSV 텍스트 또는 파일 경로
- 선택 입력: 컬럼 매핑 정보

출력:
- 표준화된 거래내역 배열
- 파싱 실패 행
- 누락 컬럼 경고

### categorize_transactions

거래 설명과 금액 패턴을 기준으로 지출을 분류한다.

카테고리 예시:
- housing
- food
- transport
- telecom
- subscription
- job_search
- education
- portfolio
- healthcare
- shopping
- income
- transfer
- unknown

### analyze_cashflow

월수입, 월지출, 저축률, 고정비 비중, 변동비 비중을 계산한다.

출력 예시:

```json
{
  "monthly_income": 1800000,
  "monthly_expense": 1120000,
  "saving_rate": 0.378,
  "fixed_cost_ratio": 0.316
}
```

### calculate_runway

현재 현금성 자산과 월평균 지출 기준으로 생존 가능 개월 수를 계산한다.

출력 예시:

```json
{
  "cash_assets": 4200000,
  "monthly_expense": 1120000,
  "runway_months": 3.75,
  "target_months": 6,
  "gap_amount": 2520000,
  "status": "warning"
}
```

### detect_spending_risks

지출 리스크를 탐지한다.

탐지 항목:
- 현금성 자산 부족
- 고정비 과다
- 반복 구독
- 급증 지출
- 취준 필수비 부족
- 불명확한 이체/현금 지출 비중 과다

### make_budget_plan

목표 구직 기간까지 버티기 위한 월 예산안을 생성한다.

출력:
- 유지해야 할 지출
- 줄일 수 있는 지출 후보
- 월별 감축 목표
- 3개월/6개월/9개월 시나리오

### explain_finance_result

계산 결과를 사용자가 이해하기 쉬운 문장으로 설명한다.

주의:
- 투자 매수/매도 추천을 하지 않는다.
- 대출/금융상품 가입을 권유하지 않는다.
- 정보 제공과 예산 점검 범위로 제한한다.

## 출력 예시

```json
{
  "monthly_summary": {
    "income": 1800000,
    "expense": 1120000,
    "saving_rate": "37.8%",
    "fixed_cost_ratio": "31.6%"
  },
  "runway": {
    "cash_assets": 4200000,
    "monthly_expense": 1120000,
    "months": 3.75,
    "status": "warning"
  },
  "risks": [
    "현금성 자산이 목표 6개월 생활비보다 부족합니다.",
    "구독 지출이 반복되고 있어 별도 점검이 필요합니다.",
    "면접/교육/포트폴리오 비용을 별도 예산으로 분리해야 합니다."
  ],
  "actions": [
    "월 12만원을 줄이면 6개월 생활비 목표에 더 가까워집니다.",
    "구독 항목을 먼저 정리하는 것이 부담이 적습니다.",
    "투자 확대보다 현금성 자산 확보를 우선 검토하세요."
  ]
}
```

## 사용자 질문 예시

- 나 지금 취준 중인데 6개월 버틸 수 있을까?
- 이번 달 지출 중 줄여도 되는 항목이 뭐야?
- 면접 준비비와 교육비를 남기려면 다른 지출을 얼마나 줄여야 해?
- 수입이 다음 달부터 없으면 몇 개월 뒤 위험해져?
- 내 거래내역에서 취준 필수비와 단순 소비를 나눠줘.

## 포트폴리오용 문장

> 기존 자산관리 앱은 소비 내역과 자산 현황을 잘 보여주지만, 무소득 또는 불규칙 소득 상태의 취준생이 구직 기간을 버티기 위한 의사결정을 내리기에는 개인 맥락이 부족하다고 보았습니다. 이를 해결하기 위해 금융앱에서 내려받은 거래내역 CSV를 표준화하고, 현금성 자산과 월평균 지출을 기준으로 생활비 생존 기간, 고정비 부담, 취준 필수비, 조정 가능 지출을 계산하는 PlayMCP용 자산관리 도구를 설계했습니다.

## 구현 범위

### 1차 MVP

- 샘플 CSV 파싱
- 표준 거래내역 변환
- 수입/지출/카테고리 집계
- 생활비 런웨이 계산
- 고정비/변동비 비중 계산
- 간단한 리스크 메시지 생성

### 2차

- 카테고리 자동 분류 규칙 개선
- 취준 필수비 분리
- 3개월/6개월/9개월 예산 시나리오
- PlayMCP 콘솔 등록
- 사용 예시 캡처 및 포트폴리오 문서화

### 제외 범위

- 실제 계좌 자동 연동
- 토스/카카오뱅크 내부 데이터 직접 호출
- 마이데이터 API 운영 연동
- 금융상품 추천
- 투자 매수/매도 추천

## 개인정보 처리 원칙

- 실제 거래내역 CSV는 git에 커밋하지 않는다.
- 계좌번호, 카드번호, 상대 계좌, 상세 메모, 실명은 제거한다.
- 데모에는 `sample_transactions.csv`처럼 가짜 데이터만 사용한다.
- 실제 파일은 `data/private/` 또는 `sample-data/finance/private/` 아래에 보관하고 `.gitignore`로 제외한다.
