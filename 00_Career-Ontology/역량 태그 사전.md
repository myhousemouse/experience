# 역량 태그 사전

## 제품/기획 계열

- [[문제정의]]: 해결할 문제, 사용자, 시장 맥락을 정의하는 역량
- [[PM]]: 우선순위, 요구사항, 일정, 협업, 산출물을 조율하는 역량
- [[서비스 기획]]: 기능 구조, 사용자 흐름, 정책, 명세를 만드는 역량
- [[AX]]: AI 또는 자동화 기술을 업무/서비스 흐름에 적용하는 역량
- [[개발 협업]]: API, ERD, Swagger, Figma, 기능명세를 통해 개발자와 맞추는 역량
- [[문서화 발표]]: 보고서, 발표, 대본, 회의록, 명세서로 의사결정을 정리하는 역량

## UX/디자인 계열

- [[사용자 리서치]]: 인터뷰, UT, 설문, Maze, 인사이트 도출
- [[UX UI]]: 화면 흐름, 와이어프레임, UI 개선, 시연 가능한 화면 구성
- [[디자인 시스템 이해]]: 컴포넌트, 토큰, GUI, 일관성, 프론트 협업

## 개발/기술 계열

- [[백엔드 구현]]: API, Service, Repository, DB 연동, 서버 로직 구현
- [[프론트 구현]]: Android Studio, Kotlin, 화면 구현, 사용자 흐름 구현
- [[데이터 모델링]]: ERD, SQLite, CRUD SQL, 스키마, 더미데이터
- [[AI 활용]]: 챗봇, RAG, Gemini, 프롬프트, AI 신뢰성 설계
- [[인프라 이해]]: AWS, Docker, 배포 환경, 보안그룹, RDS, 모니터링
- [[로우코드 구현]]: Flextudio, API 연동, 빠른 MVP, 제약 기반 우회 설계

## 운영/비즈니스 계열

- [[기업 협업]]: 실제 기업, 대표님 피드백, 고객사 요구사항, 실제 사용
- [[운영 개선]]: 내부 대시보드, ERP, 데이터 품질, 라벨링 기준, 업무 프로세스 개선
- [[데이터 품질 관리]]: 기준 정립, 검수, 라벨링, 중복/오류 탐지
- [[문제 해결]]: 기술/협업/기획의 막힘을 진단하고 대안을 만든 경험

## 태그 사용법

프로젝트를 한 직무에 고정하지 말고 아래처럼 복수 태그로 해석한다.

```md
role_tags: [PM, UX, 개발협업]
skill_tags: [문제정의, 사용자 리서치, 기능명세, Figma, API 이해]
evidence: [Notion, Figma, 회의록, 최종 GUI]
jd_fit: [서비스기획, AX기획, Product Manager]
```
