확인된 핵심: 설문 원본 138건, 위버스 사용 경험 ‘있다’ 66건, 상세 불편 문항 응답 63건. 상세 응답자 중 팬레터 불편 36명(57.1%), 번역 불편 38명(60.3%). 이는 당시 표본의 응답으로 전체 사용자 불편률·현재 앱 상태·개선 효과가 아니다. [S01]

본인 역할은 리뷰 크롤링·설문 설계/진행·버블 비교·Figma 개선안 작성이다. 주도 제안은 팬레터·번역이며 태스크 기여 약 70%는 자기 추정이다. 교수의 ‘우리 팀이 1등’ 발언은 사용자 진술의 피드백으로 기록하고 공식 순위·수상으로 쓰지 않는다. [U01]

원본 파일은 첨부 경로에 보존했다. 이 폴더에는 개인 응답 대신 익명 집계와 발표 텍스트·확인한 화면만 저장했다. 집계를 재현하려면 `scripts/recompute_survey.py`에 원본 XLSX 경로와 출력 경로를 지정한다.
