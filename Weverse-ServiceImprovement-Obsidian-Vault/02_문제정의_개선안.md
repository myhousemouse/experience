# 문제 정의와 개선안

모두 수업 팀 과제의 개선 제안·화면 산출물이다. 발표의 ‘도입·개선했다’는 표현을 위버스 공식 서비스 배포로 해석하지 않는다. 발표 화면과 텍스트를 확인했으나 실제 클릭형 Figma·API 연결·평가 모델은 직접 실행하지 않았다. 출처: P01·S01·N01/N02·U01.

## 1. 팬레터 — 본인 주도

- 문제: 금칙어가 있다는 안내만으로는 어떤 부분을 고칠지 알기 어려움. 장문에서는 수정 부담이 커진다는 팀 해석. [N01, P01 17]
- 근거: 사진을 보고 불편하다고 응답한 36/63명(57.1%). 실제 작성 실패·이탈률이 아니다. [S01 X]
- 제안 흐름: 팬레터 작성 → 보내기 버튼 → 금칙어가 있으면 하단 안내와 해당 표현을 빨간 글씨로 표시 → 수정할 위치 확인. 이후 재전송·실패 복구의 세부 흐름은 자료만으로 미확인. [P01 15·17]
- 산출물: PPT 17의 작성 화면·금칙어 강조·하단 안내. [근거 화면](근거/슬라이드17_개선화면.png)
- 본인 역할: 개선안 Figma 작성과 해당 기능 주도라는 사용자 확인. [U01]
- 운영 측면 추가 검토 제안: 정상 문장 오탐·금칙어 우회·다국어 기준·도움말·운영 기준 공개 수준. 이는 이후 분석자의 제안이며 당시 본인이 검토했다고 쓰지 않는다.

## 2. 번역 — 본인 주도

- 문제: 사투리·줄임말·유행어가 오번역되거나 비속어처럼 나타나 해외 팬이 이해하기 어려울 수 있다는 당시 조사·팀 설명. 특정 원문/정답쌍·발생 건수는 제공되지 않았다. [P01 20]
- 근거: 사진 제시 번역 불편 응답 38/63명(60.3%). 글로벌 팬 비중·실제 오역률을 측정한 것은 아니다. [S01 AA]
- 제안: ChatGPT로 어절별 의미를 외국어로 설명하는 보충 UI, ‘좋음/나쁨’ 번역 평가. 화면에 원문·기본 번역·추가 설명·Good/Not really 버튼이 보인다. [P01 20, 근거 화면](근거/슬라이드20_개선화면.png)
- 구현 범위: Figma 개선안·발표 화면을 확인했다. 실제 API 연동·자동 학습·정확도 상승·평가 데이터 활용 방식은 미확인이다. ‘평가 버튼이 있어 스스로 학습한다’고 단정하지 않는다.
- 운영 측면 추가 검토 제안: 용어집·오역 신고·검수 경로·허위 설명·응답 지연·비용·언어별 품질. 당시 수행과 구분한다.

## 3. 공지 탐색

제목에 그룹/앨범/행사 정보가 길게 섞여 원하는 공지를 찾기 어려움. EVENT·NOTICE 등 대분류와 스케줄 특성 분류 제안. 사진 불편 40/63(63.5%), PPT 17에 분류 탭 화면. 단순 표본 수치만으로 우선순위가 확정됐다고 하지 않는다. [S01 Y, P01 17]

## 4. 라이브 댓글 탐색

댓글 시각과 영상 위치를 직접 계산해야 한다는 문제에서 방송 시작 후 경과시간 표시·시간 클릭 이동을 제안. 사진 불편 36/63(57.1%). PPT 20에 관련 화면이 있으나 실제 동작은 미실행. [S01 Z, P01 20]

## 최신 사용자 확인 U02 — 구현·크롤링 범위 우선 적용

리뷰 크롤링 코드는 직접 작성했고, 개선안 산출물은 Figma 프로토타입뿐이라고 확인했다. PPT의 ‘연동·도입·학습’은 실제 서비스 구현으로 해석하지 않는다. 번역은 2024년 커스텀 GPT 결과를 참고해 API/서비스 연동 출력을 제안한 것이며 정확도 개선 측정은 없다. 첨부 XLSX에는 설문 응답만 있고 리뷰·별점 데이터는 없다. 낮은 별점 선별의 정확한 기준은 기억이 불확실해 공란 유지. 상세: [전체 개선안과 개인 역할 정정](06_개선안_전체목록.md).

## 업로드 PNG·Notion MD 확인 보완

Figma 링크 직접 접근은 여전히 실패했지만 업로드 ZIP의 PNG 33장을 확인했다. 팬레터 3상태·번역 3상태·클립 생성 13화면·DM 이름 변경 5화면·라이브 타임스탬프 3화면·투표 3화면·공지 1장·캘린더 1장·공통 진입 1장이다. [화면별 근거](09_UI이미지_화면별검토.md)를 참조한다. 클릭 연결·실제 기능/API는 실행하지 않았다. 사용자 업로드 MD는 팬레터 node 72-13197, 라이브 node 28-5676을 구분하고 라이브 재생바 댓글 위치 표시는 미구현이라고 명시했다. 새 화면을 실제 배포·번역 정확도 상승·실제 사용자 테스트로 확대하지 않는다. MD 속 FGI·피드백 권고는 실행 기록이 아니므로 수행했다고 쓰지 않는다.

## 최신 사용자 확인 U03 — 작성 시 우선 적용

개선안은 리뷰 크롤링과 유저리서치로 찾은 불편에서 선정했다. 사용자 확인상 **실제 클릭 가능한 Figma 프로토타입을 제작**했으며 분석자가 전달받아 확인한 것은 정적 PNG다. 클릭을 직접 검증하지 못한 것과 클릭 기능이 없는 것을 구분한다. 예상 기대효과는 PPT에 있어 목표·예상으로 활용할 수 있다. 사용자가 제시한 팀 피드백 자료는 개선 전후·11/20~22 UI 구체화 기록이며 특정 의견자·수정 계기는 미확인이다. [선정 이유·협업 기록·기대효과](10_선정이유_프로토타입_협업기록.md).
