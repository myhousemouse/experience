# 본인 기여와 재사용 에피소드

출처 U01: 2026-10-15 대화 사용자 확인. P01·S01은 팀 산출물로, 개인이 모든 내용을 단독 작성했다는 증거가 아니다.

## 역할·결과 구분

| 항목 | 확인된 범위 |
|---|---|
| 개인 행동 | 리뷰 크롤링, 설문 설계·진행, 버블 경쟁사 분석, Figma 개선안 작성 |
| 주도 개선안 | 팬레터 작성·번역 정확성 개선 제안 |

## WV-01 — 사용자 의견을 팬레터 수정 안내로 구체화

- 상황: 팬레터에서 금칙어 안내는 있지만 수정 위치를 찾기 어려웠던 당시 UX.
- 본인 행동: 리뷰 수집·설문 설계/진행·버블 비교를 거쳐 금칙어 위치 강조와 안내가 있는 Figma 화면 제안.
- 근거: 사진 제시 불편 36/63(57.1%), 전체 조사 138건과 분모 구분. PPT 17의 화면.
- 결과: 개선안·발표자료 산출, 교수의 긍정적 피드백. 실제 사용 편의 개선 성과는 미측정.
- 재사용 관점: VOC를 구체적인 실패/수정 안내로 옮긴 판단. 실제 운영 정책을 수립·배포했다고 쓰지 않는다.

## WV-02 — 번역의 이해 장벽을 보충 설명과 평가 UI로 개선 제안

- 상황: 사투리·유행어 등의 번역이 팬 이해를 방해할 수 있음.
- 본인 행동: 설문·조사와 Figma 개선안을 담당했고, 어절별 추가 설명·번역 평가 UI를 제안.
- 근거: 불편 38/63(60.3%), PPT 20.
- 결과: 설명·평가 흐름 화면 제안. 정확도 향상·실제 모델 학습은 확인되지 않음.
- 재사용 관점: 글로벌 사용자 이해를 지원하는 서비스 개선. 실제 다국어 운영 경력으로 바꾸지 않는다.

## WV-03 — 새 기능의 기대와 사용자 반응을 비교한 팀 검토

TTS·팬 매칭 등을 조사하고 발표에서 구현하지 않은 아이디어로 구분했다. 원본의 4~5점 분포·중립 응답을 함께 읽어야 한다. 해당 판단을 본인이 주도했는지는 미확인이라 개인 에피소드로 확정하지 않는다.

## 다음 지원서에 쓸 근거의 우선순위

3. 완성한 개선안과 발표 피드백.

현재 기능 재현·당시 모집 경로·리뷰 분류 기준·개인 설문 분석 범위를 추가 확인하면 더 정확히 쓸 수 있다. 지금 자료로 빈 부분을 추정해 채우지 않는다.

## 최신 사용자 확인 U02 — 구현·크롤링 범위 우선 적용

리뷰 크롤링 코드는 직접 작성했고, 개선안 산출물은 Figma 프로토타입뿐이라고 확인했다. PPT의 ‘연동·도입·학습’은 실제 서비스 구현으로 해석하지 않는다. 번역은 2024년 커스텀 GPT 결과를 참고해 API/서비스 연동 출력을 제안한 것이며 정확도 개선 측정은 없다. 첨부 XLSX에는 설문 응답만 있고 리뷰·별점 데이터는 없다. 낮은 별점 선별의 정확한 기준은 기억이 불확실해 공란 유지. 상세: [전체 개선안과 개인 역할 정정](06_개선안_전체목록.md).

## 추가 자료 R01·F01~F04 확인

사용자가 리뷰 수집 코드·분석 요약을 제공해 수집 국가·정렬·날짜·별점 분석 조건을 보완했다. Google Play는 전체 별점 수집, 이후 1~2점 불만·4~5점 만족 분류다. App Store는 한국 RSS 최신순 최대 10페이지이며 96건 메모는 미재집계다. 리뷰 범주 수의 중복·원본 CSV는 미확인이다. 앞의 ‘낮은 별점 기준 미확인’은 이 자료에 따라 1~2점으로 갱신하되 분류 코드는 미확인으로 유지한다. [코드·분류 검토](07_리뷰수집_분류근거.md).

Figma 네 노드는 접근 실패해 디자인을 읽지 못했다. [노드별 링크·확인 상태](08_Figma_수정UI_참조.md)를 참조한다. PPT 화면을 확인한 것과 Figma 원본을 확인한 것을 구분한다.

## 업로드 PNG·Notion MD 확인 보완

Figma 링크 직접 접근은 여전히 실패했지만 업로드 ZIP의 PNG 33장을 확인했다. 팬레터 3상태·번역 3상태·클립 생성 13화면·DM 이름 변경 5화면·라이브 타임스탬프 3화면·투표 3화면·공지 1장·캘린더 1장·공통 진입 1장이다. [화면별 근거](09_UI이미지_화면별검토.md)를 참조한다. 클릭 연결·실제 기능/API는 실행하지 않았다. 사용자 업로드 MD는 팬레터 node 72-13197, 라이브 node 28-5676을 구분하고 라이브 재생바 댓글 위치 표시는 미구현이라고 명시했다. 새 화면을 실제 배포·번역 정확도 상승·실제 사용자 테스트로 확대하지 않는다. MD 속 FGI·피드백 권고는 실행 기록이 아니므로 수행했다고 쓰지 않는다.

## 최신 사용자 확인 U03 — 작성 시 우선 적용

개선안은 리뷰 크롤링과 유저리서치로 찾은 불편에서 선정했다. 사용자 확인상 **실제 클릭 가능한 Figma 프로토타입을 제작**했으며 분석자가 전달받아 확인한 것은 정적 PNG다. 클릭을 직접 검증하지 못한 것과 클릭 기능이 없는 것을 구분한다. 예상 기대효과는 PPT에 있어 목표·예상으로 활용할 수 있다. 사용자가 제시한 팀 피드백 자료는 개선 전후·11/20~22 UI 구체화 기록이며 특정 의견자·수정 계기는 미확인이다. [선정 이유·협업 기록·기대효과](10_선정이유_프로토타입_협업기록.md).
