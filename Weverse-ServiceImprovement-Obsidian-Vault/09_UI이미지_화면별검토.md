# 개선 UI 이미지 확인

출처 I01: 사용자 업로드 ZIP. PNG 33장 추출·확인, 8개 기능군과 공통 진입 화면 1장. ZIP의 macOS 부속 파일은 제외했고 한글 파일명을 정상화했다. 원본 프레임 픽셀 크기는 [이미지 목록](UI_이미지/이미지목록.json)에 기록했다.

출처 M01·M02: 사용자 업로드 Notion MD 두 개의 개선 전후·11/22 프로토타입 설명. 화면은 정적 PNG이므로 Figma 클릭 연결과 실제 API/필터/저장 동작을 실행한 것은 아니다. 사용자 확인에 따라 산출물은 프로토타입이다.

## 팬레터 — 본인 주도 개선

- 전송 전: 작성 편지에 금칙어 위치가 표시되지 않는다.
- 전송 시: 하단에 ‘금지어를 확인해 주세요’ 안내와 빨간색으로 강조한 표현이 보인다.
- 별도 상태: 강조 표시가 남고 하단 경고가 없는 화면이 있다. 실제 시간 경과·경고 자동 소멸 방식까지 증명하는 것은 아니다.
- 개선 의도: 오류 안내만 받는 상태에서 수정할 위치를 찾을 수 있는 상태로 바꾸는 제안.
- 아직 미확인: 수정 후 성공 전송·미입력·길이 초과·금칙어 오탐·필터 실제 동작. 화면의 빨간 부분을 실제 서비스의 금칙어 판정 결과로 취급하지 않는다.

## 번역 — 본인 주도 개선

- 오역 예시: 화면에 ‘내새꾸 마이 무라 함 또 간디’와 ‘My shrimp, my mura, ham, and Gandhi.’가 함께 보인다. 특정 실제 발화의 수집 경로나 공인 정답쌍은 확인하지 않았다.
- 개선 화면: ‘My baby ate a lot, then left again.’이라는 번역과 어절별 설명을 보충하는 팝업, 음성·복사·공유 아이콘, Good/Not really 평가 버튼.
- 평가 상태: Good을 선택한 별도 화면. 실제 평가 저장·모델 업데이트는 확인되지 않는다.
- 본인 설명 U02: 사투리 등을 처리하는 커스텀 GPT 결과를 참고해 연동하면 오역을 줄일 수 있다는 제안이었다. 위 영어 결과의 문맥 적합성·정확도도 별도 검증하지 않아 ‘정확한 번역으로 개선했다’고 쓰지 않는다.

## 라이브 클립 — 팀 프로토타입

진입 버튼 → 구간 선택 → 선택 범위 확인(재선택/네) → 제목 입력(30자 이내 표시) → 생성 완료·커뮤니티 공유 여부 → 미디어의 클립 게시 형태까지 화면이 있다. 재선택과 선택 상태 차이를 표현했다. 이는 사용자가 구간을 직접 지정하는 흐름으로, 설문의 ‘자동 하이라이트 생성’과 다르다. 실제 인코딩·게시·저장·권한 확인을 수행한 것이 아니다. 개인 단독 기여로 쓰지 않는다.

## 나머지 화면

- 공지: EVENT·NOTICE 등 분류 탭이 있는 세 화면. 실제 분류 데이터/필터 동작은 미확인.
- 캘린더: 아티스트 일정·개인 일정 탭, 날짜·일정 목록. 데이터 연동·일정 추가 성공 여부 미확인.
- DM 이름: 더보기 → 이름 변경 → 입력 화면/입력 상태. 실제 저장·길이 제한·다국어 정책 미확인.
- 타임스탬프: 댓글을 경과시간에 연결하는 화면군과 MD 설명. MD에 재생바의 아티스트 댓글 위치 표시가 **미구현**이라고 명시돼 있다. 클릭 시점 이동은 프로토타입 설명이며 실행 테스트를 하지 않았다.
- 투표: 게시물의 투표 전후·결과 상태를 표현한 3화면. 실제 투표 집계/중복 방지 미확인.
- 알림 스택은 PPT에서 확인했지만 이번 ZIP에는 별도 알림 전후 화면이 없다. TTS·팬 매칭도 ZIP에 없다.

## 최신 사용자 확인 U03 — 작성 시 우선 적용

개선안은 리뷰 크롤링과 유저리서치로 찾은 불편에서 선정했다. 사용자 확인상 **실제 클릭 가능한 Figma 프로토타입을 제작**했으며 분석자가 전달받아 확인한 것은 정적 PNG다. 클릭을 직접 검증하지 못한 것과 클릭 기능이 없는 것을 구분한다. 예상 기대효과는 PPT에 있어 목표·예상으로 활용할 수 있다. 사용자가 제시한 팀 피드백 자료는 개선 전후·11/20~22 UI 구체화 기록이며 특정 의견자·수정 계기는 미확인이다. [선정 이유·협업 기록·기대효과](10_선정이유_프로토타입_협업기록.md).
