# 위버스 앱 개선 프로젝트

최신 확인: 2026-10-15. 정보시스템 관리 관련 수업의 팀 과제로 팬 플랫폼 위버스 개선 방향을 제안했다. 과목 정식 명칭·활동 전체 기간은 미확인이며 설문은 2024년 11월 자료다.

## 본인 역할

- Python으로 앱 리뷰 크롤링 코드 직접 작성.
- 설문 설계·진행, 경쟁사 버블 분석.
- 팬레터 금칙어 위치 안내·번역 보충 설명/평가 개선안 주도 및 Figma 프로토타입 작성.
- 태스크 기여 약 70%는 자기 추정, 팀 전체 성과의 객관적 기여율이 아니다.

## 확인한 결과·범위

- 설문 총 138개 응답 행, 상세 문항 63건(경험 있음 60·없음 3). 팬레터 불편 36/63, 번역 불편 38/63은 사진 제시 응답이다.
- 최종 발표 27슬라이드와 클릭 가능한 Figma 프로토타입을 완성했다는 사용자 확인. UI PNG 33장 확인. 서비스 개발·배포와 다르다.
- 교수에게 ‘우리 팀이 1등’이라는 평가를 들었다는 진술. 공식 순위·수상은 미확인.
- 개선 효과는 PPT의 예상 기대효과이며 실제 이탈·만족·정확도 개선율을 측정하지 않았다.
