# 개선안 선정·프로토타입과 피드백 기록

최신 출처 U03: 2026-10-15 사용자 확인. 리뷰 크롤링과 유저리서치에서 확인한 불편이 개선안 선정 이유다. 클릭 가능한 Figma 프로토타입을 실제 제작했다고 확인했다. 분석자는 정적 PNG를 보았으며 클릭 연결은 직접 실행하지 않았다. ‘클릭 불가’ 또는 ‘정적 화면만 제작’이라고 쓰지 않는다. 실제 서비스 코드·API 개발이나 배포와는 다르다.

## 조사에서 개선안으로 연결

- 팬레터: 금칙어가 있다는 안내만으로 수정할 위치를 찾기 어려운 문제 → 금칙어 위치 강조와 경고 안내. 사진 제시 불편 응답 36/63건은 보조 근거이며 이탈률·실제 이용 성공률이 아니다.
- 번역: 당시 사투리·유행어 오역 사례와 조사 → 커스텀 GPT 결과를 참고한 보충 설명·평가 UI 제안. 사진 불편 응답 38/63건, 정확도 개선 측정은 없음.
- 공지: 주제·스케줄이 섞인 목록에서 정보 탐색이 어려움 → 카테고리 분류.
- 라이브: 댓글 시각과 영상 시점을 계산해야 함 → 방송 경과시간과 클릭 이동.

개선안별 리뷰 범주의 직접 대응 건수·중복·설문에 따른 우선순위 점수는 미확인이다. 사용자는 조사 활용을 확인했으나 ‘이 기능이 최다 불만이라 선정했다’는 기준을 추가하지 않는다.

## 예상 기대효과와 실제 결과

| 제안 | 기대효과 | 실제 확인한 결과 |
|---|---|---|
| 팬레터 안내 | 수정 위치 탐색 부담·작성 중 이탈 가능성 감소 | 강조·안내가 있는 클릭형 프로토타입을 제작했다는 사용자 확인, 정적 화면 확인 |
| 번역 설명·평가 | 사투리·유행어 이해, 해외 팬 소통 장벽 완화 | 번역/설명/평가 상태 화면. 실제 정확도 향상은 미측정 |
| 공지·타임스탬프 | 정보와 영상 시점을 찾는 번거로움 감소 | 분류·경과시간 화면과 프로토타입 기록 |
| 클립·투표 | 콘텐츠 공유·팬 참여 유도 | 흐름/상태 화면, 참여 증가 미측정 |

기대효과는 PPT 17·20~22·26에 제시된 목표·예상이다. 실제 개선율이나 출시 후 효과로 쓰지 않는다. 성과는 조사·문제 정의·클릭 가능한 Figma 프로토타입·발표와 교수 피드백 범위로 둔다.

## 지원서 작성 준비 상태

현재 자료로 작성 가능하다. 본인 리뷰 코드·설문 설계/진행·버블 비교·팬레터/번역 프로토타입 역할을 중심으로 조사→판단→제안 흐름을 설명한다. 구체적인 피드백 수정 사건은 필요한 문항에서만 추가 확인하고, 현재 기록을 넘어서 채우지 않는다.
