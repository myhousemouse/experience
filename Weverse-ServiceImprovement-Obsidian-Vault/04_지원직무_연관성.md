# 플랫폼 서비스 운영 인턴 JD와 비교

J01은 사용자가 붙여넣은 공고다. 공식 페이지 직접 열람 실패와 분리한다. 공고: https://careers.hybecorp.com/ko/o/238385 . 주요 업무는 운영 정책·프로세스, 데이터/VOC 기반 개선, 온보딩·가이드, 레이블 커뮤니케이션이다.

| 요건 | 위버스 과제에서 쓸 근거 | 한계/보완 |
|---|---|---|
| 데이터·VOC 기반 개선 | 리뷰·설문·버블 비교→팬레터·번역 Figma | 운영 로그·개선 후 효과는 없음 |
| 운영 정책/프로세스 | 금칙어 안내·평가 흐름이 이용에 미치는 영향 분석 | 실제 정책 결정·예외 운영 경력 아님 |
| 유저 온보딩·가이드 | 무엇을 고치고 어떻게 이해할지 안내하는 UI | 출시 온보딩·이용 가이드 실제 운영은 미확인 |
| 글로벌 사용자 | 번역 이해 장벽 제안 | 표본 국가·언어 없음, 글로벌 대표성·외국어 역량 입증 아님 |
| 레이블 커뮤니케이션 | 팬·아티스트 접점 이해의 보조 근거 | 직접 레이블 협업 경험 미확인 |
| 개발/기획 협업·이슈 대응 | 수업 팀 개선 화면·발표 | 실제 개발 반영은 쎄듀 QA 30건/10건 반영과 리트머스 경험으로 보완 |

분석 의견: 지원 경험으로 활용 가치가 있다. 위버스 과제는 해당 서비스의 사용자 문제 분석, 쎄듀는 실제 QA·개발 반영 추적, 리트머스는 현업 요구·운영 도구·AI 결과 점검으로 역할을 나누면 좋다. 회사의 채점표·합격 보장이 아니다.

자소서에서는 기업 소개·현재 검증되지 않은 점유율 대신 본인이 어떤 의견을 수집했고 문제를 어떻게 좁혔으며 무엇을 제안했는지 쓴다. 138명을 모두 위버스 사용자로 표현하거나 Figma 제안을 실제 서비스 출시로 바꾸지 않는다. 금칙어 공개 수준·오역 검수 같은 운영 고려는 실제 당시 검토 여부를 확인한 뒤 개인 행동으로 쓴다.

지원 자격의 학위·경력 합산·6개월 풀타임 가능 여부는 별도 미확인이다.
