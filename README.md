## 사용법

1. JD가 들어오면 [[JD 분석 템플릿]]에 붙인다.
2. 요구 역량을 [[역량 태그 사전]] 기준으로 바꾼다.
3. [[경험 매핑 테이블]]에서 프로젝트를 고른다.
4. [[직무별 해석]]과 JD playbook으로 표현을 맞춘다.
5. [[포트폴리오 구성 템플릿]]에 맞춰 최종 포트폴리오를 구성한다.
